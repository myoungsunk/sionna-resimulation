# 실험 검증 계약

- 질문 ID / 작성 역할 / 작성 시각:
- 상태: DRAFT / FROZEN / AMENDED (사후 변경 여부):
- 정책 ID 및 지침 커밋 또는 해시:
- 대상 저장소 / 브랜치 / 기준 커밋:
- 질문 / 경쟁 설명 / 구별 가능한 결과:
- 허용 주장 / 성공해도 허용하지 않는 주장:
- 수식 / 변수 / 단위 / 좌표 / 시간 인덱스 / 조건부 가정:
- 입력·해시 / 학습·평가 분할 / 독립 반복 단위:
- 변경 요인 / 고정 요인 / 동반 개입 / 식별 한계:
- 평가 표본·시간·mask / 지표·목표·자유도:
- 기대 조건 키·수 / 누락·중복·실패·제외 규칙:
- 수용·기각·판단 불가 기준 / 사전 민감도 분석:
- 기준선 일치 대상·허용오차:
- 핵심 수학·동작 검사 / 예외 처리:
- 계약 항목 → 구현 함수 → 검사:
- 실행 범위·중단 조건 / 출력 위치 / 출처 기록:
- 계약 변경 이력·이유 / 영향받는 주장:

실행 전 계약과 실행 후 증거를 구분한다. 실행 후 실제 커밋·명령·환경·인자·시각·종료 상태·해시·예외를 연결한다.
