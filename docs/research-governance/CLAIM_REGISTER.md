# 주장과 정정 상태

새 주장 또는 기존 주장을 변경할 때 기록한다. 이 초기 파일에는 과거 MB_VAR 결론을 새로 승인한 행이 없다. 기존 주장 이전은 원 증거와 정정 이력을 확인한 별도 작업이다.

| 주장 ID | 질문·계약 | 정확한 주장과 한계 | 정책 버전 | 구현 커밋·위치 | 실행·증거 | 감사·결함 | 주장 상태 | 수정·재검증·정정 링크 |
|---|---|---|---|---|---|---|---|---|

주장 상태: PROPOSED / SUPPORTED_WITHIN_SCOPE / ON_HOLD / WITHDRAWN / SUPERSEDED.
결함 상태는 별도 기록: OPEN / FIXED / REVALIDATED / CLOSED.
실행 성공이나 감사 완료만으로 주장 상태를 승격하지 않는다. 원 주장과 원 증거를 삭제하지 말고 후속 정정에 연결한다.
