# B + P 7.5 cm: R0–R1 실행 결과

## 결론

탐지된 오류 678건 모두에서 참조 tap이 기존 VAB 생성 후보에 있고, RF 유효성 조건과 고정 P 구간을 통과했다. 후보 생성·유효성 판정·P 교집합에서 잃은 참조는 각각 0건이다. **현재 병목은 후보 누락이 아니라 선택과 정상 보호다.** 이는 후보 포함률 100%이며 정정 성공률 100%가 아니다.

정상 오경보 11건에서도 P 안에 유효 RF 대안이 하나씩 존재한다. 기존 RF support 비교에서 B가 더 강한 경우는 6건, 잘못된 P 대안이 더 강한 경우는 5건이다. 따라서 RF 후보 존재 또는 기존 support 우위만으로 11건 모두를 보호할 근거는 확보되지 않았다.

## A. 기준선 연결

- 고정 코드: `fca24720524068badeab79b78098a244cebc62b5`.
- B: 각 RX 자기 peak 진폭의 30% crossing 중 유효한 이른 tap. P: 저장 구간 중점, 반경 0.075 m, 비교 여유 1e-12 m. M 없음.
- R2 979행, R4 742행, R5 1,415행, 총 3,136행. `(case,k,t)` 및 `pose_id` 저장. t는 초 단위 time이다.
- 실제 저장 Hrf로 Hann 257 / IFFT 1028 CIR을 재구성하고 B·참조·경보·시간·B S·LoS S의 기존 행별 결과 일치를 확인했다.
- 3,136행 재현 검사 및 기존 S1 기록과 후보 RF 점수·자격 비교 68,736건 통과.
- 입력 payload 및 원본 코드 해시는 [SUMMARY.json](SUMMARY.json)의 `source_hashes`, 실행 스크립트 해시는 `script_sha256`, 산출물 해시는 [ARTIFACT_HASHES.json](ARTIFACT_HASHES.json)에 있다. 매니페스트 입력/코드 SHA와 일치 확인.

## B. 후보 포함과 누락

기존 `generate_revision(..., 'VAB', ...)`의 TWO_PORT_UNION 후보를 사용했다. 실제 에지, edge−1, 에지 이후 tap의 출처를 각각 기록했다. P 격자 tap을 새 RF 후보로 삽입하지 않았다. 유효 후보는 기존 usable / supported / polarization_valid 조건을 만족하는 후보이며, 평가용 참조는 후보 생성·점수 입력에 넣지 않았다.

|단계|참조 포함|참조 누락|
|---|---:|---:|
|VAB 생성 후보|678|0|
|RF 유효 후보|678|0|
|RF 유효 후보 ∩ P|678|0|

|P 안의 정수 tap 수|TP 행 수|유효 RF∩P 1개|유효 RF∩P 2개|참조 누락|
|---|---:|---:|---:|---:|
|1|655|655|0|0|
|2|23|2|21|0|
|합계|678|657|21|0|

657건은 교집합에 참조 하나만 남고, 21건은 참조를 포함한 두 후보가 경쟁한다. P 격자 두 개 중 하나가 RF 후보로 남지 않은 2건에서도 참조는 보존된다. 이들은 참조 누락 사례가 아니다.

기존 RF support는 로브 강도와 해당 tap 진폭을 정규화한 값이며, RF 비용은 음의 로그 형태다. P를 적용하기 전 전체 유효 RF 후보에서 참조가 RF 1위인 TP는 0/678건이었다. 이 점수는 참조 에지의 정확성을 보장하지 않는다. 참조와 B의 쌍별 비교는 다음과 같다.

{('B too late', 'B stronger'): 251, ('B too early', 'ref stronger'): 427}

즉 B가 너무 이른 427건은 참조 support가 B보다 높고, B가 너무 늦은 251건은 B support가 참조보다 높았다. 기존 점수의 우위가 올바른 정정 방향 전체를 지지하지 않는다. 이는 순위 진단이며 K2/K3 선택기 실행 결과가 아니다.

### 정상 오경보 11건 전수 비교

## C. 실제 CIR 근거

[CIR 근거 갤러리](EVIDENCE.html)에 총 14개 그림을 수록했다. 정상 오경보 11건 전부와 P 격자 2개·B가 너무 이른 사례·너무 늦은 사례 각 1건이다. 대표 사례는 해당 조건의 첫 행으로 선정했다. 참조 후보 누락은 0건이므로 누락 사례 그림은 해당 없음이다.

각 그림에는 두 RX의 실제 CIR, 각 RX 30% 선과 에지, B, 전체 생성 후보, 제외 여부, P 구간, 평가용 참조 tap을 표시했다. 갤러리 표와 pool JSON에는 후보 출처 및 상세 제외 사유를, 동반 NPZ에는 실제 복소 CIR을 저장했다. 전체 지연 개요와 관련 tap 확대를 함께 제공한다.

## 실행·검증 상태와 주장 범위

- R0 기준선 연결: 완료. R1 후보 포함/누락 및 11건 RF 비교: 완료.
- 산출물 원본 SHA 재검증, 전체 행/집단 수, 후보 교집합 집계, PNG 14개 파일 무결성 검사 통과. 대표 그림 시각 확인. 구현자 자체 확인이며 독립 감사가 아니다.
- 첫 RUN_001은 Windows 긴 파일 경로 때문에 실패했다. 실패 기록을 보존하고 캐시 경로만 짧게 바꾼 RUN_002에서 정상 종료했다. 연구 설정은 변경하지 않았다.
- FP 교체, 정정 성공률, 거리/S 개선, K0–K3 실행, P 민감도, EKF는 수행하지 않았다. B+P 7.5 cm와 비경보 유지 규칙은 보존했다.
- 현재 노출된 3,136행의 고정 P 재생 결과이며 새로운 환경 일반화·폐루프 개선을 주장하지 않는다.
- 다음 단계의 근거: 후보 확장을 우선할 필요는 현재 TP에서 발견되지 않았다. 선택·보류 정책과 정상 보호의 손익 비교가 다음 질문이다. 이번 실행은 R1에서 종료한다.
