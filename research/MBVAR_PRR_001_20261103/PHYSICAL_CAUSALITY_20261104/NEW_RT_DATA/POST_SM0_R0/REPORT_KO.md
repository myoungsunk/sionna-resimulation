# R0 통제 콘크리트 판의 경로 귀속

PR #34의 e2ff5b3e를 기준으로 PR #33의 Snowball 성공 출력 151개와 실패 출력 19개의 바이트 해시를 별도로 검산했다. 분석 입력은 성공 raw 32개다. FFD가 투영된 2×2 복소 H를 대상으로 하며, first-path 관측은 기존 TX+45 열의 두 RX 포트를 사용한다. 신규 RT 호출은 0회다.

C01−C00은 바닥 효과, C10−C01과 C11−C01은 같은 바닥 위에 콘크리트 판을 추가한 효과다. 모든 bin에서 기준 장면과 공유하는 interaction chain의 복소 기여는 동일했다. 빈 chain은 직접파다. 바닥만 있는 C01과의 필드 일치 및 장면의 두 물체 구성을 근거로 ID 1을 바닥, ID 2를 판으로 해석했다. 원시 배열 순서 (2,1)은 판과 바닥을 모두 포함하는 경로다. 반사점·입사각은 저장되지 않았다.

경로별 전력 제거 효과는 해당 경로와 나머지 장의 간섭을 포함하므로 경로별 제거 효과들을 더하지 않는다. R0_COHERENT_POWER_TERMS.csv의 all_added는 추가장 전체를 한 번에 비교한다. 고정 tap 분해는 먼저 새 채널을 기존 tap에서 평가하고 이어서 새 tap으로 옮기는 순서를 사용했다. 194에서 tap 27 선택에 해당하는 증분은 전체 Δs의 약 69.6%다.

32개 key의 ray 합과 저장 H 사이 최대 상대 L2 잔차는 3.925e-8이고 동일 조건 반복 H는 16/16 일치했다. 이 판정은 통제 장면 네 pose에만 적용된다. 음성 대조에서 특정 반사점 이탈이나 차폐가 원인이었는지, 원래 6면 복도에서 같은 현상이 발생하는지, EKF 과신 또는 시간적 확률 상관이 존재하는지는 미판정이다.
