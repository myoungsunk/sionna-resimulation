# SM0 실행 범위

사용자가 PR #28의 15개 pose에 대해 SM0 생성과 독립감사를 승인했다. 기준 커밋은 2173469403327dd7fdbfb3ecf3a3c77508b7b1da다. 같은 원본 scene·bank·포트·solver·257개 주파수를 사용하며, R4 194번 한 곳에서 과거 결과를 먼저 재현한다. 첫 대조가 실패하면 원시 실패와 원인을 남기고 확대를 중단한다. 나머지 14개는 첫 대조 독립 검증 후에만 실행한다.

원시 계수로부터 두 방법으로 만든 복소 합을 검증한다. 독립 scalar float64 기준에 대한 상대 L2와 최대 정규화 잔차를 각각 1e−8 이하로 동결했다. 실제 경로 기여 분석에 사용하는 Full/직접파가 원본 Full/LoS와 일치해야 하며, 상대 L2 기준은 각각 1e−3/1e−5다. 기존 float32 연산과 네이티브 CFR도 별도 기록한다. 각 pose의 검출 tap은 원본과 직접 대조한다. R4의 기존 대조 4개와 C0-A 결과는 references에 있다.

주파수별 원래 ray index와 지연, 각도, 물체, interaction chain을 보존한다. 주파수 간 비교는 동일한 표면·상호작용 순서의 합으로 한다. 같은 순서 안에 복수 광선이 있을 때 물리적으로 동일한 단일 ray로 간주하지 않는다. 한 그룹 또는 해당 표면을 지나는 모든 그룹을 복소장 합에서 제거해 두 포트의 전력과 편파비를 계산한다. 같은 tap에서의 변화와 first-path 검출을 다시 수행한 변화를 분리한다. 서로 겹치는 여러 표면 제거 효과나 signed ratio의 제거 차이를 합산하지 않는다. 포트 전력에 대해서만 coherent quadratic allocation의 합을 대조한다.

이번 범위는 C0-B 원시 데이터와 검증까지다. 표본은 사후 선택한 사례이며 C1에서 동일 EKF prior에 개입하거나 C2에서 Heading 오차·과신의 재귀적 인과관계를 계산하지 않는다. SM1, SM2, C3 및 새 복구 정책 채택 여부는 별도 범위다.
