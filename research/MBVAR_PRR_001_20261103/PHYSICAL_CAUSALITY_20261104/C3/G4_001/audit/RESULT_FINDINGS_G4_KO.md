# C3 G4 독립 결과감사

**판정: ACCEPT — 확보한 24조건의 저장 채널 물리 분석·36개 yaw 대조와 보고서에 한정.**

질문은 C3-SM2-YAW-001이다. 독립 AUDITOR가 동결 계약, 실행 GO와 코드, 독립 검산 결과, 실제 종료 증거 및 해석 보고서를 대조했다. G4 결과를 수용하며, 기존 알고리즘 전체 채택 NO-GO와 실시간 적용 HOLD는 유지한다.

## 수용 범위와 실행 증거

6개 고정 좌표에서 yaw 0°, 180°, +35.7°, −35.7°의 24조건, 좌표마다 사전 지정한 6쌍씩 총36쌍을 모두 확인했다. 선행 G2의 4조건과 G3의 저장 데이터 20조건만 사용했다. actual-yaw 두 캡처는 출처 연결용이며 이 분모에 포함하지 않았다.

생산 실행 코드는 1c1decaa8ae43dcd5119596943b499f9b495d338이다. 원래 Windows C1B 모델 환경, 동결한 전이 의존성과 bank, 실제 BLAS 1 thread를 확인했다. 입력 135개 항목과 출력 해시 목록 103개 산출물을 검증했다. 생산 실행과 독립 검산 모두 실제 자연 종료0, 소유권 해제·참조0, 프로세스·supervisor·job 부재가 확인됐다.

생산 SourceFFD 초기화는 1회이고, 별도 독립 검산에서 원래 모델을 1회 초기화했다. 새 RT·학습·EKF 실행은 모두0회다. 기존 G3 원래 실행은 FORCED_AFTER20이며 정상 종료 수용은 false다. 저장 데이터 수용과 G4의 정상 종료가 이 결함을 소급 해결하지 않는다.

## 독립 검산 내용과 결과

독립 검산기는 생산 physics.py, model_adapter.py, authority.py를 호출하지 않았다. 저장 original_field의 순차 합으로 legacy group과 Full의 exact replay를 확인하고, 별도 SciPy FFT·selector·스칼라 및 행렬 계산으로 전체 결과를 검산했다. float32 RF 위상을 새 환경에서 재생성하거나 F64 그룹으로 대체하지 않았다.

- 24조건×257 bins=6,168개의 주파수 조건, 양 RX의 스펙트럼·CIR·전력·Full/LoS 검출 tap을 확인했다.
- 진폭 peak 30%, 동률 첫 RX·첫 threshold tap, modulo1028 ±4 tap 창, signed 편파비를 검증했다.
- fixed-tap·selector 분해, group 개별 전력·교차행렬·coherent allocation, group 제거 2,976행과 surface 제거 288행을 검산했다. surface는 group 합집합으로 한 번만 제거했다.
- 원래 모델 중심 상태24개와 차분 양끝96개, s/rad→s/deg 변환, 두 차분 step과 active branch를 확인했다.
- 20조건은 두 step 모두 smooth 검증을 통과했다. P10Yp/P10Yn의 yaw0°·180° 네 조건은 branch 변화로 미분 일치 판정에서 제외됐으며 원자료와 endpoint를 보존했다.
- 36쌍의 방향은 사전 yaw 순서의 뒤−앞이다. JSON·CSV와 조건별 요약을 모두 확인했다.

독립 FFT 대조의 최대 배열 상대오차는 9.399409350717209e-15로 1e-8 기준 이내다. 독립 조건 분해 잔차 최대값은 2.7755575615628914e-17이다.

보고서가 집계한 생산 CIR joint/RX별 Erel/Emax 최대값은 1.6178677509887792e-15, 중심 전력 폐합 최대 절대 잔차는 6.938893903907228e-18, 36쌍 분해 최대 절대 잔차는 8.326672684688674e-17이다. smooth 차분40개 step의 최대 절대 오차는 3.3857692205430112e-09이며, 모두 기존 1e-6+1e-4|Hψ| 기준을 통과했다. 서로 다른 오차 지표를 같은 수치로 취급하지 않았다.

## 보고서 수치와 물리 해석

원문 보고서의 24개 조건 행, 6개 좌표의 yaw 대조 최소·최대48개 값, R4/R5 표면 제거 순위8행, 다섯 집계 지표를 검증된 산출물과 대조했다. 6자리 반올림과 단위를 확인했으며 추가된 물리적 차이 설명도 자료와 일치한다.

R5_982 yaw0°의 eMP=+0.541626은 fixed=+0.081130과 selector=+0.460496으로 나뉜다. +35.7°에서는 Full/LoS tap이 모두55이며 selector=0이다. −35.7°에서는 tap60/55와 selector=+0.394038이 나타난다. 따라서 이 위치의 차이를 같은 tap의 복소 간섭만으로 설명할 수 없다는 한정된 결론은 지원된다.

R4_168에서는 선택한 yaw에 따라 fixed와 selector의 부호·크기가 바뀐다. P10 두 좌표의 8조건에서는 Full/LoS tap이 모두11이고 selector=0이지만 fixed는 남는다. 같은 tap에서도 signed 편파 차이가 발생한다는 대조를 지원한다.

R5의 0°→+35.7°에서는 직접파 변화와 eMP 변화가 일부 상쇄된다. 작은 Full 변화만으로 약한 안테나 yaw 응답이나 작은 다중경로 영향을 단정할 수 없다는 설명도 타당하다.

이들은 고정 좌표의 이산 yaw 대조와 저장 채널의 대수적 분해다. 개별 효과의 독립·가산 기여율, 연속 yaw의 실제 RT 미분 또는 전체 자연주행 원인을 확정한 결과가 아니다.

## 보존한 경계와 검증 기록

저장 group/surface 제거는 기존 경로 스펙트럼에 대한 오프라인 개입이다. 실제 벽을 제거했을 때의 경로 재생성과 재산란을 포함하지 않는다. 원래 SourceFFD Hψ는 해당 관측모델의 active-branch 미분이며 새 RT 물리 미분·Fisher 정보·독립 상태 정답으로 해석하지 않는다. Heading/XY·NEES 개선, 새 guard, 채택 또는 실시간 성능을 주장하지 않는다.

실행 전 CIR 영점 부근의 원소별 상대오차 결함은 기존 Erel/Emax 정의와 동일1e-8로 수정했다. 최초 preflight 실패001/002와 유효한 flat-spectrum 회귀를 보존했다. 실제 과학 출력이나 원래 RF 기준을 바꾼 수정이 아니다.

최종 보고서 대조용 경량 검사 초안에서는 Windows 기본 cp949 디코딩과 숫자 뒤 문장 마침표를 포함하는 정규식 오류가 있었다. UTF-8과 숫자 파싱만 수정해 검사를 완료했다. 이는 보고서 검사기의 행정 오류로, 생산 분석·독립 모델 검산을 재실행하거나 산출물·보고서·수치 허용오차를 변경하지 않았다.
