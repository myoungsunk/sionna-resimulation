# 발동 전 특징과 20초 복구 손익

질문 N0B-F1/F2. 공개 평가 사건에 대한 사후 탐색, 구현자 자기검사. 입력 기준 PR #24 176ccac7. 재현 명령은 이 폴더에서 `python analysis.py`. EVENT_JOIN.csv는 P0의 직전 시점 특징과 N0B 결과를 사건 ID로 1:1 연결한다. 520/520 일치, 모든 직전 인덱스 k−1. 기각 29건을 연결표에 보존하고 실제 처치 491건에서 연관성을 계산했다. 처치 전 GT 정확도는 참조용이다. Δ는 ON−OFF, 음수는 누적 오차 감소다. signed Δs는 기록되지 않아 최근 5초 평균 절댓값을 사용했다. 공분산은 직전 출력 posterior다.

SEED_ASSOCIATIONS.csv는 단계·경로·채널·bias·arm 안에서 seed별 변수 중앙값 사이의 Spearman ρ와 seed 하나씩 제외한 범위를 제공한다. 표본이 부족하거나 값이 일정하면 빈칸이다. 경로와 seed는 층화와 반복 관측 처리에만 사용했다. 분석은 학습·독립 평가를 포함하지 않는다. 삭제 민감도는 신뢰구간이 아니다.

Full에서 S2의 평균 |d0|와 두 손익 사이 ρ 범위는 R4 +0.52~+0.90, R5 −0.60~−0.06이다. 평균 |Δs|도 각각 −0.59~−0.35, +0.20~+0.60으로 반전됐다. S2 A/B 위치 차이는 두 경로에서 음의 방향이지만 R5 공동 손해 65건 중 57건이 같은 bias·arm의 R4 공동 이득 특징 범위 안에 들었다. OVERLAP.csv에 범위와 반례 ID를 남겼다.

S3 Full은 평균 |d0|, NIS, 직전 Heading 분산이 양쪽 경로에서 두 적분 차이와 모두 양의 순위 연관을 보였다. 세 특징의 부호는 seed를 하나씩 제외해도 유지됐다. R4에서 모든 실제 처치가 이득이므로 그 안의 순위는 이득 크기의 순위다. 불리한 부호를 판별하는 성능은 여기서 추정되지 않는다.

CONDITIONAL.csv는 각 단계·bias·arm의 Full 사건을 합친 특징별 중앙값으로 |d0|와 민감도 또는 공분산을 각각 둘로 나눈 기술표다. 경계는 사후 요약용이며 구간별 사건 수, seed 수, 결과 부호, seed 중앙값의 중앙값을 제공한다. S3 B0 C_CP에서 높은 |d0|·낮은 민감도의 R5 12건(8 seeds)은 전부 공동 손해, 높은 |d0|·높은 민감도의 R4 14건은 전부 공동 이득이다. 전자 구간에는 R4, 후자에는 R5 관측이 없다. S3의 |d0|×민감도 16개 구간 중 두 경로가 함께 관측된 곳은 2개다. 경로별 조건 분포가 달라 공통 발동 기준을 식별하기 어렵다.

판정은 S3 후보 특징의 방향 재현까지다. 임계값, 새 RF에서의 판별 성능, 미등록 시점의 효과, 동일 시작점 S2 대 S3 우열은 미검증이다. Native-LoS 결과는 별도 층에 두었다. 전체 채택 NO-GO 및 실시간 HOLD 유지.
