# N0B 실행계획 — 같은 상태에서 복구를 켰을 때의 손익과 R4 이득 보존

**상태: 제안 · 미실행.** 결정 질문은 두 가지다. R5에서 개입 직전 이미 정확한 경우와 부정확한 경우에 같은 복구 처치가 각각 어떤 손익을 만드는가? 그 손익 차이를 이용할 가능성이 있을 때, 동일한 온라인 규칙으로 R4의 확인된 이득을 유지할 수 있는가?

제안 기준은 cc21c58b의 S1–S3 최종 결과와 4ca8e954의 제안서다. P0 표와 독립 검산은 [분석 보고서](P0/P0_REPORT_KO.md)와 [감사 보고서](P0/P0_INDEPENDENT_AUDIT.md)에 있다. 기존 채택 NO-GO와 실시간 HOLD를 출발점으로 삼는다. 아래의 신규 판정 기준은 실행 전 동결할 제안값이다.

## 1. 사건 등록과 비교 분모

1. 기존 seed 10–29는 공개 자료 재분석 집합이다. 원시 실행을 식별하는 키는 단계·경로·bias·채널·seed·자연 정책 arm·pose ID·결정 시각이다. [사건 목록](P0/LABELS.csv)의 index를 고정 trace의 pose ID에 대응시키고, 코드·입력·mask·환경·선행 처치 이력 해시를 실행 전에 동결한다. 동일 경로의 여러 시드는 동일 RF를 공유한다.
2. 주 집단은 R5 Full의 **모든 원래 발동 시점**이다. 자연 정책의 처치 전 predicted prior와 동시각 GT로 |Heading 오차| ≤1° 및 XY 오차 ≤0.10m이면 정확, 나머지는 부정확으로 **분기 전에 한 번만** 표시한다. 이 레이블은 평가기 전용이다. B0/L2, 예방 OFF/ON, S2/S3를 각각 보고한다. 각 층의 사건·고유 seed·고유 pose·처치 가능 수를 기록한다.
3. 원본 기준 R5 Full은 S2 주입 164건(정확 132, 부정확 32), S3 후보 162건(132, 30)이다. S3는 161건 채택(132, 29), 1건 경계 초과다. R4 Full은 단계별 후보 80건이 모두 부정확하고 S3 채택은 56건이다. Native-LoS는 동일 규칙의 음성 대조로 포함한다. 전체 잠금 자료의 기대 분모는 S2 261건, S3 259건이다. 같은 사건이 두 정책·단계에 나타나도 독립 표본으로 합산하지 않는다.
4. 누락·history 부족·안전경계 초과·추적창 검열·무발동을 구분한다. 쌍을 만들 수 없어도 원래 분모에 남긴다. 사건이 없는 시점의 잠재적 이득은 이 설계의 추정 대상 밖에 있다.

## 2. 단일 사건에서 복구만 바꾸는 시험

각 자연 정책을 처음부터 원래 순서로 재생한다. 해당 시점에 발동 조건이 확정되고 처치하기 직전에 완전한 상태를 복제한다. 복제본에는 x/P, shadow BASE, gate와 risk·geometry·cooldown 상태, 과거 가중치, checkpoint·packet 이력·원본 pose ID가 포함된다. 이후 두 분기는 같은 z·μ/R·운동 입력·시각·BASE 수용 mask와 같은 예방 정책을 사용한다. C 계열의 예방은 계속 OFF, D 계열은 계속 ON이다. D를 A의 이력에서 시작하지 않는다.

| 분기 | 이번 사건에서만 바뀌는 것 | 그대로 유지할 것 |
|---|---|---|
| S2 ON / OFF | 동결된 ΔP를 측정 직전에 적용 / ΔP=0 | 예측 평균, bg, Q, 관측 가중치, 갱신 순서 |
| S3 ON / OFF | 동결된 역사 재가중 후보를 검증·교체 / 기존 foreground 체인 유지 | 동일한 원래 체크포인트·가용 이력·예방 규칙, P 주입 OFF |

S3 ON은 원래의 history·finite·PSD·변화량 검사를 모두 거친다. 기각은 실제 교체 효과 분석에서 NA로, 원래 정책의 시도 효과에서는 무처치로 기록한다. 두 분기의 상태기계에는 이번 결정 기회를 소비한 것으로 표시하고 20초 추적창에서 양쪽의 추가 복구를 막는다. 이후 일반 EKF 재귀와 상태 의존적 가중치는 각각 자연스럽게 전파한다. 이 규약은 단일 처치의 효과를 분리한다. 전체 정책 성능은 아래의 별도 전 구간 시험에서만 평가한다.

**실행 전 독립 코드감사.** 분기 직전 상태·이력·입력 해시 일치, 처치 직후 ON의 원래 자연 출력 재현, OFF에서 해당 처치 기여가 0인지 검사한다. S3 identity/cold parity, 원자적 교체, suffix 변경 시 과거 불변, pose ID 중복·누락·지연 거부를 재검산한다. 기존 float64 허용오차 atol=rtol=1e-10, mask와 ID는 완전 일치한다. 시간 경계에는 기존 수정 허용오차 1e-9초를 적용한다. 실패 시 해당 실행을 중단하고 원인 수정·새 SHA·재감사 뒤 재개한다.

## 3. R5 손익과 R4 재현 판정

- 각 쌍에서 ON−OFF의 10초·20초 Heading 절대오차 적분(°·s), XY 오차 적분(m·s), p95, 회복시간을 계산한다. 적분은 동일 timestamp의 사다리꼴 합을 쓴다. 주 지표는 20초 두 적분이다. 둘 다 감소하면 공동 이득, 둘 다 증가하면 공동 손해, 방향이 다르면 혼합, 수치 허용범위 안의 차이는 동률로 별도 표기한다. 허용범위는 지표 단위별 독립 identity 수치오차를 바탕으로 결과 열람 전에 동결한다.
- 원래 정확한 사건은 **정확 구간 이탈률·최초 이탈시각·재진입시간**을, 부정확한 사건은 **회복률·회복시간**을 분리한다. 회복은 두 정확도 기준을 연속 2초 만족할 때로 정의한다. 검열된 시간은 0 또는 20초로 대체하지 않는다. 20초 미만이면 해당 적분은 NA, 가용 길이 및 10초 완전성은 따로 기록한다. 실제 오차와 함께 NEES4·coverage·공분산 크기를 보고한다.
- 사건별 값과 seed별 요약을 모두 남긴다. 같은 seed의 반복 사건은 먼저 같은 층 안에서 요약하고 seed 단위로 쌍대 bootstrap한다(PCG64 20261103, 10,000회, 95% 구간). 유효 seed가 1개인 층은 구간을 추정하지 않는다. 작은 층은 N과 반례를 병기한다. 정확/부정확 층의 ON−OFF 차이는 효과 이질성의 기술 통계이며 정확도 자체의 인과효과로 해석하지 않는다.
- **R4 양성 대조:** 기존 개발 seed 0, Full, t=60초, B0/L2에 대해 원래의 등록 M 시험을 먼저 재현한다. C−A/D−B의 20초 적분 및 회복시간을 [원본 쌍대 비교](P0/BENEFIT.csv)와 수치 대조한다. 이는 baseline A의 공통 이력을 쓰는 원래 M 설계다. 자연 D 이력을 사용하는 새 사건 시험과 결과를 합치지 않는다. 공개 seed 10–29의 R4 Full 전 사건도 같은 분기 규약으로 분석해 이득·손해·기각 분포를 제시한다.

## 4. 발동 규칙이 R4 이득을 보존하는지 검증하는 후속 관문

단일 사건 시험에서 R5 손익을 구분할 근거가 없거나 R4에서 이득을 잃는 반례를 설명하지 못하면 여기서 종료한다. 후보가 있으면 개발 자료로만 하나의 공통 guard를 정하고 코드·특징·시점·계수·비교 arm을 별도로 동결한다. 경로명, seed, GT, Native-LoS oracle, 향후 관측은 guard 입력에서 제외한다. 현재 예방 할인 규칙은 고정한다.

1. **전 구간 비교.** 같은 seed의 A, B, C_CP, D_CP, C_CP_G, D_CP_G를 t=0부터 각자의 인과적 이력으로 재생한다. C_CP_G−C_CP 및 D_CP_G−D_CP가 guard 추가 효과다. B−A로 예방 단독의 R5 실패를 계속 표시한다. S2 주입은 별도 기전 대조로만 사용한다.
2. **R4 보존의 정량 기준 제안.** t≥30초, Full B0·L2 각각에서 지표 m의 seed별 이득을 ‘예방만 적용한 B의 RMSE − 결합 정책 RMSE’로 정의한다. Heading과 XY 각각에서 원래 D_CP의 이득 중앙값이 양수일 때, 새 D_CP_G가 그 이득의 **80% 이상**을 유지해야 한다. 같은 seed의 차이 ‘새 이득 − 0.8×원래 이득’의 중앙값과 쌍대 bootstrap 95% 하한이 모두 0 이상이어야 보존으로 판정한다. 원래 이득이 양수가 아니면 해당 지표 보존은 판정 불가다. C 계열도 A를 기준으로 같은 양식을 보고한다. ‘이득의 80% 보존’과 기존 ‘개선한 seed 비율 80%’는 별도로 보고한다. 기존 R4 Heading RMSE/A ≤0.90 목표도 독립적으로 검사한다.
3. **R5 및 Native-LoS 보호.** 원래 계약의 주 평가창, A 대비 Heading·XY RMSE의 쌍대 비율 중앙값 ≤1.05, p90 ≤1.20, near-zero 절대 여유 및 불확실성 기준을 그대로 적용한다. near·late·최악 seed의 악화를 함께 공개한다. R4 보존 또는 보호 관문 중 하나라도 실패하면 전체 채택은 NO-GO다.
4. **평가 분리.** 공개 seed 10–29에서 계산한 값은 재현·탐색 근거다. 새 공통 규칙의 확인에는 데이터 출처·미열람 상태를 기록한 별도 집합을 guard 동결 뒤 열어야 한다. 같은 RF의 새 센서 seed만으로는 환경 일반화를 주장할 수 없다. 별도 집합이 확보되지 않으면 확인 판정은 보류한다.

## 5. 실행 순서와 인계물

사건·분모·허용오차 동결 → 독립 코드감사 → R4 원래 M 재현 → R5/R4/Native-LoS 단일 사건 분기 → 독립 결과감사 → 공통 guard 연구 착수 여부 판정 순서로 진행한다. 새 guard 전 구간 시험은 앞 관문의 증거와 별도 동결이 필요하다. Incremental Shadow EKF와 5Hz 지연 최적화는 별도 연구로 둔다.

실행 인계물은 source/input/env 잠금, event registry, pair-start hash, ON/OFF packet trace, disposition/censoring, endpoint 표, seed별 추정치·구간, R4 보존·R5 보호 표, 실패 로그, 독립 감사 판정이다. 실제 성능 결과를 기록할 때 실행 SHA와 감사 SHA를 분리한다. 실행 전 제안이므로 현재 채택 NO-GO, 실시간 HOLD를 유지한다.
