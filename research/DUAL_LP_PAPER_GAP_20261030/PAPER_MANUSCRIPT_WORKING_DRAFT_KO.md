## 1. 이번에 선택할 데이터: 같은 복도·Mount 0°의 2×2 구성

**주 데이터는 R2·R5 × Anchor A·B의 네 사례로 선정한다.** 그 안에서 R5-A/B를 상세 설명의 대표 쌍으로, R2-A/B를 다른 경로에서도 양상이 반복되는지 확인하는 대응 쌍으로 쓴다. 모든 사례를 동등한 분량의 개별 실험 장으로 만들지 않는다.

| 역할 | 선정 case | 비교 관계 | 이 사례가 필요한 이유 |
|---|---|---|---|
| 대표 현상 | `R5_aA_m0` | R5-B와 같은 경로, 다른 앵커 | 기존 보정이 고정 수용집합과 자체 수용집합에서 크게 다른 결과를 내며, 잔차·공분산·시간구간 진단이 연결됨 |
| 대표 대조 | `R5_aB_m0` | R5-A와 같은 경로·장착각 | 같은 종류의 보정이 자체 gate에서도 기준 대비 이득을 유지한 조건. 무조건 관측을 덜 쓰면 된다는 설명의 보호 대조군 |
| 경로 반복 | `R2_aA_m0` | R5-A와 같은 Anchor A·장착각 | R5-A만의 큰 실패 사례를 일반화하지 않고, 다른 경로에서 같은 방향의 변화가 있는지 확인 |
| 교차 확인 | `R2_aB_m0` | R5-B와 같은 Anchor B·장착각 | A/B 차이를 R5 한 경로의 우연으로 설명하지 않도록 2×2 비교를 완성 |

**일관성은 ‘네 사례 모두 개선’이 아니라, 두 경로에서 같은 조건부 대비가 반복된다는 뜻이다.** 현재 관측된 대비는 A 계열에서는 자체 gate로 바뀔 때 악화가 커지고, B 계열에서는 일부 손실이 있어도 기존 기준선 대비 개선이 남는다는 것이다. 이는 현재 단일 센서·초기화 실현과 명시한 B0/L2 조건에서의 관찰이다. 앵커 위치만의 순수 인과효과 또는 모든 시드에서의 법칙은 아직 아니다. [S1, S2]

### 선정 범위

- 공간·안테나·관측기: 기존 C0 Corridor, 동일 FFD/SourceFFD 계열, TX +45°·RX ±45°, 동일 첫 경로 관측 정의, **Mount 0°**.
- 원자료: 위 네 case의 Full/Native-LoS H, pose/time, 기존 Sensor-v2 입력을 짝으로 유지. Full은 실제 문제, Native LoS는 물리 관측·정상 조건의 대조이다. 아래 수치표 자체는 **Full RF 결과만**이다.
- 조건: 본문은 **B0와 L2**를 대응시킨다. 중간 bias L0/L1은 보충 확인용으로 남기며 원본에서 제거하지 않는다.
- 모집단: 전체 주행을 사용한다. 재귀는 t=0부터, 주 점수는 기존 정의대로 t≥30 s. 오류가 큰 특정 구간만 잘라 전체 성능으로 제시하지 않는다.
- 분석 실행을 섞지 않는다. 수치표는 하나의 `D2_GATE_SCORES.csv`에서 추출한다. 과거 LUT J4 수치, 다른 μ/R 버전, 다른 시드 평균을 같은 표에 붙이지 않는다.

이는 문서상 데이터 선정이다. 원 H를 새로 복사·재생성하거나 모든 바이너리의 해시를 이번에 재검사한 것은 아니다. 선택한 근거 스냅샷과 실제 실행 source SHA는 구분한다.

## 2. 왜 이 네 사례인가: 이미 확인되는 반복 양상

선정의 출발점은 아래의 **같은 실행 계열** 비교다. 최종 방법의 성능표가 아니라, 다음 분석에서 설명할 현상을 정하기 위한 표이다.

`BB_ORIG`는 해당 진단의 기존 보정 기준선이며 **고정 R0의 Conventional J4와 동일하지 않다.** `MB_VAR`는 과거 연구의 평균·분산 변경 arm으로, 이번 논문의 M2로 채택한 것이 아니다. `fixed`는 BASE 수용집합을 공유한 진단, `self`는 각 필터의 자체 NIS gate를 쓰는 재귀 실행이다. 두 경우 모두 상태가 재귀적으로 전달되지만, fixed-mask 결과를 배포 성능으로 부르지 않는다. [S1, S2]

| Case | Bias | BB_ORIG Heading (°) | MB_VAR fixed Heading (°) | MB_VAR self Heading (°) | XY: BB_ORIG → MB_VAR self (cm) |
|---|---|---:|---:|---:|---:|
| R2-A m0 | B0 | 1.844 | 1.636 | 1.927 | 16.76 → 17.18 |
| R2-A m0 | L2 | 1.571 | 1.389 | 2.131 | 17.32 → 18.53 |
| R5-A m0 | B0 | 4.353 | 3.833 | 8.886 | 45.30 → 87.75 |
| R5-A m0 | L2 | 4.681 | 4.744 | 9.779 | 47.48 → 91.26 |
| R2-B m0 | B0 | 1.205 | 1.077 | 1.085 | 6.83 → 5.33 |
| R2-B m0 | L2 | 0.947 | 0.793 | 0.813 | 5.77 → 4.30 |
| R5-B m0 | B0 | 1.073 | 0.540 | 0.643 | 8.69 → 4.46 |
| R5-B m0 | L2 | 0.716 | 0.527 | 0.615 | 6.09 → 4.65 |

**出典 / 출처:** [S1] 원 CSV의 `case`, `bias`, `arm`, `gate`로 선택하고 `head_rmse`, `xy_rmse_cm`를 반올림해 옮겼다. 시드 평균이나 새 필터 계산이 아니다. 원 CSV의 Git blob은 `efe55ff9b13b6c6c70f2820e26bacc88ca460d26`이다.

이 표에서 사용할 수 있는 설명의 출발점은 다음과 같다. **같은 종류의 평균·분산 변경이라도, 관측을 수용하는 이력과 이후 prior가 달라지면 이득이 유지되는 기하 조건과 무너지는 기하 조건이 구분된다.** 특히 R5-A L2는 fixed에서도 Heading이 4.681°에서 4.744°로 소폭 악화하므로 ‘고정 gate에서는 언제나 성공했다’고 서술하지 않는다.

이것을 곧바로 ‘시간상관이 원인’ 또는 ‘Gate만 고치면 해결’로 결론내리지 않는다. Gate 변화는 수용 표본, 미래 상태·공분산·Jacobian도 바꾼다. **시간·공간 잔차 구조와 유효 정보량이 이 차이를 얼마나 설명하는지**가 다음 분석의 핵심이다.

## 3. 선택한 사례에서 갈무리할 데이터는 네 묶음으로 제한

실험 이름별로 원고를 늘리지 않고, 같은 네 사례의 아래 자료만 연결한다.

| 데이터 묶음 | 남길 데이터 | 논문에서 답할 질문 | 기존 위치 |
|---|---|---|---|
| P1. 물리 관측 | paired Full/LoS H, pose/time, r·s, SourceFFD h·Heading Jacobian | Dual-LP 정보가 존재하고 어떤 관측오차가 생기는가? | [S5], [S6] |
| P2. 공간적 잔차 | signed εr·εs, 평균·중심분산·동시 r/s 상관, 거리·상대방위·tap | 같은 보정이 왜 위치·경로에 따라 다른 입력을 만드는가? | [S2]의 `D3_EPS_BY_DISTANCE.csv`, `D3_DECOMPOSITION.csv` 및 해당 원 trace |
| P3. 시간순 이용 | 순서가 보존된 잔차, gate 전 innovation/NIS, accepted mask, prior/posterior P·오차 | 연속 관측을 어떻게 받아들이고 누적할 때 신뢰성이 깨지는가? | [S1], [S2]의 `D2_GATE_FLIPS.csv`, `D3_EPS_TEMPORAL.csv`, `D3_R5A_WINDOWS.csv` |
| P4. 결과·반례 | 같은 시행의 Heading·XY·bias 오차, NEES/coverage; 기존 개입과 시드 결과 | 설명이 반복되는가, 어디서 성립하지 않는가? | [S1], [S3] |

각 묶음은 동일 case/pose/time과 모델 정의로 연결한다. 진단 파일에 요약 통계만 있고 packet-level 필드가 없으면, 보존된 원 trace에서의 대응 확인을 다음 작업으로 표시한다. 요약표를 원시 시계열인 것처럼 취급하지 않는다.

원자료의 `raw r/s`, `GT 기준 RF 잔차`, `평균보정 후 잔차`, `prior innovation`은 별도 변수로 유지한다. 같은 이름의 `BASE`, `MB_VAR`도 실행 버전과 μ/R 정의가 다르면 자동으로 합치지 않는다. [S2, S3]

## 4. 예외는 한계와 원인 분석으로 남긴다

본문의 상세 시계열은 네 사례에 집중하되, 아래 사례는 결론의 적용 범위를 제한하는 근거다. 특히 주 가설을 반박하는 결과는 단순 부록으로 숨기지 않고 본문의 Limitation에서 명시한다.

| 사례 | 배치 | 이미 있는 근거와 원인 해석의 경계 |
|---|---|---|
| **R4-B m0** | 핵심 경계 사례 | B0에서 BB_ORIG 대비 MB_VAR self의 Heading은 1.442°→1.431°로 거의 같지만 XY는 8.54→9.43 cm로 악화한다. 같은 fixed 비교에서 BB_VAR의 XY 7.31 cm에 평균변경을 결합한 MB_VAR는 8.87 cm이다. 평균·분산 결합이 위치 이득을 상쇄하는 양상은 보이지만 유일한 물리 원인은 미확정이다. [S1] |
| **R4-B m0의 순서 교란 반례** | 3-D의 일반화 경계와 연결 | 수정된 E4 판정에서 R5-A MB_VAR는 10개 시드 중 9개가 기준 1–3을 함께 충족했지만 R4-B는 0개였다. 이는 해당 semi-synthetic 대조의 조건부 지지/반례이며, ‘상관이 없다’는 결론이 아니다. [S3] |
| **R5-B의 초기상태 변화** | 주 사례 자체의 강건성 한계 | 주 데이터에서 개선된 R5-B도 초기상태를 바꾸면 큰 오차가 생긴 기록이 있다. 사후 선택된 초기화 시드 0/3/8/9의 교차 실험을 별도로 유지한다. 위치와 Heading 초기오차가 함께 바뀌므로 Heading 초기오차 단독 원인으로 단정하지 않는다. [S3] |
| **R2-A m45** | 장착각 변경에 대한 외삽 경계 | Mount를 바꾸면 민감도와 포트 전력 분배도 바뀐다. m0에서 얻은 설명을 m45까지 확장하지 않는다. 필요 시 동일 R2-A의 paired mount 대조 하나만 제시하고, mount 연구 전체를 본문에 추가하지 않는다. [S6] |
| **R4-A m0** | 보충 검토·전체 선택 원장 | 본문 상세 그림에서는 제외한다. R4-B의 반례가 R4 전체를 대표하는지 점검할 때 함께 사용하며, 성능이 나쁘다는 이유로 원자료를 폐기하지 않는다. [S1, S2] |

**복원 자료 상태 정정:** R4/R5 × A/B의 Mount 45° 과거 H 원본 4개는 2026-11-01에 회수되어 GitHub에 게시됐다. 따라서 이제 ‘원본이 없다’고 쓰지 않는다. 다만 그 전달 검증은 바이트 동일성·배열 구조이며 C0 물리 재구성·관측/필터 parity의 최종 승인은 아니다. 이번 선정에서는 **설명 축을 m0로 고정하기 때문에 확장 후보로 보류**한다. [S7]

## 5. 현재 제외하거나 압축하는 내용

| 내용 | 이번 논문에서의 처리 |
|---|---|
| Office·새 장면·합성 GP/OU/echo 실험 | 현재 네 사례의 동일 RF 계열 설명에 섞지 않는다. 필요성이 입증될 때 별도 검증으로만 추가 |
| G0–G5 전체 특징량, 모든 회귀기·bias-state·window 변형 | 방법별 나열 삭제. 선택 사례의 핵심 설명을 구분하는 대조만 후속 선정 |
| 초기 LUT 결함·pole·코드 수리 연혁·감사 실행 과정 | 데이터 신뢰성 근거로 연결하되 본문 기여로 길게 전개하지 않음 |
| 모든 경로의 모든 조건별 시간 그래프 | R5-A/B 상세 + R2-A/B 대응 요약으로 압축. 원본 결과는 보존 |
| 독립 holdout 주장 | 선택은 이미 본 데이터에 기초한 탐색적 사례선정이다. 이를 사전등록·독립 확인 시험으로 다시 부르지 않음 |
| ≥3-anchor 결과와 최종 M2 | 요구된 최종 비교군으로 유지하되, 지금의 데이터 선정 단계에서 신규 RF·모델을 구현하지 않음 |

전체 C0의 기존 7개 case를 없애는 것이 아니다. **4개는 주 설명, R4-B·R2-A45는 명시적 경계, R4-A는 보충 검토**로 읽는 순서를 바꾼다. 최종 방법의 성능을 주장할 때는 선택한 상세 사례와 전체 평가 모집단을 구별하고, 사용한 전체 평가 case의 간단한 결과표를 함께 남긴다. 현재의 네 사례만으로 전체 성공률을 계산하지 않는다.

| **2. Dual-LP Concept** | 같은 사례의 Native LoS 및 SourceFFD h/J | 단일 앵커 편파비의 Heading 민감도와 위치 의존성을 보여주는 대표 그림 하나 |

R5의 A/B 쌍으로 대표 현상을 상세히 제시하고 R2의 A/B 쌍으로 다른 경로에서의 반복 양상을 확인한다. 각 사례의 Full RF와 Native LoS를 대응시키며, 전체 주행을 유지한 채 기존 t≥30 s 구간에서 상태추정 오차를 평가한다. 이 네 사례는 한 장면의 조건부 비교이지 네 개의 독립 환경은 아니다.

## 7. 다음 단계의 질문만 남기고 모델은 결정하지 않는다

선정한 자료에서 다음 세 가지를 확인한 뒤 설명과 모델을 확정한다.

1. **공간적 공통성:** R2/R5의 A에서 반복되는 악화가 거리·상대방위·tap/잔차 구조 중 무엇과 연결되는가? 같은 경로의 B는 무엇이 다른가? 앵커 이름만으로 원인을 분류하지 않는다.
2. **시간순 정보 이용:** 같은 순간 분산으로는 설명되지 않는 지속성·정보 중복이 있는가? 관측 순서·수용집합·미래 prior의 효과를 구분하고, 단순 자기상관을 실제 상태별 정보량으로 대체하지 않는다.
3. **경계 설명:** 같은 설명이 R4-B와 R5-B 초기화에도 성립하는가? 성립하지 않으면 다른 원인이 확인된 범위와 미설명 부분을 구분한다.

현재 표는 이 질문을 설정하는 근거이다. 이미 분석한 결과를 더 유리하게 만들기 위해 case·시드·시간 구간을 다시 고르는 절차가 아니다. 다음 모델을 정한 뒤에는 이 선정 집합을 결과에 따라 교체하지 않고, 추가/제외가 필요하면 이유와 영향을 기록한다. R5-A 60–120 s는 사후 진단창으로만 활용하고 전체 궤적 성능을 대체하지 않는다. [S2]
