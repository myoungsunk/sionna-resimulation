# 그림 설계 — 직접경로·다중경로·모델 효과

연결: [[01 초안 - 한글]] · [[01b 본문 초안 - 물리 관측·모델·결과]] · [[00 GitHub 근거 - 수치와 적용 경계]] · [[00 그림 1 - LOS 방위각 편파 응답 근거]]

## 1. 목표: 성능 개선표에서 물리–관측–갱신–성능의 연결로

필요한 흐름은 **직접경로에서 편파가 제공하는 방향 응답 → 다중경로에서 관측이 달라지는 양상 → 관측 특성에 대응하는 모델 개입 → 실제 추정 성능과 실패 조건**이다.

“극적 효과”는 같은 입력·구간에서 물리량, 잔차, 갱신, 오차의 연결을 한눈에 보이게 하는 것을 목표로 한다. 성공 경로 R2-B·R5-B와 한계 경로 R4-B를 함께 유지한다.

> [!important] 물리적 민감도와 추정 성능을 구분한다
> 현재 모델은 안테나·채널·직접경로 관측함수 $h$를 바꾸지 않는다. 같은 pose에서 $h_s$, 물리 Jacobian $H_{s\psi}$와 원시 포트 전력이 모델 적용으로 좋아졌다고 그리면 안 된다.
> 개입은 **거리 평균 교체**와 **편파 추가분산**이다. 분산만 추가하면 같은 pose·평균의 원시 편파 잔차와 자기상관은 그대로이며, $R$, gain, 정규화 잔차, 재귀 상태와 오차가 변한다.

“다중경로 영향 받기 전”은 **동일 기하의 직접경로만 남긴 채널 기준**으로 정의한다. 주행 중 특정 시점부터 반사가 켜지는 실험을 뜻하지 않는다. LoS 경로가 존재하는 Full 채널에도 다중경로가 함께 있을 수 있으므로 범례에는 **LoS-only / Full**을 사용한다.

## 2. 본문 순서와 목표 그림

F번호는 준비용 ID다. 본문 그림 번호는 아직 부여하지 않는다.

| ID / 배치 | 보여줄 변화 | 필요한 패널·지표 | 현재 준비 상태 |
|---|---|---|---|
| F0 / 대표 그림 | 직접경로 기준 → Full 악화 → Full 모델 적용 | 같은 주행의 $s^{LoS},s^{Full}$, $\epsilon_s$, Heading·XY 오차, RMSE | **설계 완료, 일치 원시자료 미확보**. 서로 다른 요약표로 3단계 성능을 합성하지 않음 |
| F1 / 물리 관측 도입 | 방위각에 따른 포트 분담과 signed 편파 응답 | $\psi$ 대 $P_\pm/(P_++P_-)$, $s$; 민감도 곡선은 branch 검증 후 | 기존 그림 1 사용 가능. 앵커 바로 아래 고정 위치·입사각 0° |

### F0: 대표 그림의 구체적인 구성

**열:** 동일 경로의 LoS-only+BB_ORIG / Full+BB_ORIG / Full+MB_VAR.  
**행:** (a) 공통 시간축의 $s$와 직접경로 예측, (b) 관측 잔차, (c) Heading 오차, (d) XY 오차. 전체 평가구간 RMSE는 옆 표에 제시한다.

Full에서의 단독 평균·분산 개입은 F6의 2×2 대조로 분리한다. 대표 그림에 한 경로를 쓰더라도 R2/R4/R5 전체를 같은 형식으로 제공한다. 대표 구간은 최대 오차를 사후 선택하지 않고 기하·회전·평가시간 등 명시적인 기준으로 고른다.

1. **채널 영향:** LoS-only와 Full에서 같은 궤적·센서 입력·초기화·검출기를 사용한 관측과 재귀 성능이 필요하다.
2. **모델 효과:** 동일 Full 관측에 BB_ORIG/MB_ORIG/BB_VAR/MB_VAR를 적용한 결과가 필요하다.
3. **편파 사용의 손익:** “다중경로에서 편파 이용 자체가 시스템을 악화시킨다”고 쓰려면 동일 Full 조건의 **거리만 이용한 기준선**도 필요하다. 현재 네 arm은 모두 편파를 사용하므로 이 주장을 직접 검증하지 않는다.

LoS-only+MB_VAR는 직접경로에서 추가분산을 부여하는 영향까지 확인하려는 확장 비교다. 이번 준비에서 새 실행은 하지 않았다. 기존 정상입사 그림 1은 주행 성능의 LoS-only 기준선을 대신하지 않는다.

### F2·F5: 시간·거리와 물리량·성능을 연결하는 그림

동일 packet ID로 정렬한 다음을 한 시간축에 배치한다.

| 행 | 변수·지표 | 해석 |
|---|---|---|
| 1 | $\rho^{GT}(t)$, 입사각, 상대 방위각, 로봇 Heading | 오프라인 기하 설명; 실제 lookup 거리와 구분 |
| 2 | $s^{LoS},s^{Full},\Delta s$, 두 포트 전력, 검출 tap | 차등 응답·중첩·검출 선택의 변화 |
| 3 | $H_{s\psi}^{GT}$와 $H_{s\psi}^{prior}$, branch 안정 여부 | 물리 구조와 실제 선형화 위치 구분; 큰 미분을 정보량으로 동일시하지 않음 |
| 4 | $\epsilon_r,\epsilon_s,\delta h_s,\nu_s$ | $\nu=\epsilon+\delta h$의 오차 성분 |
| 5 | $\hat\mu_r$, $\rho_{\rm lookup}$, 기준·추가 $R_{ss}$, signed $K\epsilon,K\delta h$ | 모델 작용; lookup은 원 구현의 motion prediction 직전 posterior 기준 |
| 6 | Heading·XY 오차, gate 수용 여부 | 재귀 결과와 탈락 packet 위치 |

거리축에서는 공통 bin별 median/IQR 또는 RMS·평균·표준편차와 $n$을 표시한다. **현재 그림 A는 그 목표의 일부**다. 비슷한 거리라도 상대 방위각·tap이 다르므로 거리만으로 원인을 확정하지 않는다.

$K\epsilon$과 $K\delta h$는 상쇄할 수 있다. gain 감소나 한 항의 절댓값 감소를 매 packet의 오차 개선으로 읽지 않는다. 동일-prior 국소 효과와 서로 다른 prior를 따라가는 최종 재귀 성능도 구분한다.

### A — 거리별 관측 잔차와 분산 규모

![[03_Research/EKF/2026-11-01 논문 초안/figures/observation_model_figures_20261102/plots/A_distance_residuals.png|850]]

**캡션 초안.** B0, $t\ge30$ s의 유한 관측 전체를 true horizontal distance 구간으로 묶은 진단. 위 행은 기준 평균 BB와 교체 평균 MB의 거리 잔차 RMS, 아래 행은 편파 잔차 RMS와 분산의 제곱근 규모다. 동일 행의 세 경로는 공통 세로축을 사용한다. 가로축은 폭이 다른 bin을 등간격으로 배치한 범주축이며 선은 구간 간 연결 안내다. 구간별 $n$은 동반 CSV에 제공한다.

D3 자료는 **gate 비선택**으로, 01b 표 1의 BASE-accepted 수치와 분모가 다르다. 아래 추가분산 곡선은 원 진단 코드가 **true distance**에서 계산한 값이다. 실제 필터의 $\rho_{\rm lookup}$ 및 $R_{\rm used}$ 기록으로 제시하지 않는다. 편파 원시 잔차는 평균 교체에서 그대로이므로 BB/MB 개선 곡선으로 중복하지 않았다.

R4의 일부 bin에서는 잔차 RMS가 기준 분산 규모를 넘지만 다른 bin에서는 반대다. “모든 거리에서 과신”으로 일반화하지 않는다. RMS와 centered 표준편차도 구분한다.

### 정렬·표본 조건

- scene/route/anchor/mount/seed/packet ID와 원 timestamp로 연결한다. 반올림 시간이나 거리값만으로 join하지 않는다.
- LoS-only/Full 비교는 동일 기하·입력·검출기를 사용하고 tap 변경을 표시한다.
- 민감도는 GT/prior 평가 위치와 branch 안정성을 따로 기록한다. 전환점에서 미분 곡선을 구분한다.
- full-time / $t\ge30$ s / fixed accepted / self accepted / all candidates를 명시한다. 최종 RMSE는 원 정의의 전체 평가시점 기준이다.
- 기존 896구간의 signed 갱신은 full-time fixed-accepted, local loss는 $t\ge30$ 전체후보로 **544구간의 분모가 다르다**. 동일 표본의 원인–결과로 그리지 않는다. 보완 384공통표본은 문서 보고가 있으나 이번에 원 표를 확보하지 않았다.
