## 1. 현재 관측을 추가하는 것과 기본 융합에서 제거하는 것은 언제 같은가?

동일 prior x-,P-와 동일 full-update 후보 xF,PF에서 보정 d=xF-x-, D=P--PF를 정의한다. 각도는 원형으로 처리한다.

- 추가: x=x-+alpha*d, P=P--alpha*D.
- 제거/약화: x=xF-(1-alpha)*d, P=PF+(1-alpha)*D.

같은 alpha를 선택하면 같은 상태와 공분산이다. 이진 수용 a와 제거 r=1-a도 동치다. 따라서 표현만 바꾸는 것은 새 추정 알고리즘이 아니다.

차이는 (1) prior가 어떤 RF 수용 이력으로 만들어졌는지, (2) 위험 증거가 애매할 때 기본값이 무엇인지, (3) 현재 관측만 생략하는지 과거 RF 영향을 복구하려는지다. 현재 관측을 거부해도 이전 RF로 바뀐 위치·헤딩·바이어스·공분산은 원복되지 않는다. 이미 융합된 현재 평균만 되돌리면서 PF를 유지하는 것은 잘못된 조합이다. 과거 RF 영향의 제거는 체크포인트 이후 X/P 재생 또는 다른 복원 설계가 필요하며 C/D에서 다룬다.

'운동 우선'도 한 번 RF 보정을 수용한 후에는 그 보정된 상태에서 다음 운동 예측을 수행한다. 매 시점 순수 DR로 초기화한다는 뜻은 아니다. 이번 pure-DR와 S4 donor는 두 종류의 이력을 비교하는 진단용이다.

## 4. B단계: 손실 위험 판정기 비교

### 동결 조건

- fit: 40<=t<100, baseline S4/DR 2종 x 4수준 = 2,400행 / 300개 물리 프레임.
- calibration: 100<=t<120, 같은 donor = 800행 / 100개 물리 프레임.
- gap: 120<=t<140.
- diagnostic test: t>=140, 16 donor = 4,464행 / 279개 물리 프레임.
- 같은 k의 모든 정책·수준은 같은 분할. Oracle/learned donor는 학습·calibration에 사용하지 않음.
- 참값·실제 오차·Full-LoS·oracle 수용 mask·prior ID·bias level·절대 시간/프레임·절대 x/y는 입력 금지.
- 전체 R2가 이미 공개됐으므로 독립 맹검 또는 새 환경 일반화 시험이 아님.

모델은 동일한 작은 랜덤포레스트(64 trees, max_depth=4, min_leaf=40) 계열이다. Heading/XY 제곱오차 순이득과 두 큰 손실 사건을 학습했다. 큰 손실 진단 기준은 절대 Heading 오차 +0.5deg, 절대 XY 오차 +0.01m다. 이는 안전성 기준이 아니다. 9개 risk-score cutoff 중 calibration 제약을 만족하는 것을 선택했고, test 결과를 보고 변경하지 않았다. score는 보정된 확률을 보장하지 않는다.

- M0: 기존 단일 임계값 설계를 fit 구간에서 다시 학습. 이전 40–120 학습 규칙과 다른 규칙이므로 구분한다.
- M1: 기존 크기 중심 특징 12개.
- M2: 부호 있는 보정·DR 차이·몸체좌표·상호작용 포함 28개.
- M3: 운동·바이어스·교차공분산·모델상 정보 변화·과거 이력 포함 43개.

M2/M3와 M1의 비교는 특징 묶음 비교이며 부호 하나의 독립 인과 대조가 아니다. 이번 판정 출력은 거부/전량이며 다중 alpha의 온라인 선택과 재귀 전파는 C에서 다룬다.

### S4/learned/oracle prior의 의미

M2/M3는 S4 prior의 후반 4조건에서 gate 통과 후보 271개를 모두 수용했다. 즉 이 구간의 새로운 선택 이득은 기존 gate 대비 없었다. learned donor에서는 일부 즉시 이득이 있지만 해당 정책을 다시 재귀 실행한 것이 아니다. Heading Oracle prior에서는 M2/M3 모두 조건별 Heading 순이득 합이 음수였다. 현재처럼 잘 추적된 상태를 보호하는 판별까지 달성했다고 할 수 없다.

### 추가 감사: calibration의 이득 쏠림과 지원 없는 상태

`verification/calibration_by_prior.csv`로 분해했다. M2 calibration의 Heading 제곱오차 순이득 중 98.05%는 L2/DR에서, M3에서는 95.56%가 L2/DR에서 발생했다. B0/DR와 L0/DR의 calibration 수용수는 두 모델 모두 0이었다. 그럼에도 M2는 test에서 B0/DR 13개, L0/DR 21개를 수용하여 모두 큰 손실을 만들었다.

따라서 pooled calibration 통과는 모든 상태 영역의 안전성을 검증하지 않는다. 단일 전체 점수 대신 조건별/블록별 위험과 보정 필요성을 보존하는 정규화 목적, calibration 지원이 없는 영역의 신뢰 제한을 검토할 근거가 있다. 이번 결과를 본 뒤 threshold를 변경하거나 재학습하지 않았다. 실제 상태의 오류 수준을 bias level 라벨로 온라인 제공해서는 안 된다.

## 6. 결론과 다음 단계

A/B는 실제 원본 NPZ로 완료했다. 양의 신호는 prior에 따라 보정 유형과 필요 강도가 달라진다는 것, 일부 prior에서 추가 특징이 관측 손익을 더 잘 구분한다는 것이다. 그러나 고정된 한 판정기로 DR 보호와 drift 보정을 동시에 달성한 것은 아니다. 모델 최종 채택은 보류한다.

C에서는 이 결과를 고정한 채 자기 X/P에서 정확 LUT를 재평가하는 폐루프와 binary/soft 행동공간을 비교한다. D에서는 10/20초 지연 손익, 자이로 bias 영향, 공분산, 예방/회복 및 별도 데이터 일반화를 분리한다. 이번 턴에는 C/D를 실행하지 않았다.

현재 질문의 답은 '더하기가 본질적으로 낫다'가 아니다. **같은 prior와 선택이면 추가/제거는 동치이고, 실제 성능 차이는 prior의 RF 이력과 조건부 손실 위험의 판단에서 나온다.**
