# G1-CHAR-002 heading 조건부 특성 학습(TEACH/REPEAT) → R2/R4/R5 궤적 평가 사양 (2026-11-15)

상태: DIAGNOSTIC_ONLY, mount 0 기준. S2′ STOP, Step 3 보류, G-T2/G-V 봉인을 유지한다. 실행 전 커밋한다.

## 0. 목적

사용자 지시에 따라 진행 순서를 바꾼다.

1. **학습.** heading 방향을 축으로 세 가지를 TEACH/REPEAT 주행 데이터로 학습한다.
   - S: LoS 편파비와 그 heading 민감도
   - 편파의 다중경로 영향 e_s
   - ranging의 다중경로 영향 e_r
2. **평가.** 학습한 모형이 다른 궤적(R2/R4/R5)에서 얼마나 맞는지 궤적별로 비교한다.

이는 TEACH/REPEAT로 현장 데이터를 쌓고, 이후 임의 궤적을 주행하는 운용 구조와 같다.

## 1. 데이터 분할

| 역할 | 데이터 | 비고 |
|---|---|---|
| 학습 | 새 RT G-T1 A/B/C의 P-A_TEACH ∪ P-A_REPEAT (station 18개, yaw 0±60° sweep) | REPEAT는 TEACH와 거의 같은 실현값이다(ρ≥0.99). 학습 표본으로 함께 쓰되 독립 표본 수로 세지 않는다 |
| 평가 1 (같은 장면, 다른 궤적) | G-T1 A/B/C의 P-A_PRIME, P-B, C1–C4 | 궤적 일반화만 본다 |
| 평가 2 (다른 장면, 다른 궤적) | BLOCK_C R2/R4/R5 × 앵커 A/B, mount 0 | 장면도 다르다. 복도 폭 2.4 m(G-T1은 1.94 m), 앵커 x=4/10(G-T1은 3/7/9.8), 높이 2.65 m 동일, 재질 동일 |

P-D, P-E, G-T2, G-V는 쓰지 않는다. 오차 정의는 G1-CHAR-001 §2와 같다(e_s, e_r=r_full−r_LoS, e_r^abs, g_ψ).

## 2. 조건 변수 (상태에서 계산 가능한 것만)

- **ψ_f** = (body yaw − 로봇→앵커 bearing) mod 180°, 15° 구간 12개. LP 안테나는 180° 회전에 대해 대칭이므로 접어서 쓴다. 이 가정은 학습 데이터에서 ψ와 ψ+180°의 g_ψ를 비교해 보고한다.
- **d**: 앵커 거리. 앙각은 높이가 고정이라 d로 정해진다.
- 학습 지지 범위 밖의 평가 표본은 **외삽**으로 따로 집계한다. 기준은 d > 학습 최대 d, 또는 학습 표본 30개 미만인 ψ_f 구간이다.

## 3. 학습할 표현

### 3.1 S (LoS 편파비)

- 학습 데이터에서 ψ_f별 |g_ψ| 중앙값과 s_LoS 범위를 보고한다.
- LoS 모형 자체는 동결 FFD bank(los_h)이며 학습하지 않는다. parity만 확인한다.

### 3.2 e_s

| 표현 | 형태 | Goal 경계 |
|---|---|---|
| S0 | Gaussian, σ 상수 | 1 |
| S1 | Gaussian, σ(d)=a·d^k | 1 (MB_VAR) |
| S2 | Gaussian, σ(ψ_f, d)=a_b(ψ_f)·d^k | 1 |
| S3 | Student-t, scale(ψ_f, d), ν 공통 | 1 |
| S4 | S3 + 평균 μ(ψ_f) | **2 후보** (heading 조건부 s 편향 보정). 비교용으로만 둔다 |

### 3.3 e_r^abs

| 표현 | 형태 |
|---|---|
| R0 | Gaussian 상수 |
| R1 | Gaussian μ(d), σ(d) |
| R2 | Gaussian μ(ψ_f, d), σ(ψ_f, d) |
| R3 | Student-t scale(ψ_f, d), μ(ψ_f, d) |

ranging 평균 보정은 Goal 1 허용이다.

공통 적합 방식은 다음과 같다.

- 학습 표본으로 최대우도 적합한다.
- ψ_f 구간 모수는 학습 표본 30개 미만이면 전체 공통값으로 대체한다.
- 결과를 본 뒤 재적합하거나 구간을 바꾸지 않는다.

## 4. 평가 지표 (궤적 × 앵커별)

1. **95% 예측구간 coverage.** 전체, ψ_f 구간별, d 구간별(<4, 4–8, ≥8 m)로 본다. 상·하단 이탈률을 따로 보고한다.
2. **PIT KS 거리, 평균 log predictive density.**
3. **heading 영역 integrity.**
   - 예측 heading 표준편차 σ_ψ = scale_s/|g_ψ|를 쓴다.
   - 실제 |e_ψ^eq|가 95% 구간 안에 드는 비율을 본다.
   - 예측 σ_ψ의 중앙값과 실제 |e_ψ^eq|의 중앙값도 함께 보고한다.
4. **외삽 표본과 지지 범위 내 표본을 분리**해서 보고한다.
5. **기준선과의 비교.** 같은 궤적에 대해 평가 데이터 자체로 적합한 S1/R1(oracle)을 함께 보고한다. 학습-평가 이전 손실을 보기 위해서이며, 판정에는 쓰지 않는다.

이 단계는 packet 단위 calibration이다. EKF 재실행(궤적별 NEES, heading RMSE)은 결과를 본 뒤 2단계로 사양을 따로 쓴다. 2단계에서는 BLOCK_C 원 EKF 코드(SourceFFD/W0)와 B0 입력이 필요하다.

## 5. 해석 규칙 (사전 등록)

- **heading 조건이 필요한 경우.** S2/S3가 S1보다 평가 1과 평가 2 모두에서 coverage 오차(|coverage−0.95|)를 줄이면, heading 조건부 표현이 필요하다고 본다.
- **장면 이전 실패.** 평가 1에서는 맞고 평가 2에서만 실패하면, 장면 이전 실패로 기록한다. 그러면 TEACH/REPEAT 학습은 같은 장면 안에서만 유효하다.
- **heading 조건부 편향.** S4가 S3보다 평가 2에서 크게 나으면(coverage 오차 절반 이하), heading 조건부 편향이 장면을 넘어 이전된다는 뜻이다. Goal 2 후보로 기록한다.
- **외삽 영역 실패.** 외삽 표본에서만 실패하면 TEACH 경로 설계(yaw 범위, 거리 범위)의 한계로 기록한다.
