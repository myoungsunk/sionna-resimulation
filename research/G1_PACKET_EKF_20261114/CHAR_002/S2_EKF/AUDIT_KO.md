# G1-CHAR-002 S2 결과·코드 감사 (2026-11-15)

대상은 `c7f0cf7`(S2 EKF 실행)이다. trace 54개를 LFS에서 받아 다시 분석했고, 코드 `run_s2.py`, `replay_s2.py`, `metrics_s2.py`를 읽었다. 이 문서는 감사 기록이며 새 판정을 내리지 않는다.

## 1. 결론 요약

1. **구현은 사양대로 동작했다.** prior 기반 조건 변수, 평가 truth를 나중에 여는 순서, E0 parity, 지표 정의(Pose95 χ²₃ 0.95, heading ±1.96σ)를 확인했다. 결과를 뒤집을 구현 오류는 찾지 못했다.
2. **E3, E4, E5 실패의 직접 원인은 사양 결함이다(작성자: Claude).**
   - (a) **Student-t 재가중이 R을 줄이는 방향으로도 작동한다.** w=(ν+1)/(ν+ν²/S)는 혁신이 작으면 1보다 커서 R_ss가 줄어든다. 또 출발값이 분산이 아니라 scale²이다. 그 결과 E3의 √R_ss 중앙값은 0.050–0.081로, E2(0.114–0.136)의 약 40–60%다.
   - (b) **E4는 이동 거리가 2 cm를 넘으면 상관을 끊었다.** 이는 기존 측정과 맞지 않는다. 시간 상관 1/e 길이가 0.4–3.6 s이고, 이는 0.2 m/s에서 8–72 cm에 해당한다. 재방문 10 cm에서도 ρ가 0.47–0.88이었다.
   - (c) **어느 arm도 시간 상관에 따른 정보 중복을 반영하지 않는다.** 정규화 혁신의 lag-1 자기상관이 s에서 0.75–0.93, 거리에서 0.3–0.65다. 독립 관측으로 가정하면 공분산이 과소해진다.
3. **E5(평가 궤적 참값으로 다시 맞춘 모형)가 가장 나쁘다.** 이것이 2-(c)의 직접 증거다. 주변분포를 정확히 맞출수록 √R이 작아지고(s 0.036–0.079), 상관을 무시한 정보 과다가 더 커진다. 따라서 "학습 모형이 틀려서" 실패한 것이 아니라 **"독립 관측 가정"** 때문에 실패한 것이다.
4. **E0가 가장 좋은 이유는 세 가지다.** 이 중 둘은 공정 비교를 깨고, 하나는 Goal 1 경계를 넘는다.
   - **in-sample 팽창.** E0의 R은 실제 RF 잔차보다 크게 잡혀 있다(기존 진단: ε²/R 0.11–0.68). 거리 의존 σ_b hand table과 VAR 형태는 같은 R2/R4/R5에서 고른 in-sample 선택이다. 10 m에서 hand table 0.24는 잔차 적합값 0.109(LORO 0.048–0.140)의 약 2배다. 이 팽창이 시간 상관에 따른 정보 중복을 우연히 상쇄한다.
   - **같은 복도 학습.** μ_B, μ_M, R은 같은 corridor 안에서 경로 제외(LORO)로 학습했다. 경로는 다르지만 장면은 같다.
   - **편파 평균 보정 μ_M 포함.** E0의 s 평균 보정 중앙값은 0.006–0.024이고, R4의 q95는 0.071이다. 이는 사용자가 정한 Goal 2 항목(s 평균 편향 보정)에 해당한다. E1–E5에는 넣지 않았다.
5. **E1이 E0보다 Pose95가 낮은 주원인은 heading이 아니라 거리다.**
   - E1의 heading 95% coverage(85.3%)는 E0(87.1%)와 비슷하다.
   - 거리 정규화 혁신 분산은 E1이 0.44–0.64, E0가 0.14–0.26이다.
   - E0의 거리 평균은 채널 특징(EXDS) 기반 ranging 보정이며, Goal 1에서 허용된다.

## 3. 코드 확인 사항

| 항목 | 확인 결과 |
|---|---|
| 조건 변수 | `geometry()`가 prior 상태로 거리와 (yaw − atan2(anchor−robot)) mod 180을 계산한다. CHAR-002 학습 정의와 같다 |
| 평가 truth 격리 | 모든 online arm을 마친 뒤 evaluator를 연다. E5만 그 뒤 truth로 재적합한다(진단 arm, 설계대로) |
| Student-t | `student_variance`가 R_ss/w를 3회 반복한다. 사양 §4.2를 그대로 구현했고, 결함은 사양에 있다 |
| E4 | 이동 2 cm 초과 시 φ=0이다(사양 그대로). 학습한 상관 성분 비율이 0.99999999로 상한에 붙어 백색 성분이 거의 0이다 |
| gate | E0의 shadow gate mask를 모든 arm에 고정했다. 사양과 같다 |
| 지표 | Pose95는 χ²₃(0.95)=7.81, XY95는 χ²₂, heading은 ±1.96√P_ψψ다. 정상이다 |
| 열잡음 | 학습 σ는 잡음 없는 RT에서 왔고 열잡음 분산을 더하지 않았다. 다만 oracle의 scale(열잡음 포함)이 TEACH보다 작아(0.02–0.03 vs 0.04), 주원인은 아니다 |

## 5. 정정 (2026-11-15, 사용자 진단 `6269285` 반영)

- §1의 3번 "E5가 독립 가정 실패의 직접 증거"는 **교란되어 있다**. E5도 S3 누적 재가중을 썼으므로, 재가중 결함과 독립 가정의 효과가 섞여 있다. 독립 가정을 시험하려면 E2형 Gaussian을 평가 궤적에 재적합한 oracle이 따로 필요하다.
- 사용자 진단에 따르면 앵커 B에서 E1의 Pose95 저하는 대부분 거리 평균 성분이다(−13~−35 %p).

  - 따라서 §1의 4번 설명(σ_b 팽창이 주원인)은 **앵커 B에서는 2차 요인**이다.
