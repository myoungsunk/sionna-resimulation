# §3.3 거리별 팽창 제외 재생과 D1 게시 검증

범위는 mount 0°, 앵커 B, B0, Full RF, R5, seed 10이다. 1,415 packet에 seed 10 E0 고정 gate를 적용하며 1,384개를 수용한다. 근거리 분류는 E0-LORO 갱신 전 수평거리 ρ < 3 m로 고정했다. 근거리는 448개이며 모두 수용한다. 원거리는 967개 중 936개를 수용한다.

원래 실행은 2026-11-16 16시 15–17분 KST에 Windows Python 표준 입력으로 이뤄졌다. 복구한 원본 코드와 결과 JSON을 보존하고, 같은 코드에 저장 래퍼를 적용해 trace를 생성했다. 원래 실행은 trace NPZ를 쓰지 않았다. 이번에 생성한 18개 trace의 출처는 재실행이다. `SOURCE_PROVENANCE.json`과 `original_results/ORIGINAL_RESULTS_PROVENANCE.json`이 코드·원래 출력의 출처와 해시를 기록한다.

3 m는 기존 결과를 본 뒤 정한 진단 경계다. 기존 스케줄 A1(M1-I 0.5 m)과 A2_4(HF-KI 4°)의 저장된 Reff를 사용했다. 분산 스케줄을 다시 학습하거나 현재 궤적에서 계산하지 않는다.

HF-KI 4°의 근거리 팽창 제외에 따른 전체 XY RMSE 차이는 -9.52 cm이고, 10 s 짝 블록 95% 구간은 [-12.87, -5.67] cm다. 기존 28개 완전 블록과 bootstrap seed를 그대로 사용했다.

근거리 y RMSE는 heading 약화에서 3.91 cm, y 약화에서 5.25 cm다. 이 두 조건의 전체 XY RMSE 짝 차이 구간은 `runs/A2_4_weak/RESULT.json`에 보존했다.

세 단계 모두 복구한 원래 6자리 출력 JSON과 정확히 일치한다. unrounded 점수와 bootstrap 구간은 각 `SCORES.json`에 있다. 기준선과 전체 팽창의 x, P, prior, Pprior, h, H, R, K, innovation, S의 parity 최대 차이는 0이다. 18개 trace의 시간·pose ID·gate·분산·유한성·공분산을 검사했고 14개 보고 조건의 점수를 별도 선형계 풀이로 재계산했다. 원래 반올림 수치와의 최대 차이는 4.78e−7이다.

이 게시물은 기존 R5·seed 10 진단의 재현성 자료다. 원본 코드·결과의 복구, trace 재생 성공, 점수 검산을 기록한다. 최종 모델 채택 판정을 추가하지 않는다.
