## 4. 사다리 — 어느 성분에서 바뀌는가 (B단계, H2S 기준 J, McNemar 정확 검정)

| 단계 | 바뀌는 성분 | B0 잃음 / 얻음 (p) | L2 잃음 / 얻음 (p) |
|---|---|---|---|
| F2L → F2S | 편파 분산 표 → sweep | 2 / 0 (0.50) | 4 / 0 (0.13) |
| F2S → F2SB | R_rr, 원거리 μ_s → sweep (b) | **6 / 0 (0.03)** | **6 / 0 (0.03)** |
| F2SB → F2SK | 근·중거리 μ_s → kriging | **0 / 11 (0.001)** | **0 / 9 (0.004)** |
| F2SK → F2SKRW | μ_r → sweep (b) | 5 / 4 (1.00) | 5 / 2 (0.45) |
| F2SKRW → F2SKRW-V | 근·중거리 편파 분산 → V | 0 / 2 (0.50) | 0 / 3 (0.25) |
| F2SKR → F2SKRW | μ_r 가중 균등 → (b) | 6 / 3 (0.51) | 7 / 2 (0.18) |

- **kriging이 가장 큰 이득입니다.** F2SB에서 잃은 것을 되찾고도 남는다. 이 결과는 A단계와 같은 방향이다.
- **μ_r 교체(F2SK → F2SKRW)는 득실이 엇갈립니다.**
  - 거울해가 F2SK 4–5건에서 0건으로 줄어든다.
  - 대신 R2 정확도가 나빠진다. B0 R2 중앙값 기준 XY 6.0 → 11.8 cm, heading 0.99 → 1.73°.
- **원인 후보: sweep μ_r의 거리 의존 편향입니다.**
  - 거리 innovation 평균(중앙값)은 R2 3–6 m에서 F2SK +0.4 cm, F2SKRW −1.0 cm다.
  - R4 3–6 m에서는 −0.6 cm에서 −2.8 cm로 바뀐다.
  - 이전에 확인한 sweep HGB의 3–6 m 편향(−1.4…−1.9 cm)과 같은 방향이다.

## 7. 결과 해석 (계획 §9)

| 질문 | 결과 | 허용 판단 |
|---|---|---|
| ① sweep 내부 판정 | 실패. 거울해가 아니라 무결성(pooled Pose95)과 R2 정확도 때문이다 | "① 실패 (그 밖)" |
| ② 계열 간 비교 | 무결성은 B0 통과, L2 실패. 정확도는 B0, L2 모두 열등 | "열등. 열등 성분은 μ_r 교체 단계" |
| 보조 V | N_J 16/15로 주 후보보다 높고, XY는 비열등 | 다음 계획에서 V를 주 후보로 한다. 이번 판정은 바꾸지 않는다 |

- **현재 상태:** 장소 측정 절차와 사전 정보만으로 만든 필터는 이 판정 기준을 통과하지 못한다. LORO 수준에도 정확도가 못 미친다.
- **가장 큰 열등 성분은 sweep μ_r입니다.** R2 정확도를 잃고 거울해는 줄인다. 두 효과가 같은 성분에서 나온다.
- **무결성 실패의 대부분(pooled Pose95 0.85–0.90)은 F2L에도 있습니다.** sweep 대체만의 문제로 볼 근거는 없다.
- 이 판정 뒤에 성분이나 설정을 조정하지 않았다.

## 8. 한계

- 설계는 seed 10–29와 R2/R4/R5를 보며 정했다. 궤적은 같고 seed만 새것이다.
- V 표는 참 station 자세에서의 kriging 잔차로 적합했다. online은 prior 자세를 쓴다.
- H2S는 계획 정의(kriging 없음)상 약한 기준이다. H2 기준 결과도 함께 보고했다.
