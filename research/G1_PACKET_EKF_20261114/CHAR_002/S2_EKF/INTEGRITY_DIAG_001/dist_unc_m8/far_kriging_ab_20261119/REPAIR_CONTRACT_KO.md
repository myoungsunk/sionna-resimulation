# 기준선 재현 진단과 수치 수정 범위

질문 ID: `IPALO-FAR-KRIGING-AB-20261119/REPRO-01`.
역할: IMPLEMENTER 자기 검사. 시작 커밋: `b51b76ed3de68d28d2cdcce6d560c91ffe30df2c`.
적용 지침: 저장소 동결 `gm_theta_m6/inputs/{COMMON_CONTRACT,ROLE_IMPLEMENTER}.md`.
사용자 승인 범위: 불일치 원인 조사·수정·기존 게이트 재검증, 통과한 경우에만 전체 A/B 실행·업로드.

원본 Phase B 입력 law, 원본 sweep 자산과 평가표, 기준선 허용치 `1e-8`, seed·route·condition·분산·Q·NIS·RMSE/coverage 정의는 유지한다. 기존 실패 결과는 덮어쓰지 않는다. 후보 A/B arm을 수행하지 않는 baseline-only 진단을 사용한다.

## 식별 검사

1. 기존 NumPy 2.4.6/Python 3.11 환경과 원본에 기록된 NumPy 2.5.3/Python 3.12 환경을 분리해, 같은 입력 배열·소스로 기준선만 재생한다.
2. 상태·공분산·innovation·R·mask의 최초 차이를 찾아, 같은 이전 상태에 대한 Kriging 이웃과 예측값을 비교한다.
3. 입력 NPZ 파일 해시와 배열 일치를 구분한다. 압축 파일 해시 불일치만으로 수치 입력이 다르다고 단정하지 않는다. 원본 seed30–49 배열은 보관본이 없으므로 직접 동일성 검사는 불가능하다.

## 수치 수정 후보

동결 Kriging은 `np.argpartition(d,150)[:150]`으로 이웃을 고른다. L1 거리의 150번째 경계에서 원래 같은 거리인 학습점이 부동소수점 오차 때문에 서로 교체되는 문제를 검사한다.

수정 함수 `kriging_stable.neighbor_indices`는 `32*eps*max(1,abs(cutoff))` 이내의 cutoff 동률을 원본 training-row 순서로 결정하고, 최종 이웃도 같은 순서로 선형계에 넣는다. 최대 이웃 수 150, 학습점/순서, 커널, 초모수, 평균, nugget 및 EKF 방정식은 유지한다. 동률 외에 분리된 거리의 최근접 이웃은 바뀌지 않아야 한다.

이는 과거의 임의 tie 선택과 다른 결과를 낼 수 있는 **수정 후보**다. 수치 안정성 회복만으로 동결 기준선 재현이나 A/B 수행 권한을 얻지 않는다. 두 환경에서 상태 X·P·mask·R·시점 비교 및 원래 POINT_B 절대 오차 검사를 모두 보고한다. 기존 `1e-8` 게이트 실패 시 전체 A/B를 수행하지 않는다. 점수가 좋아지는 tie 정책이나 런타임을 찾기 위한 탐색은 하지 않는다.

원본 코드·동결 표를 수정하지 않고 명시적인 `--stable-kriging` 진단 옵션에만 적용한다. 기존 게이트를 통과하지 못한 수정 후보를 기존 F2SKRWV로 채택하거나, 원본 평가표를 수정해 통과시키지 않는다.
