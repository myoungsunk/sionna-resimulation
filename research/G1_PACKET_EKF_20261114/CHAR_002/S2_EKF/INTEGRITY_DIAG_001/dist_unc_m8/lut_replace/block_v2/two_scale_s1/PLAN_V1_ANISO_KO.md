# V1 비등방성 확인 (사전 고정, 2026-11-27)

| 항목 | 내용 |
|---|---|
| 질문 | 다중경로 편파 오차 장의 상관이 x(진행), y(횡), yaw(회전) 방향으로 다른가, 거리에 따라 어떻게 다른가 |
| 라벨 | e = s_full − s_LoS (A, oracle). 4 cm sweep은 H_LoS에서, station 격자는 FFD에서 s_LoS를 만듦(parity 확인 후 사용) |
| 자료 | ① 4 cm sweep: 중심 P016(ρ 2.05), P010(4.75), P003(7.90) 주변 x −16…+16 cm, y = 0, 36 yaw. 중심은 station 격자 값 사용 ② station 격자: x 0.45 m 열, y 0 / ±0.30 / ±0.45 m 줄, 36 yaw |
| 사전 확인 | 4 cm sweep에서 추출한 s_LoS와 FFD s의 차 p90 ≤ 0.005. 중심 ±4 cm의 s_full 곡선이 중심 곡선과 상관 ≥ 0.9 |
| 지표 | 곡선 상관: 두 위치의 36-yaw 오차 곡선 e(ψ)를 같은 yaw끼리 묶어 평균을 빼지 않은 상관. 거리 방향별 1/e 길이(구간 내 선형 보간). 성분(δ, κ, offset): 위치 간 차의 RMS를 각 성분 station SD로 나눈 값 |
| 방향 | x 미세: 4 cm sweep (4–32 cm). x 거친: 격자 열 (0.45–1.8 m). y: 격자 줄 (같은 열, Δy 0.15–0.9 m). yaw: 같은 station 안 e(ψ)와 e(ψ+Δψ), Δψ 10–90° |
| 판정 | 거리 bin마다 y 길이 / x 길이 비가 [0.5, 2] 밖이면 "비등방성이 크다". yaw 길이는 단위가 달라 보고만 한다. 4 cm 자료는 세 중심 각각을 그 거리 bin의 대표로 보고한다 |
