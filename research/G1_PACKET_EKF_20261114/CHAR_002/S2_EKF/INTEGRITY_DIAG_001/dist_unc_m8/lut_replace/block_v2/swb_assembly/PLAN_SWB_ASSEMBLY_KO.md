## 3. arm (구간별 교체 사다리)

경계 처리(B4): 서로 다른 출처의 곡선이 만나는 3 m, 6 m에서 곡선 값을 logistic(폭 0.15 m)으로 섞고, 섞은 함수에서 Jacobian을 계산한다.
분산 표: 각 arm에서 그 arm의 블록 잔차로 다시 적합한다(c₁a² + c₀, 거리 bin [0, 3, 6, 10)). SWB 구간은 열 제외(LOCO) 잔차, FFD 구간은 bias_ffd P2의 표를 쓴다.

| arm | < 3 m | 3–6 m | ≥ 6 m | 목적 |
|---|---|---|---|---|
| R0 | P2 (FFD + heading형 bin 평균 + 근거리 kriging) | P2 | P2 | 기준. bias_ffd P2와 replay parity |
| R1 | SWB 측정 곡선 (x cubic spline, y 선형) | P2 | P2 | 측정 곡선 보간이 FFD + kriging의 국소 평균을 대신하는가 |
| R2a | SWB | **현재 SWB 코드 그대로**: station 곡선을 흩어진 몫(D − δ̄)만 되돌림, δ̄는 ρ Gaussian 0.75 m (B1) | P2 | 중거리 station 고유 모양을 남겨도 되는가 |
| R2b | SWB | 같은 쪽 ±3열 × 5줄 평균 모양을 χ_ref + δ̄로 회전 | P2 | 재현되지 않는 모양을 평균에서 빼야 하는가 |
| R3 | SWB | R2* (4절 규칙으로 선택) | **SWB fullco: ±3열 × 5줄 평균** (FAR_STATION = False, B2) | 전체 SWB |
| R3-K | R3 | R3 | R3 | kernel 길이를 N1–N6에서 학습한 값으로 교체 (5절) |

- χ_ref(ρ): y줄·앵커 쪽별로 1 ≤ ρ < 3 m station의 χ와 ρ ≥ 6 m 같은 줄 ±3열 평균의 χ를 2차식으로 적합(현재 코드).
- R3 parity(B2): fullco 재구성 계수 sha는 31a5bc5c이고, 보관 계수 fbbd6430과 비트 단위로 일치하지 않는다(재구성 보고서: 표 차 ≤ 3.5e−18, "pending archived replay parity"). 실행 전 Paper 1 V1 결과 1 seed를 재생해 parity를 확인하고, 불일치하면 원인을 기록한 뒤 재구성 계수로 진행한다.

## 4. 정적 관문과 사전 선택 (N1–N6, 필터 전)

**잔차:** r = s_fp − m(참 pose). valid 관측만 쓴다.

| 지표 | 단위 | 통과 기준 (R0 대비) |
|---|---|---|
| 잔차 RMS | 거리 bin | ≤ 1.10배 |
| heading 등가 편향 Σa·r / Σa² | 거리 bin × 앵커 쪽 (C3) | \|값\| ≤ \|R0\| + 0.3° |
| 감도 a 부호 일치율 (FFD 대비) | 거리 bin | ≥ 0.95 (< 6 m). 원거리는 보고만 |
| packet 95% 포함률 \|r\| ≤ 1.96√(c₁a² + c₀) | 거리 bin | 0.90–0.98 |

**분산 표 변형 (B3):**
- T-LOCO: 열 제외 잔차 그대로
- T-ADJ: 간격 보정. 같은 열에서 한 줄을 뺀 잔차와 열 제외 잔차를, station 간 거리(줄 0.15–0.3 m, 열 0.45 m)에 대해 거리 bin별로 비교한다. 분산 대 거리의 선형 관계를 경로–최근접 station 거리 분포의 중앙값으로 외삽해 표를 축소한다.
- 선택: arm마다 N1–N6 포함률이 [0.90, 0.98] 안에 드는 변형을 고른다. 둘 다 들면 0.95에 가까운 쪽, 둘 다 밖이면 T-LOCO로 두고 관문 실패를 기록한다.

**R2* 선택:** 관문을 통과한 R2a, R2b 중 N1–N6 중거리(3–6 m) bin × 쪽의 |heading 등가 편향| 평균이 작은 쪽을 고른다. 차이가 0.1° 미만이면 R2a(현재 코드)로 한다. 둘 다 관문에 실패하면 R3로 진행하지 않고 실패 지표를 보고한다.

관문에 실패한 arm은 필터를 돌리지 않는다.

## 5. kernel 길이 학습 (K-b, N1–N6)

- **라벨:** R3 블록 잔차 r(위 정의)
- **쌍:** 같은 궤적 안의 packet 쌍. 거리 bin은 앞 packet의 ρ로 정한다.
- **arc 길이 L:** 회전 누적 < 2°인 쌍에서 corr(Δarc) = exp(−Δarc / L)을 적합한다(Δarc ≤ 2 m).
- **yaw 길이 Y:** 이동 누적 < 2 cm인 쌍(제자리 회전)에서 corr(Δψ) = exp(−Δψ / Y)를 적합한다(Δψ ≤ 90°).
- **궤적 가중:** 궤적마다 따로 적합한 뒤, 거리 bin별 중앙값을 쓴다. 궤적별 값의 범위를 보고한다. N3는 원거리가 없고 원거리 yaw는 N4에만 있으므로, 적합 가능한 궤적이 2개 미만인 모수는 F2 기본값(1 m / 10°)으로 두고 기록한다.
- **보고 (판정 아님):**
  - N1–N6 궤적 하나 제외 예측: 다섯 궤적의 중앙값 kernel로 남은 궤적의 경험 상관을 예측한 오차
  - K-a 비교: R2/R4/R5 LORO로 적합한 길이 (진단용, 필터에 쓰지 않음)
  - pose 오차 민감도: 참 pose에 상관 길이 1 m, sd 2 cm의 위치 오차와 sd 0.5°의 heading 오차를 넣었을 때 L, Y의 변화
- bias_ffd P3의 길이(0.4 m / 0.15 m)는 평가 궤적의 참값 라벨에서 나왔다(A1). P3 결과는 "누설 포함, 상한 참고"로 다시 표기하고, 이 계획에서는 쓰지 않는다.

**진단 (손실 위치):** R1 대 R0, R2* 대 R1, R3 대 R2*, R3-K 대 R3. 같은 규칙으로 계산하되 주 판정에는 쓰지 않는다. 함께 보고할 것: Pose95, Heading95, XY95, NEES3, 궤적·거리 bin별 heading 평균 오차와 z RMS(D1), 경계 ±0.3 m 구간 잔차(B4).

**확정 (C1):** dev에서 R2*, 표 변형, kernel을 정했으므로 dev 결과는 선택 편향을 포함한다. 확정 seed 70–89 입력을 frozen 생성 절차로 만든 뒤, R0, R3, R3-K를 한 번만 실행한다. 확정 실행 전에 arm과 설정을 이 폴더에 다시 기록한다.
