# 쌍 곱 회귀(①)의 합성 주입 시험 (사전 고정, 2026-11-27)

| 항목 | 내용 |
|---|---|
| 목적 | E[e_ie_j] = a_ia_j C_θ(Δ) + C_res(Δ) 회귀가 실제 N1–N6의 a 수열과 쌍 구조에서 알고 있는 공분산을 되찾는지 확인 |
| 입력 | N1–N6 참 pose의 FFD 감도 a, 누적 arc. 쌍 선택은 S1b와 같음(같은 궤적, 30 s, 누적 회전 < 2°) |
| 합성 | δ_k = σθ(ρ_k)·g_k, n_k = σres(ρ_k)·h_k. g, h는 arc 좌표의 독립 지수 공분산 과정(OU), 길이 Lθ, Lres. σθ = 0.92 / 3.25 / 3.36°, σres = 0.011 / 0.048 / 0.161 (거리 bin 3개, station 표) |
| 사례 | T1: Lθ 1.0 m, Lres 0.1 m / T2: Lθ 0.1 m, Lres 1.0 m / T3: Lθ = Lres = 0.3 m / T4 교란: T1에 더해 n의 분산을 \|a\| 상위 1/3 packet에서 3배 / T5 평균: T1에 δ 평균 −2.5°(중거리만) 추가 |
| 반복 | 사례마다 20회 (rng seed 0–19) |
| 추정 | 거리 bin × lag bin(0–0.04, …, 2–4 m)마다 OLS. 0 간격은 e_k²를 [1, a_k²]에 회귀. 조건수 > 10인 lag bin은 제외. 정규화 ρ(Δ) = C(Δ)/C(0)의 1/e 교차로 길이 L̂ |
| 판정 (거리 bin별) | 회복 성공: 20회 중앙값에서 \|L̂/L − 1\| ≤ 0.3 (두 성분 모두), 0 간격 \|σ̂²/σ² − 1\| ≤ 0.2. T4는 L̂θ 편향 ≤ 30%이면 교란에 견딤. T5는 평균이 C_θ의 평평한 남는 높이로 나타나는지 보고만 |
