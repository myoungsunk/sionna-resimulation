## 2. 사용자가 확정한 비교 조건

### 2.1 센서 조건·gyro Q와 L2 단위 정정

| 항목 | B0 | L2_GYRO_ARW |
|---|---|---|
| SensorV2 설정 | level=1, condition=noise_pair | **level=1, condition=noise_pair 유지** |
| gyro 백색 잡음 N | 0.015°/√s | **0.060°/√s** |
| 각 증분 분산 | Var(δψ)=N²Δt | B0의 16배 |
| wheel 입력·RF·초기화 | 같은 seed의 짝 입력 | B0와 완전 동일 |
| gyro bias·scale factor·bias RW·slip | noise_pair 정의대로 비활성 | 동일하게 비활성 |

앞서 제시했던 0.05→0.20°/s는 동결 코드의 drift-level **bias** 값이다. 실제 백색 잡음은 `gyro_N_rad_sqrt_s`이며, 사용자가 B0를 유지하고 이 계수만 4배 높이는 것으로 정정 승인했다. L2_GYRO_ARW는 과거의 모든 오차 항을 바꾸는 full L2와 구별한다. `level=2`로만 바꾸거나 `condition=gyro_noise`로 wheel 잡음을 제거해서는 안 된다.

같은 seed의 gyro 난수 스트림을 사용해 `gy_L2−gy_truth = 4(gy_B0−gy_truth)`를 검사한다. gy는 rad 단위의 **각 증분**이고 각속도가 아니다. wheel 입력·dt·z·평균 보정·x0·P0의 짝 동일성을 별도로 확인한다.

**주 L2는 주입한 gyro 잡음에 필터 Q를 맞춘다.** 기존 [e0_batch.py](e0_batch.py)의 입력 잡음 공분산에서 gyro 각 증분 항은 `Q_input[1,1]=radians(0.015)²·dt`다. 아래 계수를 명시적으로 공급해 기존 G로 navigation 공분산에 전달한다. 0.060은 degree 단위 계수이므로 radian 변환 없이 제곱하지 않는다.

| 재생 조건 ID | 실제 gyro N (°/√s) | 필터 gyro Q_input[1,1] (rad²) | 판정 역할 |
|---|---:|---|---|
| B0 | 0.015 | radians(0.015)²·dt | 주 판정 |
| L2_GYRO_ARW | 0.060 | **radians(0.060)²·dt** | Q 일치 주 판정 |
| L2_GYRO_ARW_Q_B0_STRESS | 0.060 | radians(0.015)²·dt | **보고 전용, M7_PASS에서 제외** |

거리 잡음 `Q_input[0,0]=2e−5·|ds|`, 기존 b_g random-walk 항 0, 전이·잡음 전달 G와 다른 모형 항은 유지한다. 바뀌는 것은 gyro 각도 잡음 기여이며 전체 P나 전체 Q가 일괄 16배가 된다는 뜻이 아니다. H0부터 H5′까지 같은 조건의 Q를 적용한다. H2 기준선도 해당 조건 Q로 재생한다. 이 변경은 주입 사양에 맞춘 **실행 전 사양 정정**이며 결과를 보고 맞추는 조정이 아니다.

stress는 주 L2와 같은 online NPZ·초기값·동결 모수·arm을 재사용하고 필터 gyro Q만 B0로 되돌린다. seed 10–29의 자체 gate에서 보고하며 고정 mask stress는 추가하지 않는다. stress의 실패·성공은 주 판정을 바꾸지 않는다. B0 대 주 L2는 올바른 Q를 사용하는 두 센서 품질의 비교이고, 주 L2 대 stress는 Q 불일치의 전체 효과를 가른다.

### 2.2 seed별 초기 분포

- seed 10–29 각각에서 SensorV2의 `initial` 스트림을 사용한다. 참 시작 자세에 표준편차 [0.10 m, 0.10 m, 5°]의 독립 영평균 Gaussian 오차를 더하고 ψ를 wrap한다. b_g 초기 평균은 0이다.
- P0는 `diag(0.10², 0.10², rad(5)², rad(0.1)²)`로 생성 분포에서 구성한다. b_g의 마지막 단위는 rad/s다. 같은 분포이므로 seed마다 P0의 수치가 같은 것은 정상이며, 실현 초기오차에서 P0를 만들지 않는다.
- 같은 seed에서는 H0–H5 및 H5′, B0/L2/stress 및 자체·고정 gate 대조가 동일한 x0/P0를 사용한다. 과거 M6처럼 seed 10의 실현 x0를 다른 seed에 덮어쓰지 않는다.
- 참값은 오프라인 센서·초기화 생성과 점수 계산에만 접근한다. 후보 재생 함수는 online NPZ와 동결 모델만 받는다.

| 고정 mask · 대조 | 두 주 조건, seed 10–14, H1–H5 및 H5′ | 과거 **B0 seed 10 E0**의 궤적별 mask를 그대로 적용 |

| DR | 모든 H0 | 관측 갱신 없음. gate 미적용 |

고정 mask의 수용 수는 R2 971/979, R4 728/742, R5 1384/1415다. H1 고정 대조도 같은 2채널 E0에서 유래한 mask를 사용하므로 운용 1차원 gate의 결과로 해석하지 않는다. 자체 gate의 수용 수는 이 값으로 강제하지 않는다. 고정 mask를 적용해도 거절 packet의 예측과 GM 감쇠는 수행한다.

**R_ref는 모든 주 arm과 고정 mask 대조에서 각 arm 자기 상태로 조회한다.** D5의 조회 시점을 유지해 packet i의 예측 전, 직전 posterior의 수평거리 `ρ_before=‖x_(i−1),xy^+−a_xy‖`를 사용한다. i=0에는 x0를 사용한다. D5의 거리 knot [0,1.5,3,6,10] m와 해당 LORO σ_b 표를 선형 보간하고, 끝 구간 밖은 끝값을 유지한다.

`R_ref,i = R_packet,i + diag(0, σ_b(ρ_before)²)`이다. **분산**을 더하며 σ_b를 직접 더하지 않는다. KI의 q_s 조회는 이와 달리 자기 **예측 prior** 거리에서 수행한다. 현재 측정이나 evaluator를 분산 조회에 사용하지 않는다. 과거 M6 G0의 R 시계열을 공통 공급하는 모드는 구현 parity 검사에만 허용한다.

## 3. Arm과 동결 모형

| arm | 정의 | 상태·역할 |
|---|---|---|
| H0 | 일반 DR, wheel ds와 gyro gy로 예측만 수행 | [x,y,ψ,b_g]. 관측 및 b_g 추정 갱신 없음 |
| H1 | 거리 단독 EKF | 같은 4상태, 거리 관측·평균 보정만 사용한 실제 1차원 Joseph 갱신 |
| H2 | G0 = E0-LORO-σ_b | 같은 4상태, **정확도 판정 기준선** |
| H3 | 기존 G1+KI | 5상태 GM-θ와 동결한 잔여 s 영역 causal KI |
| H4 | G1 단독 | 같은 GM-θ·σ_θ, KI만 제거 |
| H5 | KI 단독 | 4상태, H3와 같은 q_s 표·kernel, b_θ만 제거 |
| H5′ (실행 ID H5P) | GM 몫을 차감하지 않고 같은 규칙으로 적합한 KI 단독 | 4상태, σ_θ=0으로 donor 적합한 q_s′. 동결한 대조 arm |

H1은 2차원 gain을 구한 후 편파 열을 0으로 만드는 방식으로 구현하지 않는다. H5는 GM 공분산을 차감한 뒤 M6에서 얻은 **같은 잔여 q_s**를 사용한다. b_θ를 없애면 원래 GM이 담당하던 상관 몫도 빠진다. **H5가 실패해도 “b_θ가 필요하다”는 증거로 쓰지 않는다.** H5는 잔여 모수의 성분 제거 대조이며, 전체 상관 몫을 KI로 처리하는 고정 규칙 대조는 H5′다.

관측 함수·SourceFFD/LUT, packet z, packet에 이미 동결된 μ_MB·μ_BASE, 거리·편파 잡음의 기본 R와 평균 보정 규칙을 유지한다. navigation Q는 §2.1의 조건별 gyro 항만 바꾼다. 이 계보의 μ_MB에는 기존 편파 평균 보정도 포함돼 있으므로 임의로 0으로 바꾸지 않는다. 평균 모형 재학습, 모수 grid 탐색, 20개 seed 점수에 따른 arm·모수 선택은 하지 않는다. H5′의 사전 고정된 donor 재적합만 아래 절차대로 허용한다.

### 3.1 GM-θ

상태는 `[x,y,ψ,b_g,b_θ]`, b_θ의 단위는 rad다. 초기 b_θ=0, P_θθ=σ_θ², 초기 교차 공분산은 0이다. 각 packet에서

`α = exp(−|ds|/1 m − |wrap(gy−b_g,previous^+ dt)|/rad(10))`,

`b_θ^- = α b_θ,previous^+`, `Q_θθ = σ_θ²(1−α²)`.

navigation의 F와 잡음 전달은 기존 재귀를 유지하고 Q의 gyro 항에는 §2.1의 조건별 사양을 적용한다. 교차 공분산을 F와 α로 전달한다. i=0에서는 초기 분포를 사용한다. α는 직전 상태와 controls로 계산한 조건부 계수로 고정한다.

`a=H_sψ(x_nav^-)`를 부호 그대로 한 번 계산해 현재 갱신 동안 고정한다. 편파 예측은 `h_s(x_nav^-)+a b_θ^-`, 편파 Jacobian은 `[H_x,H_y,H_ψ,0,H_ψ]`, 거리의 b_θ 열은 0이다. a의 상태 미분을 다시 넣지 않는 M6 조건부 선형화와 5상태 전체 Joseph 갱신을 유지한다. b_θ도 추정하며 consider로 바꾸지 않는다.

### 3.2 KI와 모수 출처

H3·H5는 같은 arm의 prior 거리로 V_i=q_s(ρ_i^-)를 조회한다. H5′는 같은 위치에서 q_s′를 조회한다. kernel은 자기 controls와 추정 b_g에서 계산한 누적 arc·절대 yaw에 대해 `k_ij=exp(−Δarc/1 m−Δyaw/rad(10))`다. 이전 **같은 arm에서 수용한** packet 중 직전 10 s·최대 100개를 사용한다.

`R_eff,ss = R_ref,ss + V_i + 2Σ_j sqrt(V_i V_j) k_ij`.

현재 packet의 gate 판정 전에 R_eff를 계산하고, 수용 뒤에만 현재 packet을 이력에 추가한다. 탈락 packet도 시간·이동·yaw는 진행한다. 과거 V_j는 당시 조회값을 보존한다. 거리 채널과 R의 원래 교차항은 유지한다. H3에서는 이 R_eff에 GM을 더해 쓰며 GM의 a²σ_θ²를 백색 R에 또 더하지 않는다.

H3·H4의 σ_θ 및 H3·H5의 q_s는 [M6 K1′·K2 결과](gm_theta_m6/characterization/K1_PRIME_K2.json)의 LORO fold를 그대로 가져온다. 원본 SHA-256은 `507db95ab5368aa46ff1f1d1cef819904ec163819b0dde99a2b150f4a6bbf672`다. 아래 수치는 표시용 반올림이며 실행 계약에는 원본 정밀도를 기록한다. H5′의 q_s′는 §3.3에서 별도로 동결한다.

| R2 | R4·R5 | 2.134300 | 0 / 0 / 0.0032278021 / 0.0036887829 |

| R5 | R2·R4 | 2.041883 | 0 / 0 / 0.0048496992 / 0.0087857134 |

모든 bin의 donor 지원 여부도 원본에서 가져온다. 지원이 없거나 범위 [0,10) m 밖인 prior에서는 기존 M6와 같이 KI 증분을 0으로 두고 노출률을 보고한다. 두 주 조건과 stress·20 seed에 같은 표를 사용한다. H3·H5 표를 재적합하거나 seed별 보정하지 않는다.

“H5의 근거리 q_s=0이므로 R4에서 실패할 수 있다”는 사전 예측은 **범위가 제한된다.** R4의 [0,1.5) m에는 작은 양의 q_s가 이미 있다. 이 값을 지우지 않고 실제 표로 시험하며, 실패·회복 방향은 결과로 판정한다. 새 3 m hard boundary를 추가하지 않는다.

### 3.3 H5′ · σ_θ=0의 고정 LORO 재적합

H5′는 같은 [M6 적합 코드](gm_theta_m6/characterize.py)의 hybrid 잔차 쌍 적합에서 **GM 공분산 차감항의 σ_θ만 0으로 둔다.** donor·가중·지원·잔차 정의·거리 bin·길이는 그대로다. donor는 R2←R4/R5, R4←R2/R5, R5←R2/R4로 고정하며 M6에서 동결한 B0 seed 10 donor 잔차·E0-LORO prior·mask와 D3 경로 평균만 사용한다. holdout 잔차와 M7 seed별 결과를 적합에 쓰지 않는다.

donor 잔차는 `e_i=raw_s,i−D3.route_mean_s`다. 같은 donor·거리 bin·궤적 시작 기준 10 s 블록 안에서 수용된 packet 쌍 중 **0.4≤Δt≤5 s**를 쓴다. 블록당 10쌍 이상, 각 donor에 지원 블록 2개 이상이라는 기존 규칙을 유지한다. 기존 코드의 분자·분모 집계 순서를 그대로 명시한다.

지원 블록 b의 쌍 집합을 P_cb, donor c의 지원 블록 집합을 B_c라 두고, 기존 적합의 차감 전 공분산 `e_i e_j`로 다음을 계산한다.

`n_cb=mean_(ij∈P_cb)(k_ij e_i e_j)`, `d_cb=mean_(ij∈P_cb)(k_ij²)`.

`n_c=mean_(b∈B_c)n_cb`, `d_c=mean_(b∈B_c)d_cb`, `q_s′(d)=max(0, Σ_c n_c / Σ_c d_c)`.

블록 안 쌍의 평균 → donor 안 지원 블록의 평균 → donor별 분자 합/분모 합 순서다. **donor별 비율 n_c/d_c를 동일 가중 평균하지 않는다.** 기존의 `σ_θ² a_ref,i a_ref,j k_ij` 차감항이 0이 된 식이다. 거리 bin별 donor·블록·쌍 수, 분자·분모, 음수에서 0으로 제한한 값, 미지원 구간을 기록한다. 지원이 없거나 [0,10) m 밖에서는 증분 0과 노출률 보고 규칙을 유지한다. **q_s′를 ρ<3 m에서 강제로 0으로 만들지 않는다.** 원래의 near-zero 표는 결과이지 H5′의 제약이 아니다.

이 donor 적합은 M7 주 재생 전에 한 번 수행하고 결과·코드·입력 해시를 계약에 묶는다. 두 주 조건·stress와 모든 seed에 같은 q_s′를 사용하며 grid·배수 탐색은 하지 않는다. H5′는 q_s′ 외에는 H5와 같은 4상태 KI·자체 gate·R_ref 정책이다. H3−H5′는 이 자료에서 두 동결 구조의 비교이며, H5′ 실패만으로 모든 가능한 KI에 비해 b_θ가 원리적으로 필수라고 주장하지 않는다.

**입력 검사:** seed 10 B0의 ds/gy/x0/P0는 동결 online과 1e−10 이내, t·pose_id·z는 완전 일치해야 한다. seed 11–14는 기존 M5 controls와 대조하되 새 x0가 과거 공통 x0와 달라지는 것은 계획된 변경이다. 모든 seed의 x0를 생성 스트림에서 다시 계산한다. 앵커 통과는 evaluator의 기존 x=10 m 교차 정의로 R2 2회, R4 1회, R5 3회다.

**구현 검사:**

1. 과거 M6의 x0·mask·R_ref 스케줄을 명시적으로 주입한 parity 전용 모드에서 G0·G1·G1+KI의 x/P/prior/Pprior/h/H/K/R_eff/ν/S를 1e−10 이내로 대조한다. mask는 완전 일치여야 한다. 이것을 새 운용 조건의 성능 재현으로 부르지 않는다.
2. σ_θ=0·q_s=0의 주변 4상태는 같은 Q의 H2와 일치해야 한다. H3의 q_s=0은 H4, H3의 σ_θ=0은 **같은 q_s를 쓴 H5**와 일치해야 한다. 이는 q_s′가 다른 H5′와의 parity를 뜻하지 않는다. H5′도 증분 q_s′=0에서 H2와 같고 H5/H5′에 같은 표를 넣으면 같아야 한다. 부호 있는 적재, GM 교차 공분산·AR 정상 분산, 정지·탈락 전이, Joseph 대칭·양의 준정부호를 검사한다.
3. H1은 독립적인 scalar Joseph 계산과 대조한다. 1차원 NIS와 6.6348966010212145 기준에서 mask를 재구성한다. H2–H5 및 H5′도 저장한 자기 ν·S로 NIS·mask를 재구성한다. 거절 시 x/P는 예측값과 같아야 한다.
4. own R_ref는 직전 posterior 조회를 독립 재계산한다. 실제 LORO σ_b 표가 평평할 수 있으므로 비상수 합성 표에서도 이전 posterior와 현재 prior의 시점을 구별하는 검사를 한다. 합성 표는 검사에만 사용한다.
5. KI의 가변 거리 표·10 s·100개 제한·수용 이력 causal 합을 별도 직접 합산한다. H0는 z 변경에 무관해야 한다. 현재 z 교란에서 prior·모수·R_ref·R_eff가 같고, 미래 입력 교란에서 공통 prefix가 같아야 한다. 현재 z가 gate와 posterior를 통해 이후 이력·상태에 영향을 주는 것은 정상이다.
6. evaluator를 로드하지 않는 후보 재생 경로를 확인한다. 초기 상태와 필요한 모델·online 입력만 전달하고 truth·미래 관측·실현 센서 오차를 전달하지 않는다.
7. B0·Q 일치 L2·stress의 gyro Q 입력을 직접 사양식과 대조하고, 독립적으로 `G Q_input Gᵀ`를 계산해 navigation P^-의 차이를 검사한다. 같은 단일 step·prior·controls에서 주 L2−stress의 예측 공분산 차이는 `G[:,1]G[:,1]ᵀ·(radians(0.060)²−radians(0.015)²)·dt`여야 한다. 다른 Q 항이 같고, H0–H5′가 해당 조건 계수를 사용하며, 계수의 조건 간 전역 상태 누출이 없어야 한다. B0 계수는 보관 원본과 parity를 유지한다.
8. H5′는 σ_θ=0의 원래 donor 적합과 독립 분자·분모 합산이 일치해야 한다. donor·거리 bin·블록·쌍 지원과 가중을 확인하고, M7 재생 점수나 holdout 잔차를 읽지 않는 적합 경로를 검사한다. 이 검사는 donor 재계산이며 새 평가 자료 적합이 아니다.

주 비교는 2조건×20 seed×3궤적×7 arm=**840 cell**, 고정 mask 대조는 2×5×3×7=**210 cell**, 보고 전용 stress는 1×20×3×7=**420 cell**, 합계 **1,470 cell**이다. H0의 고정 mask 대조 30개는 같은 주 실행 trace를 해시로 참조할 수 있어 실제 재생 수는 **1,440회**다. stress는 주 L2와 Q가 달라 별도 공분산 trace가 필요하다. parity·합성 검사와 H5′ donor 적합은 이 수와 별도 집계한다.

## 5. 점수와 동결 판정

동일한 전체 시간 격자에서 heading·XY RMSE, 종료 heading·XY 오차, Pose95·Heading95·XY95, NEES3를 계산한다. 거절 packet도 점수에서 제외하지 않는다. 기준은 같은 조건·Q·seed·gate 운용의 H2다. stress도 stress H2와의 비용 및 Q 일치 L2와의 짝 차이를 별도로 보고한다. DR·거리 단독 대비 개선율은 추가 열로 보고하고 정확도 통과 기준을 바꾸지 않는다.

블록은 5/10/20 s 이동 블록, 각 1,500회, bootstrap seed 20261115를 사용한다. **10 s 구간**으로 판정한다. 같은 궤적·seed의 arm과 B0/L2·gate 대조에 공통 resample index를 써 짝 차이를 계산한다. pooled는 seed마다 세 궤적의 packet을 합쳐 같은 정의로 계산하며, 세 궤적의 시간 블록은 각 궤적 안에서 뽑는다. seed별 점수를 단순 평균한 값과 구별한다.

| 범위 | 무결성 | 정확도 |
|---|---|---|
| 궤적별 | Pose95·Heading95·XY95 각각 ≥75%, 각각 10 s 95% 구간 하한 ≥60%, MIRROR_FAIL 0 | heading·XY RMSE 각각 같은 조건·seed·gate H2 대비 +25% 이하 |
| seed별 pooled | Pose95·Heading95 각각 ≥90%, 각각 10 s 95% 구간 하한 ≥80%, 평균 NEES3 ∈[1.5,6.0], MIRROR_FAIL 0 | 두 RMSE 각각 해당 H2 대비 +10% 이하 |

pooled XY95는 보고하되 기존 계약에 없는 추가 통과 문턱을 만들지 않는다. 10 s 구간의 유효 블록이 8개 미만이면 참고값으로 표시하고 통과 처리하지 않는다. 무결성과 정확도 판정을 분리한다. +10%를 초과한 정확도 결과를 사후 MARGINAL 통과로 승격하지 않는다.

**seed 수 분리:** 각 arm·주 조건의 seed별로 세 궤적 및 pooled에 대해 다음을 별도로 정의한다. `I_seed`는 위 무결성 조건을 모두 만족, `A_seed`는 위 정확도 조건을 모두 만족, `J_seed=I_seed AND A_seed`다. `N_integrity=ΣI_seed`, `N_accuracy=ΣA_seed`, `N_joint=ΣJ_seed`와 각각 /20 비율·구간을 필수 보고한다. I/A의 네 조합별 seed 목록도 남긴다. `N_joint`를 두 주변 통과 수의 최솟값으로 대체하지 않는다.

**20-seed 최종 규칙은 유지한다.** 각 주 조건과 arm에서 **N_joint≥18/20**이고, 20×3=60개 궤적 실행 전체에서 **MIRROR_FAIL 0건**이어야 CONDITION_PASS다. **B0와 Q 일치 L2_GYRO_ARW**가 모두 CONDITION_PASS여야 해당 arm의 M7_PASS다. N_integrity≥18이고 전 실행 거울해 0이면 무결성만의 CONDITION_INTEGRITY_PASS를 별도 표시한다. 정확도만의 18/20 여부도 병기하되 통합 판정을 대체하지 않는다. 한 주 조건만 통과하면 그 조건에 한정해 보고한다. **Q 불일치 stress와 고정 mask 대조는 M7_PASS의 필요조건·대체조건에 넣지 않는다.**

**사전 진단 미사용 seed 부분집합:** seed 10–14와 **seed 15–29(15개)**를 분리해 위 I/A/J 수(/5, /15), 비율·95% 구간, 궤적별·pooled 점수 분포, RMSE 비용, 거울해·b_g 오차를 같은 표에 보고한다. 15개 부분집합에 새 채택 문턱을 만들거나 기존 18/20 규칙을 바꾸지 않는다. “미사용”은 이전 센서·초기화 seed의 진단에 쓰지 않았다는 뜻이며, 같은 궤적·RF와 M6 donor 자료를 공유한다는 한계는 유지한다.

거울해는 기존 [M1–M4 계획](SPEC_EXPOSURE_M1_M4_KO.md)의 정의와 구현을 재사용한다. 각 앵커 통과 후 다음 통과 또는 종료 전까지, |y_truth|≥0.2 m인 구간에서 추정 y의 부호가 반대인 상태가 연속 2 s 이상이면 해당 passage를 MIRROR_FAIL로 센다. **한 건이라도 있으면 해당 arm·조건의 최종 실패**다. 통과 5 s 전 |y 오차|/σ_y>3인 PRE_PASS_OVERCONFIDENT는 경고로 별도 기록한다.

기대 1,470 cell의 누락·중복·비유한 값·수치 오류는 제외 후 분모를 줄이지 않는다. 구현 결함이면 영향받는 판정을 보류하고 수정·재검증한다. 보고 전용 stress만 미완료이면 주 결과를 stress 완료로 표시하지 않고 구분한다. 온전한 실행에서 기준을 못 지킨 seed는 과학적 실패로 남긴다. 임계값 경계와 오차 여유도 함께 보고한다.

| 추정 gyro bias 오차 · 필수 | b_g,true=0 기준 signed 평균, RMSE, 절대오차 p95·최대, 종료 오차, √P_bgbg 및 정규화 오차. 단위 °/s로 보고. 모든 조건·운용·궤적·arm·seed 및 두 seed 부분집합에 포함 |
| R2 취약 창 | 기존 80–120/120–160 s heading RMS·σ_ψ·KI 팽창·b_θ·추정 b_g, seed 10·11 및 전체 seed 분포 |
| R5 통과 1–3 | 통과 ±10 s y RMSE·heading 오차·진입 pose/bias·q_s·국소 y 정보와 branch 지표 |

b_g 표에는 R2 취약 창 및 R5 통과 ±10 s의 같은 오차 지표도 포함하고, `−Σ b_g,previous^+·dt`의 heading 보정 누적과 직접 gyro 주입오차 누적을 구별한다. 참 b_g가 0이므로 추정 b_g의 비영 평균·지속적 보정 경로를 드러내는 진단이며, 이를 독립적인 인과 기여율로 부르지 않는다. b_g의 새 통과 문턱은 만들지 않는다.

trace에는 t·pose_id, x/P와 b_g·P_bgbg, prior/Pprior, 관측 예측·Jacobian·gain, 실제 R_ref/R_eff·ν/S·NIS·mask와 gate 기준, Kν, b_θ·교차 공분산·α, prior 거리·조회 bin·q_s 또는 q_s′·causal 합·이력 수를 남긴다. 조건의 주입 N·필터 N과 실제 gyro Q 계수·dt도 추적한다. H1의 관측 차원은 1이며 H0의 관측 관련 값은 미적용으로 식별한다. b_g,true=0과 오차 계산은 평가 측에서만 적용한다. 재생 함수가 평가 참값을 저장하거나 참값으로 모수를 갱신하지 않는다.

예정 게시 묶음은 `m7_final_model_stage1/` 아래 계획 사본, 입력·재생·집계별 RUN_CONTRACT.json, INPUT_INDEX.json, CHECKS.json, EXECUTION.json, trace NPZ, 궤적별·seed별 CSV, SCORES.json, DECISION.json, REPORT_KO.md, 실행·독립 재집계 코드와 SHA256 목록이다. 실행 명령·시각·종료 상태·Python/numpy·실제 소스 및 입력/출력 해시를 연결한다. 현재는 이 묶음을 생성하지 않는다.

## 7. 결과별 분기와 주장 한계

| 결과 | 허용 후속 판단 |
|---|---|
| H3가 B0·Q 일치 L2에서 18/20 및 거울해 0을 충족 | 두 주 조건·단일 RF에서 채택 후보. DR·거리 대비 순이득은 별도 정확도 표로 확인 |
| H3가 B0만 통과 | B0 조건부 결과. gyro 품질 일반화 주장 보류 |
| H3가 고정 mask에서만 통과 | gate 운용 의존성으로 보고. 자체 gate 채택 보류 |
| H4·H5·H5′ 중 대조 arm만 전체 통과 | 사전 등록된 해당 후보의 통과를 보고. H5′는 같은 규칙으로 전체 상관 몫을 적합한 대조이며 H5와 해석을 구별. 다른 모수나 grid를 사후 추가하지 않음 |
| N_integrity≥18 및 전 실행 거울해 0, N_joint<18 | 무결성만 통과·통합 실패. seed별 정확도 실패와 I/A 겹침을 공개. 기준선 교체나 허용오차 완화로 통과시키지 않음 |
| Q 일치 L2는 통과, stress는 실패 | 명시한 Q 불일치에 대한 취약성. 주 조건 M7_PASS를 취소하지 않으며 편파 모델의 실패로 자동 귀속하지 않음 |
| H5 실패 | 잔여 q_s에서 GM 몫을 제거한 대조의 실패. **b_θ가 필요하다는 결론 금지**. H5′ 결과와 함께 해석 |
| 모든 편파 후보 실패 | 이 자료·동결 구조에서 공통 해 없음. 추가 모형·새 RF·이중 가설은 별도 범위 결정 |

20 seed는 **같은 RF 실현**에서 wheel·gyro·초기화 난수만 바꾼 반복이다. 동일 RF로 정한 M6 LORO 모수 및 사전 고정 규칙으로 얻은 H5′ 모수를 사용하며 seed 10–14는 이미 진단에 사용됐다. seed 15–29는 이전 진단에 사용하지 않은 센서·초기화 실현으로 별도 보고하되 독립 장면·앵커·RF 검증으로 주장하지 않는다.

seed 통과율에는 양측 95% Clopper–Pearson 구간을 함께 보고한다. 같은 seed의 세 궤적은 공통 난수 계보와 RF를 공유하므로 60개를 독립 시행으로 단정하지 않는다. 거울해는 발생 궤적 수/60과 passage별 실제 건수, “20 seed 중 어느 궤적에서든 발생”의 seed 단위 비율·구간을 보고한다. 독립 60회라면 0건의 단측 95% 상한이 약 4.9%라는 산술을 사용하더라도, 이를 이번 자료의 보장으로 쓰지 않는다.

M6에서는 H3가 seed 11·12·14의 XY 정확도 한도를 넘은 이력이 있다. M7은 자기 초기화·자체 gate·조건별 Q가 달라 재생 전 결과를 확정할 수 없지만, 무결성 개선과 정확도 실패가 함께 나타날 가능성을 사전에 기록한다. 어느 방향으로 나오든 궤적별 +25%·pooled +10%, N_joint≥18/20 및 거울해 0 기준을 유지한다.

M7의 실행 완료, 검사 통과, 독립 검토 완료, 동결 수치 통과와 최종 채택은 각각 구분한다. 이 계획서의 게시 상태는 **PLAN_ONLY · EXECUTION_HOLD**다.
