## 관측된 개선

- **B · B0.** E0는 세 궤적에서 heading RMSE를 46.7–72.3%, XY RMSE를 83.0–87.9% 줄였다. R5의 종료 XY 오차는 81.3 cm → 2.4 cm였다.
- **B · L2.** E0는 세 궤적에서 heading RMSE를 91.1–97.4%, XY RMSE를 95.6–98.5% 줄였다. E0의 종료 자이로 바이어스 추정값은 R2/R4/R5 각각 +0.200/+0.189/+0.199°/s였다. R5의 종료 오차는 heading 53.61° → 0.22°, XY 7.53 m → 2.29 cm였다. L2 R4/R5는 2단계와 같은 재생성 A2 입력으로 비교했다.
- **A · B0.** E0는 R2와 R4의 두 RMSE를 줄였다. R5에서 E0의 추정 heading RMSE는 2.63° → 2.93°로 늘었고, XY RMSE는 45.41 → 34.56 cm였다. E1은 R5의 heading과 XY RMSE를 DR 대비 각각 56.7%와 73.5% 줄였다. R5의 5초·10초 paired block bootstrap 95% 구간은 E0−DR의 두 지표 모두에서 적어도 한 블록 길이에서 0을 포함했고, E1−DR은 두 지표와 두 블록 길이 모두에서 0 아래에 있었다. E1 R5의 Pose95는 55.9%였다.
- **E3의 정확도와 coverage.** B · B0 R2에서 E3의 두 RMSE는 E0보다 낮았고, Pose95는 94.7%에서 45.8%로 내려갔다. 같은 궤적의 DR Pose95는 100%였으며, heading 95% 구간 반폭 중앙값은 DR 21.53°, E0 2.36°였다.

## 재현 증거

5초·10초 paired moving-block bootstrap은 길이별로 1,500회 수행했다. E0−DR은 각 RMSE 지표에서 9개 조건·궤적 조합 중 8개의 두 95% 구간이 모두 0 아래에 있었다. 구간은 각 기록 내 시간 의존성을 반영하며 비교는 기존 동결 입력에 한정한다.

54개 EKF trace의 체크섬과 evaluator 시간·패킷 ID를 확인하고 보관 점수를 재계산했다. 이전 E0 posterior에서 한 스텝 운동 전파한 결과는 모든 저장 E0 prior와 일치했다. `RESULTS.json`에 전체 점수, DR 대비 변화율과 구간, 입력 및 출력 해시와 실행 명령을 저장했다.
