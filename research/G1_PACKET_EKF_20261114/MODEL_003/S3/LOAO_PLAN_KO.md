# G1-MODEL-003 S3 LOAO 실행 정의

G-T1 A/B/C만 사용한다. G-T2와 G-V는 봉인 상태로 둔다. S1에서 OR이 O30으로 확정됐으므로 수치 계산은 공유하고 두 체인 이름과 일치 사실을 함께 기록한다.

- 학습 anchor 두 개의 S2 C1–C8을 사용한다. 30 dB에서 개발하며 고정된 구조를 20 dB에서도 민감도로 보고한다. 각 bias 수준에 두 부호와 20개 seed를 적용하고 모든 arm에서 초기 오차, 센서 증가량, RF를 공유한다. 원본 EKF4 초기 표준편차를 따른다. TB3의 `k_r` 초기 평균은 0, 사전 표준편차는 두 실측 scale 중 큰 값 0.0085°/°를 공통 적용한다. TB3 정지 bias를 해당 단계의 b_g 참값으로 기록한다. 입력 회전량은 packet gyro 회전량의 절댓값을 사용한다.
- TEACH→REPEAT는 동결 timeline의 주행 재시작 위치로의 알려진 강체 좌표 변환으로 처리한다. 모든 arm에서 같은 좌표 변환을 적용하고 필터 오차와 공분산, gyro bias 및 feature 기억을 이어간다. P-B와 C1–C4는 각각 독립 주행이다.
- R4와 J4의 백색 모델 분산은 C2의 거리별 표준편차를 G-T1 학습 거리의 pose 수로 가중해 합산한다. J-V의 s에는 C2 거리별 분산을, J-C의 거리별 s/range에는 C2 분산을 정상 분산으로 쓴다. J-C와 J-CS의 색잡음 전이는 사양의 이동거리·절대 회전량 지수식으로 계산하며 C3의 채널별 적합값을 사용한다. 모든 arm의 백색 R에는 C1 열잡음 분산을 더한다. M1-R은 prior XY의 거리 방향 분산을 쓰며, 그 위치 의존성을 고정한 편미분으로 선형화한다. s의 5점 적분 분산을 R에 더한다.
- J-CS는 C4 TEACH↔REPEAT 상관을 [0,1] 내에서 사용해 C2 s 분산을 공통 site 성분과 동적 성분으로 나눈다. 독립 표준정규 Schmidt site 상태에 해당 site의 표준편차를 곱해 관측에 연결한다. TEACH/REPEAT는 station ID, P-C 및 P-B는 진행거리 구간 ID를 쓴다. 구간 간 site 공분산은 0으로 둔다.
- J-CI는 사전 상태와 RF의 정보 가중치 0.5/0.5로 계산한다. +K는 S2 C5에서 학습 anchor의 유효 5 m 창을 합친 모집단 분산을 경로당 고정 Schmidt 분산으로 추가한다. C5 평균은 관측 또는 상태 중심값에 반영하지 않는다. J4, J-V, J-C, J-CS, J-CI와 각 +K를 비교한다. R4 및 DR은 대조다.
- 95% 포함률은 heading의 1차원 정규 구간과 XY의 2차원 카이제곱 타원으로 계산한다. bootstrap은 2,000회, seed 20261118, 조합별 site와 공통 sensor seed를 재표집한다. 재방문은 같은 bootstrap 단위다. 검출 실패와 NIS로 s를 사용하지 못한 횟수를 s 기각에 포함하고 각각도 기록한다. 패킷 수는 인접 checkpoint 구간별로 집계한다. 마지막 checkpoint 뒤의 packet은 그 checkpoint의 site 집계에 포함한다.
- LOAO 세 조합 모두가 참여하는 B 방식 §4 판정을 적용한다. 20 dB는 보고용이다. 사양의 L1 RMSE 및 단순성 기준으로 OR의 통과 arm을 고른다. 통과 arm이 없으면 DEV_FAIL로 기록하고 봉인을 유지한다.
