# G1-MODEL-003 G6 재생성 계획

S0 동결은 `924222dd797e47b7885f8a006b18a4dc7419b31c`다. [사양 §1.0.4](../SPEC_B_NEW_RT_KO.md#10-g6-처리-s1-선행)에 따라 G-T2 × B/C의 확인 자료를 별도 경로에서 재생성한다. 두 조합을 포함한 S4의 여섯 조합을 유지한다. 기존 생산 봉인 `4d755c9a016275f2ba51fee02e9908fe8cb2a27f32c187192f00bc957c45ee4a`와 두 G6 FAIL 기록을 보존한다.

## 근거

- 전체 G6 재검증에서 유한 반사면 매칭 실패 4건이 남았다. G-T2_B task 1708, G-T2_C tasks 1025·1840·2477이다. 매칭된 경로의 최대 지연 잔차는 0.0270728 ps였고 한계는 0.05 ps다. [G6 재검증](../../G1_RT_TB3_CORRIDOR_20261113/evidence/G6/G1_RT_TB3_G6_REVALIDATION_20261114T144337Z_gPzl3x/RESULT_KO.md)
- 사양의 위상 한계 개정 조건은 미충족이다. 최대 |Δs|는 0.00011442539였고 첫 경로 index 일치율은 100%였다. 개정 조건의 |Δs| 한계는 0.00005다. [관측 민감도](../../G1_RT_TB3_CORRIDOR_20261113/evidence/G6/REINVESTIGATION_KO.md#관측량-민감도)
- 네 위치에서 솔버 좌표를 그대로 써도 정확한 이미지 교점은 개구부 안에 놓였다. 동결 솔버의 광선 원점·목표 오프셋을 적용한 계산은 솔버의 벽 교점 x 좌표를 최대 0.00868 mm 차이로 재현했다. 9개 XY와 17개 노드로 실행한 탐색 검사에서 사전 확인한 네 경로만 유한 면 검사에서 제외됐다. 두 계산은 G6 전체 판정을 대체하지 않는다.

## 개입과 판정

1. G0/G7 형상·RF pose, F1 솔버·seed, 17 node, Method B, FFD, 지연/이득 계산 및 near export 조건을 유지한다. G-T2 × B/C 각각 2,818 XY, 6,072 pose를 별도 생성한다. 원래 생산 봉인 파일은 재생성 프로세스에 연결하지 않는다.
2. 각 XY에서 기준 주파수 노드의 정반사 경로를 해당 메시의 연결된 유한 반사면과 대조한다. 순서 있는 반사면 ID가 17개 노드에서 모두 일치해야 한다. 정확한 이미지 교점이 면 밖에 놓인 경로만 H/near 합성 전에 제외한다. 다른 형상 오류나 잔차 0.05 ps 초과는 실행을 실패 처리한다. 유효 경로의 지연, 계수, 정렬 순서는 그대로 사용한다. 제외 지점과 경로는 각 trace receipt에 기록한다.
3. 모든 XY·pose·주파수 노드의 완전성, 기존 생산과의 경로 수/노드 대조, 4개 위치에서 각 1개 제외, 잔차 ≤ 0.05 ps, 조립 후 G4 및 near export/LoS 재합성, pose 해시 일치를 검사한다. 영향을 받지 않은 7개 G6 조합의 해시가 확인된 기존 재검증 기록을 결합한다. 4개 위치는 동결 G3 및 DIAG G3 표본과 겹치지 않는다. 기존 G3 표본에 경로 제외가 없음을 확인하고, 변경된 네 위치에서 G3a/b/c의 동결 비교식과 문턱을 전 주파수 및 실제 pose에 추가 적용한다.
4. 재생성 파일은 조립 직후 별도로 봉인한다. G4, G6, G8, G9 및 추가 G3 검사가 모두 통과한 경우 두 교체 증거와 나머지 네 기존 조합의 봉인 출처를 S4 입력 명세에 명시한다. 기존 파일이나 봉인을 덮어쓰지 않는다. S1 전에는 결과를 G6 진입 판정에만 사용한다. 확인 데이터의 heading·포함률·오염도는 산출하지 않는다.
