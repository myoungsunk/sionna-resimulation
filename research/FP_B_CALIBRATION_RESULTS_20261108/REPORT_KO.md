- 원본 고정: R2(979)·R4(742)·R5(1415), B0 Full sensor seed10, 3,136시점. 원본 SourceFFD/W0, 운동 입력·Q·초기상태 고정, K1/K2 미사용
- 입력 NPZ·FFD SHA 통과, 원래 native/B 상태·공분산·게이트 재현 통과, 경로별 학습·폐루프 계산·저장 결과 재산술 감사 통과
- **주의**: 하나의 복도와 seed10. 신규 보정의 경로 분리는 성립하지만, 과거 native 보정값(`muMB`, `muBASE`, `R`)의 원래 적합 데이터가 독립이라는 증명은 없다.

## 1. 보정 정의

- route-held-out: R2 평가 때 R4+R5로 학습. R4, R5도 각자의 평가 경로를 제외한 나머지 두 경로로 학습.
- `delta_mu` = 각 학습 경로의 B−Native range/편파 관측 차이 평균을 경로 균등 가중. `muMB`와 `muBASE`에 동일하게 가산. 실시간 EKF에 참값 입력 없음.
- `delta_R` = 학습 경로에서만 `z - h(x_true) - muMB`의 잔차 공분산을 계산하고, B와 native 공분산 차이 중 양의 대각 성분만 기존 `R(t)`에 추가. 전체 2×2 양의 고유값 부분(PSD) 실험도 민감도 대조.
- 실험군 사전 고정: native 원본 / B 원본 / B 평균 / B 대각 분산 / B 평균+대각 분산 / B 평균+전체 공분산. 결과에 따른 파라미터 재튜닝 없음.

| 평가 경로 | 학습 경로 | 적용 Δμ_range | 적용 Δμ_s | 추가 R_range,range | 추가 R_s,s |
|---|---|---:|---:|---:|---:|
| R2 | R4, R5 | −4.617 cm | −0.001172 | 0.005619 m² | 0 |
| R4 | R2, R5 | −3.128 cm | −0.003090 | 0.006269 m² | 0 |
| R5 | R2, R4 | −4.437 cm | −0.000387 | 0.006239 m² | 0 |

## 2. 전체 pooled 평가 (3,136시점)

| 구성 | Heading RMSE | XY RMSE | 평균 NEES3 | Pose95 포함률 | XY95 포함률 |
|---|---:|---:|---:|---:|---:|
| Native frozen | **0.9954°** | **6.6246cm** | **3.99** | **88.8%** | **90.4%** |
| B frozen | 1.5566° | 12.8090cm | 25.12 | 46.1% | 43.9% |
| B + 평균 | 1.0246° | 11.1785cm | 23.27 | 10.9% | 31.3% |
| B + 분산 | 1.3904° | 11.1723cm | 18.41 | **58.2%** | **56.4%** |
| B + 평균·분산 | **0.9992°** | **10.1309cm** | **14.48** | 30.3% | 50.4% |
| B + 평균·전체 공분산 | 1.0062° | 10.2743cm | 14.47 | 27.9% | 50.3% |

최대 pooled RMSE 이득은 **B+평균·대각 분산**: 기존 B 대비 Heading RMSE 35.81% 감소, XY RMSE 20.91% 감소. 하지만 Native보다 Heading 0.004° 불리하고, XY 3.51cm 불리하다.

**신뢰도 경고:** Pose95 포함률은 B 46.1%에서 평균·분산 보정 시 **30.3%로 더 악화**했다. 평균 NEES 감소를 전체 신뢰도 향상으로 오인해서는 안 된다. 분산 단독 보정은 Pose/XY95가 개선되지만 RMSE 개선 폭은 작다.

## 3. 경로별 비교: 고정 보정 채택 보류

| 경로 | B 원본 Heading / XY | B 평균·분산 Heading / XY | 평가 |
|---|---|---|---|
| R2 | 2.1616° / 18.027cm | **0.9422° / 9.713cm** | 둘 다 개선 |
| R4 | **1.2623° / 10.622cm** | 1.3550° / 11.616cm | 둘 다 악화 |
| R5 | 1.1411° / **8.922cm** | **0.7973°** / 9.562cm | Heading 개선, XY 악화 |

R2 단독만 보면 매우 성공적이지만, R4·R5 반례로 인해 **B 고정 보정의 경로 일관성은 입증되지 않았다**. B+전체 공분산도 R4/R5 XY 문제를 해소하지 못한다.

## 4. 메커니즘 및 한계

B와 native의 tap이 다른 시점은 572/3136 (18.24%). 나머지 2,564시점에서는 두 방법의 관측 자체가 같다. 그러나 본 파일럿의 평균 보정은 **모든 시점에 동일한 양**을 가산하므로, 원래 동일한 정상 관측에도 보정이 적용되어 다른 경로에서 오차가 커질 수 있다. 이는 가능한 설명이지 인과 확정은 아니다.

| 평가 경로 | 실제 평균 B−Native range | 다른 두 경로로 학습한 보정량 |
|---|---:|---:|
| R2 | −2.948cm | −4.617cm |
| R4 | −5.926cm | −3.128cm |
| R5 | −3.308cm | −4.437cm |

경로별 관측 차이 분포가 달라 전역 보정 평균의 불일치가 확인된다. 또한 route-held-out은 동일 복도·시드에서의 탐색적 평가라 환경 일반화 근거가 아니다. B 오차의 위치·거리·heading·다중경로 잔류와 시간상관, 기존 native용 μ/R의 선행 학습 데이터 분리를 이후 반드시 검증해야 한다.

## 5. 추가 감사

원본 아티팩트 61개 ZIP CRC 검사, 경로별 결과/코드 산출물 SHA 검증, 3,136시점의 저장된 위치·Heading 제곱오차로 RMSE 재계산, 수용 마스크 및 공분산 PSD·대칭성 검산 통과. 최대 집계 MSE 차이는 6.94×10⁻¹⁸. SourceFFD를 외부 환경에서 새로 독립 실행한 감사까지는 수행하지 않았다.

조건부 시간상관 민감도 참고: 같은 3경로 내부에서 5초(25프레임), 10초(50프레임) moving-block paired bootstrap 1,500회. B 평균·분산 보정의 Heading RMSE 개선율 5초 블록 95% 구간 29.4~42.2%, 10초 블록 27.5~43.3%; XY 개선율 5초 8.6~29.3%, 10초 4.5~31.5%. **이 구간은 세 경로·같은 시드에 조건부이며 신규 경로/환경 일반화 신뢰구간이 아니다.**

## 6. 다음 연구 권고

**우선 B 보정이 효과를 내는 원리는 확인되었으나 운영 채택 보류.** 다음 실험은 표본 전체에 상수를 적용하는 방식 대신, B/native FP 차이, RX별 edge 신뢰도·CIR 전력/시간 특징, state sensitivity 등의 **현재 온라인에서 관측 가능한 정보**로 평균 오차와 R을 조건부 추정한다. 검출기 선택 정책은 그대로 B-only로 유지한다. 별도 환경·시드·경로에서 성능/NEES/포함률을 평가하고, 교차검증 결과를 보고 사후 임계값을 선택하는 것은 금지한다.
