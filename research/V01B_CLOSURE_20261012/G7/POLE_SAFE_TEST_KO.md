# Pole-safe `s` 모델·Jacobian 적용 — G7 근거리 수치 민감도 가설 검증

날짜 2026-10-12. 모델 `CARTESIAN_FIELD_DEG4_CORE2_BLEND2_3_FP_V2`(P0 복구, 계수 SHA 87a38e9c…)를 동결 필터의 `s_model` 자리에 넣고(`scripts/g7_pole_build_note.txt`) 민감도가 큰 3개 조건(R2_aA_m0, R5_aA_m0, R5_aB_m0)을 3종 교란으로 다시 돌렸다. 각 재생 1,800회(3조건 × drift 3 × seed 50 × arm 4). 이 모델은 앵커 천정각 θ<3°(수평거리 약 0.115 m 이내)에서만 원래 LUT와 다르다. 원본 LUT는 변경하지 않았다.

## 가설
- **H1**: G7 재생의 비트 수준 불일치는 원래 LUT의 극점(pole) 특이성 때문이다. → 예측: pole-safe 모델에서 불일치 run 수가 크게 줄고 첫 분기 위치가 극점 구간이다.
- **H2**: 불일치는 로봇(의 추정 위치)이 앵커 축 근처를 지날 때의 기하학적 증폭이다.

## 결과
| 비교 (3개 조건, 1,800 run) | 불일치 run (3지표 중 하나 > 1e-9) | 조건별 |
|---|---:|---|
| 원본: 기본 vs 커널 변경(A–B) | 247 | R2_aA 150 / R5_aA 48 / R5_aB 49 |
| 원본: 기본 vs ±1 ulp(A–C) | 262 | 150 / 62 / 50 |
| **pole-safe**: 기본 vs 커널 변경(PA–PB) | **251** | 150 / 39 / 62 |
| **pole-safe**: 기본 vs ±1 ulp(PA–PC) | **259** | 150 / 48 / 61 |
- **H1 기각(이 데이터 기준).** pole-safe 모델을 써도 불일치 수가 그대로다(247→251, 262→259). 각 교란에서 accept/reject 판정이 바뀐 run은 두 모델 모두 0건이다.
- 첫 분기 시점의 **참 위치** 수평거리 중앙값은 두 모델 모두 0.52 m(사분위 0.52–0.55). **추정 위치** 수평거리는 중앙값 0.19 m(사분위 0.14–0.34, 최소 0.06–0.09 m)이고 약 10 %만 극점 원뿔(0.115 m) 안이다. 즉 분기는 극점 원뿔 바로 바깥(θ≈4–5°)에서 시작하는 경우가 대부분이어서 pole-safe 모델이 바꾸는 영역(θ<3°)과 겹치지 않는다.
- **H2는 위치 효과로는 지지**된다: 추정 위치가 앵커 축 가까이(0.14–0.19 m) 있을 때 첫 분기가 일어난다. 기전(곡률 증폭 등)은 분리하지 못했다. R2_aA_m0 arm D 150회 중 129회에서 추정 위치가 극점 원뿔(0.115 m)에 들어간다(참 위치는 0.40 m 이상 유지). 참 위치만 보고 "R2는 극점을 안 지나므로 pole-safe와 무관"이라고 한 직전 설명은 **틀렸다**.

## 결론과 한계
- G7의 환경 간 비트 불일치(309/4,200)는 pole-safe 모델 적용으로 줄지 않는다. 엄격 재현성 FAIL 판정은 바뀌지 않는다.
- pole-safe 모델은 앵커 극점 근처에서 원래 LUT의 NEES 과대를 줄이므로 정식 Stage C/B 비교 기준선에 반영하는 것이 맞다(파일럿에는 아직 미연결).
- 3개 조건·150 seed 규모의 한 복도 시뮬레이션이다. 증폭 기전은 가설 수준이며, 첫 분기 위치와 상태 불변 판정만 관측했다.
