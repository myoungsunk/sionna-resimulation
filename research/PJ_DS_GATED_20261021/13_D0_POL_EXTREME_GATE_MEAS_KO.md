# d0 기반 편파 극심 게이트: 측정 수준 평가 (재귀 이전, 2026-10-22)

정의: d0 = s_Full(fp) − s_LUT(fp; x̂⁻) (2종 Δs의 fp 값). x̂⁻ = range 보정(MU_R_EXDS: 1종 Δs 포함 HGB range 평균 보정) 필터의 1차 예측 상태. d0 = 그 필터의 편파 innovation + μ_s (QA 4.5e-15). 분해: d0 = e_s + 상태 오차 부분 [s_LUT(GT) − s_LUT(x̂⁻)].
데이터: 저장된 per-step 시계열(run 39574195919, 39582073787, 39586037715), Full B0·L2, t≥30, 12,402 step(7 case×2). 새 시뮬레이션 없음. 스크립트 `d0_gate_meas.py`, 결과 `results_d0gate/`.
편파 극심 정의: |e_s| 상위 10%(≥0.216), 상위 5%(≥0.361).

## 3. heading 오차로 인한 오기각 위험
- 기각 패킷 중 상태 오차 부분이 e_s보다 큰 비율: 3–5% (B0·L2 동일). 기각 패킷의 prior heading 오차 중앙값 0.72–0.81°(전체 0.71–0.74°).
- 상태 오차만으로 3% 임계(0.49)를 넘기려면 heading 오차가 |∂s/∂ψ| 중앙값(0.010/deg)에서 약 49°, 상위 1%(0.046/deg)에서 약 11° 필요. 현재 prior 오차(약 0.7°)에서는 안전, 초기화·발산처럼 heading 오차가 10° 이상이면 정상 편파 갱신을 막을 수 있다.

## 4. 한계
- d0 게이트는 편파 innovation 크기 게이트(고정 절대 임계)와 같다. 측정 수준에서 들어가는 편향만 평가했고, 기각이 이후 prior를 바꾸는 재귀 효과는 보지 않았다.
- 편향 질량 감소가 heading 개선으로 이어지는지는 재귀에서 확인 필요(앞서 편파 평균 보정은 측정 개선 0.71이 재귀 heading 1.27로 뒤집혔다).

## 5. 게이트 외 사용처 점검 (2026-10-22)
- d0를 그대로 편파 평균으로 넣으면(μ_s = d0) ν_s = 0이 되어 편파 채널의 정보가 0이 된다. |d0| ≈ |e_s|인 이유가 상태 오차 부분(heading 신호)이 작기 때문이므로, d0를 빼면 heading 신호도 같이 빠진다. μ_s = α·d0는 그 패킷의 이득을 (1−α)배로 줄이는 것과 같다(연속 게이트).
- d0를 μ_s 모델의 학습 라벨로 쓰는 경우(정답 없이 학습): 특징 = 1종 Δs 8 + 2종 모양(측정 − LUT(x̂⁻)) 8 + log fp power, HGB, route 제외. e_s 설명 R²: 정답 라벨 0.536 / d0 라벨 0.548 (B0), 0.528 / 0.541 (L2). 두 예측 상관 0.974. 예측과 상태 오차 부분의 상관 0.012 (특징이 상태와 무관해 heading 신호를 흡수하지 않음). 라벨 잡음(d0 − e_s) RMS 0.036.
