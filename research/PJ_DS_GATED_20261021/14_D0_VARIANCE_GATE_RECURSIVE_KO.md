## 구현
- 매 패킷, 각 arm이 자기 prior에서 |d0| = |s − h_s(x̂⁻)| 계산(온라인).
- |d0| 분위 경계(80/90/95/99%)와 계층별 배율 κ = 실제 잔차 분산/POWER 분산(≥1)은 다른 두 route에서 산출(`d0_var_calib.json`). κ_s: 95–99% 4.7–5.6, >99% 15–17. κ_r: 95–99% 1.6–5.1, >99% 3.0–12.0.
- (b) B_INFL_S: V_s×κ_s. B_GATE3/5: |d0| > 상위 3%(0.45–0.51)/5%(0.34–0.41)이면 편파 채널만 기각(V_s×1e6). (c) C_INFL_R: V_r×κ_r. 평균은 POWER 그대로(MU_R 조합 arm만 range 평균 = HGB 기존+Δs).

## 해석
1. 측정 수준 정합(s95 0.956→0.99)은 개선되나 재귀 heading은 개선되지 않는다(중앙값 1.007–1.046, 5 case >10% 악화). NEES는 4.4→5.2–5.8로 오히려 나빠진다.
2. 기각·하향된 극심 패킷의 정보 비중은 원래 작다(POWER V_s가 이미 큼; 정보 가중 비중 0.1–1.2%). 정보 가중 heading 환산 편향: 기각 패킷만 +5.5°(R2 A M45), +17°(R2 B)로 나머지와 반대 부호 → 제거하면 남은 편향이 커짐(R2 A M45 −0.13→−0.20°, R2 B −0.27→−0.39°). R4 A는 같은 부호라 개선(+0.11→−0.02°). range 보정에서 본 상쇄 해제와 같은 구조.
3. (c) |d0| range 상향은 Δs 기반 INFL_R보다 약하다(거리 1.000 vs 0.975, radial 1.004 vs 0.972). 이득은 R2 A 두 case(0.84–0.96)에 한정.
4. range 평균 보정과 묶으면 (b)+(c)가 heading 중앙값을 1.155→0.997로 되돌리면서 거리오차 0.649(14/14 개선)와 위치 xy 0.935를 유지한다. 단 heading 분포가 갈린다: R2 A M45 2.35/2.44, R2 B 1.61/1.86 악화; R5 B 0.77, R2 A M0 0.86–0.93, R5 A 0.94–0.96 개선.
