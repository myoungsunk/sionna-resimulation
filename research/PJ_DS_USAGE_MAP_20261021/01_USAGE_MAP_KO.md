## 2. 상태 관측으로서의 성질
- **ψ 독립성:** \(\Delta s_{+1}\)을 \([h_s(\mathrm{GT}), g=\partial h_s/\partial\psi, g^2]\)로 설명하는 R² 중앙값 0.03(0.007–0.117), corr(Δs, g) −0.19–0.01. Δs는 heading과 거의 무관하고 편향과 관련된다 → Step 2의 ψ–β 혼동을 푸는 관측 조건을 만족.
- **시간 구조:** 상관시간 Δs₊₁ 0.7–3.5 s(중앙값 1.65), \(e_s\) 0.8–6.8 s(중앙값 3.0). Δs가 편향보다 빨리 변한다 → Δs 관측 잡음에도 시간상관이 있고 편향보다 짧다. (참고: \(e_r\)은 5–31 s로 매우 지속적; 비중심 정의라 평균 오프셋 포함.)
- **LoS 기준선:** LoS |Δs₊₁| 중앙값 0.005–0.013 (Full 0.015–0.027, 2–3.5배 작음). 단일 경로라도 0이 아니다 → 포트별 안테나 주파수 응답(분산성) 때문에 pulse 모양이 포트마다 조금 다른 것으로 해석. SourceFFD로 \(\Delta s\)의 LoS 기준값 \(h_{\Delta s}(x)\)를 예측해 빼면 다중경로 성분만 남길 수 있다(미검증).

## 3. 해석
- Δs의 고유 가치는 **부호**에 있다: 편파 편향의 부호(μ_s, β_s)와 range–편파 오차의 공동 부호(\(C_{rs}\)). 두 경우 모두 기존 특징으로는 거의 설명되지 않는다(R² 0.01, AUC 0.54).
- 크기(분산, 오염 여부)는 기존 특징이 이미 더 잘 설명한다. Δs는 학습 없이 쓰는 오염 지표(AUC 0.75–0.81)로서만 추가 가치.
- range 편향은 기존 특징으로 이미 크게 설명된다(pose 0.56, 저주파 0.59). 현재 POWER1 μ_r(0.20/0.37)이 이 정보를 쓰지 않고 있다는 부수 발견.
- 선형 결합에서 기존+Δs가 Δs 단독보다 낮은 경우(e_s 0.27 대 0.41)는 기존 특징이 route 간 분포 차이에 취약하기 때문으로 보이며, 비선형 모델에서는 결합 이득이 크다(0.52, 저주파 0.58).

## 4. 지도에서 나오는 다음 후보
1. Step 3: β_s 상태 + Δs 관측(\(\Delta s=\beta_s/\lambda+n\)), ψ 독립성 확인됨.
2. μ_s를 Δs 기반(비선형)으로 교체: 저주파 R² 0.03 → 0.58 잠재.
3. \(C_{rs}=\rho(\Delta s)\sqrt{V_rV_s}\): 부호를 Δs로 조건화.
4. μ_r를 기존 특징으로 확장: 저주파 R² 0.37 → 0.59–0.74 잠재.
