# Δs 양상별 heading·ranging 개선 (필터 없음, 2026-10-21)
패킷별 개선량(양수=개선), route-heldout HGB: 전체 효과 = POWER1 대비 기존+Δs, Δs 고유 효과 = 기존 대비 기존+Δs. heading은 \(|r_s/g|\)(°, \(|g|\ge0.4\) 패킷만), ranging은 \(|r_r|\)(cm).
층화: case 내부 \(|\Delta s_{+1}|\) 5분위, \(\Delta s_{+1}\) 부호, \(\Delta s_{+1},\Delta s_{+2},\Delta s_{+4}\) 부호 일관성.
핵심: Δs 고유 효과는 heading에서 상위 5분위(대략 \(|\Delta s_{+1}|\gtrsim0.04\))에 집중(평균 +4.4°, 중앙값 +1.8°, 개선 비율 0.67; Q1–Q3는 0 근처), ranging에서는 전 구간 소폭이며 |Δs|와 함께 증가(Q1 +0.32 cm → Q5 +1.01 cm). 두 경우 모두 7/7 case에서 Q5>Q1. 부호와 offset 일관성은 영향 작음.
