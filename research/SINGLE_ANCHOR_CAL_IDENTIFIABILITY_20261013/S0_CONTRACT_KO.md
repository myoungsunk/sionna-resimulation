# S0 확정 계약 — 2026-10-13 사용자 지정

상태: **정의 확정 / 신규 S0 posterior 구현·실행 NOT_RUN**.

이 문서는 이전 I2 보고·인계의 “S0 gauge·초기 위치 범위 사용자 입력 대기”를 해소한다. 과거 실행 당시의 NOT_RUN 기록과 동결된 설계·결과·해시 목록은 수정하지 않는다. 추가 사용자 수치 범위 없이 아래 정의로 구현 설계를 진행할 수 있다. 실용적 운용 오차 요구는 여전히 미정이다.

## 공통 정의

S0는 초기 절대 위치와 절대 Heading의 외부 prior가 없는 조건이다. 알려진 것은 앵커 위치·높이, 로봇 높이, 운동학적 구조와 센서 모델이다. Gauge는 관측 불가능한 좌표 자유도만 제거하며 관측 가능한 미지수를 고정하지 않는다. Calibration prior는 실험 전에 동결된 것을 사용한다. Truth는 생성·평가에만 접근한다. S1은 기존 초기 pose prior를 유지한다.

## 센서별 gauge

| 구성 | Gauge | 추정할 미지수 |
|---|---|---|
| A: IMU + Wheel | 초기 로봇 좌표계 (0,0,0) | Calibration과 상대 궤적 |
| B: IMU + Wheel + Ideal Range | 앵커 수평 좌표 원점, 초기 방사방향 +x | 초기 수평 반경 rho0, 상대 Heading delta0, Calibration |
| C: Full RF | RF likelihood의 회전 대칭성을 먼저 검사 | 대칭성이 깨지면 초기 방위각 포함 |
| F: Range + 편파 s | 편파·안테나 모델의 대칭성을 먼저 검사 | 식별 가능한 방위각 포함 |

B의 초기 상태는 `[rho0, 0, delta0, bg, SFg, eps_w]`이다. y0=0은 회전 gauge이고 rho0를 참 초기 반경으로 고정하거나 delta0를 참 상대 Heading으로 고정하지 않는다. delta0는 Uniform(-pi, pi]이다. 반사 모호성은 회전 gauge로 제거하지 않으며 posterior에 남을 수 있다.

## 최초 Range 기반 초기화

균일한 2D 공간밀도를 참조측도로 선택한다. 첫 noisy range z0, 알려진 높이 차 dz와 sigma_r에 대해

```text
p(rho0 | z0) ∝ rho0 * exp(-(z0 - sqrt(rho0^2 + dz^2))^2 / (2 sigma_r^2)), rho0 >= 0.
```

이 선택은 유일한 무정보 prior라는 주장이 아니다. 임의로 좁은 반경 경계를 두지 않으며, 다른 반경 참조 prior와 계산 영역/꼬리 처리에 대한 민감도를 반드시 확인한다. 대안 prior의 종류·정규화·계산 정밀도 및 비교 기준은 신규 결과를 보기 전에 기록한다. 무한 반경 정의를 수치 유한 영역으로 구현한다면 누락 질량 및 영역 확장 민감도를 증명해야 한다. 이는 추가 위치 정보를 주는 물리적 경계로 해석하지 않는다.

최초 range를 위 초기 posterior에 사용하면 필터 갱신에서 같은 관측을 다시 사용하지 않는다. Batch는 공간 참조측도와 첫 likelihood를 각각 한 번 쓰거나 동일 초기 posterior를 사용하는 동등한 표현을 사용한다. PF와 batch에 서로 다른 초기 정보를 제공하지 않는다. DR 대조군은 range 기반 초기화를 받지 않는다.

## 단계별 적용과 평가

- I1: pose prior 없이 실제 gauge를 제거한 정보행렬·nullspace를 분석한다. 기존 I1 결과가 이 계약 전체를 검증했다고 소급 표시하지 않는다.
- I2: 첫 Range 확률적 초기화, 반경 prior·계산 영역 민감도, PF/batch 수렴을 검증한다. 기존 S1 개발 결과와 별도 실행 폴더를 사용한다.
- I3: 같은 S0 초기정보와 관측 horizon을 모든 추정기에 제공한다. Uniform Heading이나 다봉 posterior를 단일 Gaussian으로 바꾸면 근사와 표현 한계를 명시한다.
- I4: Ideal Range 초기 likelihood를 Full RF에 재사용하지 않는다.
- I6: 편파가 회전 대칭성을 깨는지 검사한 뒤 gauge를 결정한다.

위치 평가는 gauge-invariant 상대 궤적오차 또는 명시한 한 번의 전역 정렬로 수행한다. 시점마다 정렬해 오차를 제거하지 않는다. 정렬은 평가 전용이며 추정기에 truth를 전달하지 않는다. Calibration 오차는 gauge와 무관하게 직접 평가한다.
