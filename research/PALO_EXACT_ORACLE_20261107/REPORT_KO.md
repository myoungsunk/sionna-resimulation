# PALO-ORACLE-001 실행 결과

범위: 선택적 편파 사용의 가능성을 탐색하는 진단 대조. R2 / anchor B / seed0의 LoS·Full × B0·L0·L1·L2. 7정책, 총 56개 폐루프 궤적, 각 979시점 중 t>=40의 779시점 평가.

동결 LUT를 각 정책 자신의 prior에서 재평가하고 선택한 상태와 공분산을 다음 시점으로 전달했다. 즉시 오차 감소를 참값으로 선택하는 greedy oracle이며 전체 궤적 최적해나 성능 상한이 아니다.

## 해석 및 한계
Heading 선택 오라클의 큰 개선은 유용한 갱신을 선택할 가능성을 보여준다. 그러나 참값을 사용하며 온라인 판별 가능성·독립 환경 일반화는 입증하지 않았다. XY만 선택한 오라클은 Heading이 기존 S4보다 악화된다. Heading 오라클의 NEES는 1보다 매우 낮다. NEES 감소 자체를 공분산 보정/일관성 달성으로 해석하지 않는다. 시점들은 상관되어 있으며 통계적 보장 없음.

## 수정·실행 기록
전달 실행기의 4상태 예측에 2x2 Q를 넘기는 결함으로 첫 실행 중단. 실패 로그와 계약은 results/ 및 logs/에 보존. v2는 동결 원본 r2_bias_replay.predict_one을 재사용하며 원본 입력 86개 SHA 재확인. numpy2.2.4/scipy1.15.2 동결 환경 사용. 시작 전 S4 8조건 모두 통과한 후 오라클 실행. RF 오염 oracle(다음 우선순위)은 미실행.

실행: python run_exact.py → python check_results.py. run_exact.py는 출력 디렉터리 존재 시 거부하므로 재실행은 별도 사본/새 경로 필요. 입력 provenance는 INPUT_MANIFEST.json, 수학/실험 계약은 results_v2/CONTRACT.json. 종료코드 v1=1, v2=0. 모든 관리 helper 종료 확인.
