# R2 실패 원인 분해 (실행 전 고정, 2026-10-23)

검증 2(run 39885708483)에서 POWER 보존 잔차 보정기 PWIDE는 R2 held 세 case 모두 BASE보다 나빴다(1.26–1.92배). R2 held의 학습 route는 R4+R5이고, 학습 route LORO에서 Δ 설명력은 R² ≈ 0, 잔차 평균 −0.036이었다.

**이 분석은 held route를 직접 보는 진단이다.** 원인 규명에만 쓰고 모델·임계값·선택 규칙을 이 결과로 바꾸지 않는다. 같은 분해를 성공한 R4·R5 held에도 적용해 대조한다.

## 정의 (held 패킷마다, GT 위치·heading에서 정적으로)
- Δ_true = e − μ_OOF (μ_OOF: BASE가 쓰는 held용 POWER, 학습 route 둘로 적합)
- Δ̂_PCIR, Δ̂_PWIDE (d0 = s_F − h_s(GT)): 검증 2의 train-only 모델 그대로
- 잔차 r = Δ_true − Δ̂ (BASE의 잔차는 Δ_true 자체)
- 편향 기여: 가중 편향식의 분자 Σ g r / V_s를 층별로 나눈 몫(g = GT에서의 ∂h_s/∂ψ, V_s = OOF POWER)

## 가설과 검사
| # | 가설 | 검사 |
|---|---|---|
| H1 목표 불일치 | 학습에서는 Δ = e − μ_inner(학습 route 하나로 적합한 약한 POWER)를 배웠는데, 평가에서는 더 강한 μ_OOF 위에 더한다 → 이미 μ가 제거한 오염을 다시 뺀다 | held에서 μ_single(학습 route 하나씩으로 적합한 POWER)을 따로 계산하고, mean(Δ̂)이 e − μ_OOF와 e − μ_single 중 어느 쪽을 따르는지, 그리고 μ_OOF − μ_single의 평균을 비교 |
| H2 거짓 오염 | Δ_true ≈ 0(깨끗한) 패킷에서 Δ̂가 0이 아닌 값을 낸다 | Δ_true 구간별 mean(Δ̂), mean(r), 편향 기여 몫 |
| H3 FP 이동 층 | 특정 FP 이동 층에서 과·소보정 | fp_shift_tap 0 / ±1 / \|·\|≥2 층별 동일 지표 |
| H4 공변량 이동 | R2 특징 분포가 학습 route(R4+R5)와 달라 보정기가 외삽한다 | held vs 학습 route 판별 HGB 분류기(5-fold 교차 예측) AUC와 판별 점수 5분위별 mean(r), 기여 몫 |
| H5 기하 | 앵커 거리·LUT 기울기 크기 특정 구간에서 집중 | 거리 5분위, \|g\| 5분위별 동일 지표 |
| 재귀 확인 | 위 층이 실제 재귀 궤적에서도 기여하는가 | 검증 2의 L_BASE·L_PWIDE 궤적(accept 패킷, 그 궤적의 g)으로 같은 층별 기여 몫 |

## 판정 방식
R2와 대조(R4, R5)에서 각 층의 기여 몫과 평균 잔차를 크기로 비교한다. 임계값 판정은 하지 않는다. R2에서만 두드러지고 대조에서는 작은 층을 원인 후보로 보고한다.
