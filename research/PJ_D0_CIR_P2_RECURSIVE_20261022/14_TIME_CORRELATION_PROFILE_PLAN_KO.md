# 시간상관 영향의 양상 분석 (실행 전 고정, 2026-10-23)

목적: 시간상관을 다루는 해법을 적용하기 전에, 현재 시스템에서 시간상관이 heading 오차와 신뢰도에 어떤 양상으로 작용하는지 정량화한다. v3 단계별 배열(run 39950207483 여섯 case + 재시도 run 39954439738의 R2_aA_m0)만 사용하고 필터를 다시 돌리지 않는다. arm: BASE, CIR, WIDE_NOES, PWIDE_NOES, ORACLE. 평가 시점은 v3 커널을 저장한 t ≥ 30 s의 10 프레임 간격.

| 질문 | 방법 | 양 |
|---|---|---|
| Q1 어느 시간 척도가 heading 오차를 만드는가 | 잔차를 상수 평균 / 30 s 이동평균 − 평균 / 3–30 s / < 3 s로 나누고, 저장된 커널 W(t,k)로 전파 | 채널 MSE 몫, heading MSE 몫, RMS |
| Q2 과신의 분해 | 필터가 믿는 분산 Σ W²R, 실제 대각 Σ W²ε², 실제 (Σ Wε)² | 전체 과신 = R 크기 불일치 × 시간상관(교차항) 배수. 실현 궤적의 항등식 |
| Q3 상관이 시간과 공간 중 어디에 묶이는가 | 시간 격자와 이동 거리 격자(2 cm)의 ACF, 30 s 구간별 τ_e와 1/속도의 상관 | ρ(0.5, 2, 10 s), ρ(0.1, 0.5, 2 m), τ_e(시간), τ_e(거리) |
| Q4 필터 일관성 | 정규화 편파 innovation ν_s/√S의 ACF, Ljung–Box Q(10)(χ²₁₀ 99% = 23.2), gate 거부 연속 길이와 독립 기대값 1/(1−p) | 백색성, 거부 군집 |
| Q5 커널 길이와 상관시간 | L_eff = (Σ|W|)²/ΣW² · Δt, τ_int | L_eff/τ_int (≫1이면 1+2Σρ로 포화) |

합성 AR(0.8) 검사에서 1+2Σρ = 9.1(이론 9.0). 판정 임계값 없이 route × arm × 채널별 크기로 보고한다. 단일 seed(원 seed) 기준이다.
