# CUT_RT: range 갱신의 위치 접선 성분 차단

세계 좌표 장부에서 R2_m45 및 R4_aA의 range 접선 몫이 커서 조건부로 실행했다. 주 분석 여섯 조건, α0/1. B0/L2는 쌍이다. 기존 결과는 변경하지 않았다.

## 개입 정의

현재 packet GT 위치와 앵커로 만든 수평 접선 단위벡터 u_t를 사용했다. 원래 joint Kalman gain의 range 열 중 위치 두 성분에만 (I−u_t u_tᵀ)를 적용했다. Heading/bias 성분과 편파 열은 해당 시점에서 유지했다. 수정 gain으로 상태 갱신과 Joseph 공분산을 계산했고 이후 x/P/H/K는 자연스럽게 달라진다. mask=A_B, 편파 평균과 R, 주행 전파는 원래 값이다. 원래 joint innovation을 쓰며 순차 갱신으로 바꾸지 않았다. GT 축을 사용하는 oracle 진단이다.

- R2_m45: 방위각 gap은 5~16% 확대되어 H2가 방위각 gap의 필요 주경로라는 판정은 지지되지 않는다. Heading gap은 73~90% 감소한다. e_t gap 감소와 β gap 증가가 동시에 나타나므로 둘을 비례한다고 간주하면 안 된다. β는 반경 위치와 비선형 기하에도 의존한다.
- R4_aA: 방위각 gap은 47~50% 감소해 부분 지지다. Heading gap은 87~88% 감소하고 부호가 음→양으로 반전한다.
- R4_aB: 방위각 gap은 약 9% 확대되고 Heading gap도 거의 유지/소폭 확대된다. 직접 range 접선 차단으로 설명되지 않는다. 세계 장부의 반경 성분→나중 접선 투영이라는 기술적 귀속과 일치하는 방향이지만, H1 단독 인과 증명은 아니다.

어떤 조건도 방위각 gap 감소율 0.7을 넘지 않았다. 기술적 장부상 큰 기여와 개입의 필요성은 다르다. 후속 상태·공분산·gain의 변화와 채널 간 상쇄가 있으므로 장부를 인과 비율로 읽지 않는다. 기존 방위각 입력 이식 진단의 결론도 특정 oracle 개입과 여섯 조건의 범위에 한정한다.
