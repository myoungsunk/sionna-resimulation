## C0. 공통 고정 사항 (모든 대조에 적용)

**조건**

- 주 조건은 마운트 0, B0의 6 case(R2/R4/R5 × A/B)이다.
- L0–L2는 RF packet을 공유하므로 민감도 보고로만 쓴다.
- R5_aB는 **보호 조건**이다. 정보 할인이 이미 좋은 추정을 해치는지 감시한다.

**Seed**

- 센서 seed는 0–9를 쓴다(`build_controls(seed=s)`). 
- seed마다 BASE mask를 gated BASE로 재생성한다.
- seed 0은 저장 trace와 parity를 확인한다(기존 검사 그대로).

**Arm 기준점**

- 기준 arm은 BB_ORIG, MB_ORIG, MB_VAR이다(`exp_pb.run` 산술 동일).
- 모든 비교는 **같은 seed·같은 packet의 쌍대 차이**로 보고한다.

**표본 집합**

- `S_all`: t ≥ 30, 유한 z 전체(gate 전, 해당 arm의 prior로 계산)
- `S_base`: S_all ∩ BASE 수용
- `S_self`: S_all ∩ 해당 arm 자체 gate 수용(E6에서만)
- 시간창은 [30,60), [60,120), [120,180), [180,240), [240,end]로 고정한다. 이 창은 기술용이다. 창별 차이를 처치 효과의 판정에 쓰지 않는다.

**Packet별 저장 (npz)**

- t, 수용 flag 3종
- z, μ, R₀, R_used, h(x̂⁻), h(x_true), H, P⁻, P⁺, ν, S, NIS(gate 전)
- ε = z − h(x_true) − μ
- δh = h(x_true) − h(x̂⁻)
- e⁻ = x_true − x̂⁻ (heading wrap)
- He⁻, ℓ = δh − He⁻
- 4-state 및 [p_x,p_y,ψ] NEES

**요약 지표 (성분 r, s별, 표본 집합별)**

- 2차 모멘트
  - E[ν²], E[ε²], E[δh²], 2E[ε·δh]: 네 항의 합 검산 ≤ 1e-12
  - E[(He⁻)²], E[ℓ²], 2E[He⁻·ℓ]
- 정규화 비율
  - 평균비: E[ε²]/E[R], E[δh²]/E[HPHᵀ]
  - 비평균: E[ε²/R], E[δh²/HPHᵀ]
- 상관
  - 교차상관 corr(ε, δh)
  - lag-1 교차상관 corr(ε_k, δh_{k+1})
  - ε의 ACF: 다중 lag, 첫 1/e·0.5 도달 lag, 미도달이면 right-censored
- n_eff: AR(1) 근사와 다중 lag 합(Geyer initial positive sequence)을 병기한다. 둘 다 **기술 통계이지 할인 계수가 아니다.**

**점수**

- Heading RMSE, XY RMSE, 접선·반경 RMSE
- Heading z-RMS, Heading 68/95/99% coverage
- XY NEES 평균과 분포(χ²₂ 분위 대비), XY 95% coverage
- 최대 \|Heading 오차\|, 오차 상위 5% 구간의 합

**재현 기준점**

- 처치 0(무변경)은 06a8a09 수치와 1e-10 이내로 일치해야 한다.
- 불일치하면 해당 대조를 중단한다.

## E1. 관측 선택·빈도·채널·가중치 분리 (DEC/RSC 정정)

처치는 모두 고정 BASE mask 위에서 수행한다. m ∈ {2, 4, 8, 16}.

| 처치 | 정의 | 바뀌는 것 | 고정 |
|---|---|---|---|
| DEC_ALLPH_m | 수용 packet 중 위상 p = 0..m−1의 m개 부분집합 각각 | 빈도 + 어떤 packet인가 | 가중치/packet |
| RAND_m | 같은 개수의 무작위 부분집합 20개(seed = 2026103000 + j) | 빈도, 선택은 무작위 | 가중치/packet |
| THIN_S_m | r은 매 packet, s는 위상 p에서만 갱신(현재 R_rs = 0이므로 s행 제거가 정확) | s 채널 빈도 | r 정보, 갱신 시점 |
| THIN_R_m | 위와 반대 | r 채널 빈도 | s 정보 |
| RSC_TOTAL_m | R_used × m (MB_VAR는 (R₀ + σ_b²w_sw_sᵀ) × m) | 총 가중치 | 빈도, 시점, 선택 |
| RSC_S_m | R_used,ss만 × m | s 가중치 | r 가중치, 빈도 |
| RSC_BASE_m | 06a8a09 방식(mR₀ + σ_b²), 재현용 | — | — |

**해석 규칙 (사전 고정)**

- **선택 의존:** DEC_ALLPH의 위상 간 분산이 RAND의 분산보다 크면, 특정 시점이 결과를 결정한다고 본다. 위상별 결과에 시점·기하를 함께 기록한다.
- **빈도 vs 가중치:** RSC_TOTAL_m의 결과 분포가 RAND_m 분포 안(2.5–97.5%)에 들면, "빈도를 줄이는 것과 가중치를 줄이는 것이 구분되지 않는다"고 판정한다. 밖이면 빈도 고유 효과(갱신 횟수·선형화 시점)가 있다고 본다.
- **채널 귀속:** THIN_S_m ≈ RSC_S_m ≈ DEC_m이고 THIN_R_m ≈ 기준점이면, 회복을 s 채널에 귀속한다.
- **R_rs 확장 시:** 이후 R_rs ≠ 0 arm에 s-thinning을 적용할 때는 조건부 관측 z_r \| z_s 또는 whitened 성분 단위로 정의를 다시 쓴다(이번 범위 밖).

## E2. 평균만 바꾸는 대조

**처치 정의**

- **MEAN_COND:** μ_M에 조건부 평균 m̂(u)를 더한다. R·gate·입력은 MB_ORIG, MB_VAR와 동일하다.
- **학습:** m̂는 평가 route를 제외한 route의 S_all 표본으로만 학습한다(Ridge, `fit_models`와 같은 제외 규칙).
- **특징 u:** 온라인에서 얻을 수 있는 것만 쓴다.
  - 예측 상태 기반: ρ̂, 예측 s, ∂h_s/∂ψ의 부호·크기
  - first-path tap 상태(RF feature가 있으면)
  - truth 기반 특징은 금지한다.

**대조**

- MEAN_ZERO: m̂ = 0, 기존과 같다.
- MEAN_SHUF: m̂를 학습 표본 내에서 순열한 뒤 적합한다. 우연 적합의 상한 역할이다.

**부수 산출**

- ε̃ = ε − m̂(u)의 ACF와 n_eff를 S_all에서 다시 계산한다.
- **판정:** ε̃의 1/e lag가 ε 대비 절반 이하로 줄면, "긴 상관의 상당 부분이 조건부 평균 변화"로 기록한다.

## E4. 시간상관만 바꾸는 semi-synthetic replay (인과 핵심)

**원리**

- 관측 시각, 기하, truth 궤적, μ, R, BASE mask를 그대로 둔다.
- RF 잔차의 **시간 배열만** 바꾼 관측 z̃ = h(x_true) + μ + ε̃로 필터를 다시 돌린다.
- ε̃는 truth를 쓴 진단용 구성이다. **실제 RF 환경을 생성하는 방법이 아니다.**

**처치**

| 처치 | ε̃ | 기대 상관 |
|---|---|---|
| ID | ε 그대로 | 원래. 기존 결과와 1e-10 parity |
| PERM | 층 내 (ε_r, ε_s) **쌍** 순열 | lag ≥ 1 상관 ≈ 0 |
| BLOCK_L | 층 내 길이 L block 단위 순열, L ∈ {1, 2, 4, 8} s | L 이하 상관 보존(용량–반응) |
| SIGNFLIP_BLOCK_L | block별 부호 무작위 반전(층 내 평균 0일 때만) | 저주파 평균 제거 민감도 |

**층(stratum) 정의 (case 내부, route 간 혼합 금지)**

- ρ_true bin(5) × anchor 기준 이동 방향 sector(4) × \|∂h_s/∂ψ\| tercile(3)
- 층 표본이 20개 미만이면 인접 sector와 병합하고, 병합 기록을 남긴다.

**순열 대상**

- S_base 수용 packet만 순열한다.
- 거절 packet은 그대로 두고, 갱신되지 않는다.

**Mask 처리**

- **주 분석:** BASE mask 고정
- **보조 분석:** z̃로 BASE mask를 재생성

**반복**

- seed 0에서 순열 20회를 돌린다(SeedSequence(2026103100, case_id, rep)).
- 이후 10 센서 seed × 순열 5회를 돌린다.

**조작 점검 (실패 시 해당 반복 폐기·보고)**

- 층별로 다음 항목이 원래 값과 상대오차 1e-12 이내로 보존되는지 확인한다(순열이므로 정확해야 함).
  - ε_r·ε_s의 평균
  - 2×2 공분산
  - \|ε\| 분위수
- 달성 lag-1 ACF가 PERM < 0.1, BLOCK_L은 L과 단조인지 확인한다.

**사전 예측 (시간상관 인과 가설 H_TC)**

H_TC가 맞다면 다음이 함께 나타나야 한다.

1. PERM에서 corr(ε, δh)와 2E[ε·δh]/E[ν²]가 0으로 접근한다. 기준: R5_aA, R4_aB에서 \|비율\| ≤ 0.10.
2. E[δh²]/E[HPHᵀ]와 Heading z-RMS가 1 방향으로 이동한다.
3. R5_aA, R4_aB의 Heading·XY RMSE가 ID 대비 감소한다.
4. BLOCK_L에서 위 세 지표가 L에 대해 단조로 변한다(L이 클수록 ID에 가까움).
5. R5_aB의 정확도가 ID 대비 10% 이상 악화하지 않는다.

**판정 규칙**

- **지지:** 1–4가 주 2 case(R5_aA, R4_aB) 모두에서 성립하고, 10 seed 중 8 이상에서 같은 부호이면 H_TC를 지지한다.
- **기각:** PERM에서 상쇄·과신이 유지되면, 시간상관은 주원인이 아니다. 이 경우 E2·E3·E5 쪽으로 귀속한다.
- **부분 지지:** 1은 성립하지만 3이 성립하지 않으면, "상관이 일관성에는 관여하나 정확도 손실은 다른 요인"으로 기록한다.

## E5. 기하·선형화 진단 (새 arm 없음)

**분해**

- C0 저장값으로 δh = He⁻ + ℓ를 분해한다.
- 창별로 E[ℓ²]/E[δh²]와 E[(He⁻)²]/E[HPHᵀ]를 보고한다.

**판정**

- **선형화 우세:** E[ℓ²]/E[δh²] > 0.3인 창은 "선형화 오차 우세"로 표시한다. 이 창의 δh²/HPHᵀ를 P 과소평가 근거로 쓰지 않는다.

**방향별 정보**

- 창별 누적 정보 I_w = Σ Hᵀ R_used⁻¹ H를 계산한다.
- prior 표준편차로 정규화한다: D⁻¹ I_w D⁻¹, D = diag(√P⁻₀).
- heading·접선·반경·b_g 방향의 고유값과 고유벡터 정렬을 기록한다.
- 단일 시점 Jacobian rank로 비관측을 판정하지 않는다.

**동일 prior 1-step**

- 실패 창 진입 시점의 prior를 고정한다.
- 다음 1–20 packet 갱신을 처치별로 재생하고, Heading·접선 오차 변화를 비교한다.
- 비교 처치: ID, PERM, RSC_TOTAL_8, COV_RS

## E6. Gate·update 공분산 2×2

평균은 MB, 초기조건과 seed는 동일하다.

| | update R₀ | update R_VAR |
|---|---|---|
| **gate R₀** | G0U0 (= MB_ORIG 자체 gate) | G0UV: gate 척도 유지, 갱신만 할인 |
| **gate R_VAR** | GVU0: gate만 완화 | GVUV (= 06a8a09 MB_VAR self) |
| **통제** | BASE 고정 mask × U0, UV | — |

**1단계 — 같은 prior에서의 즉시 효과**

- BASE 고정 mask run의 prior를 고정하고, 각 gate 규칙의 수용 여부를 packet별로 계산한다(폐루프 없음).
- 수용 변화 packet의 \|ε_s\|를 √R₀,ss와 √R_VAR,ss로 각각 정규화해 함께 보고한다.

**2단계 — 폐루프**

- 4칸을 모두 재귀 실행한다.
- 수용률, 최장 공백, 점수, 수용 변화가 생긴 시각 이후 Δ오차 궤적을 보고한다.

**임계값 민감도**

- χ²₂ 분위 0.95(5.99), 0.99(9.21, 현재), 0.999(13.82)를 비교한다.
- 임계값은 보고용으로만 쓴다. 최적값 선택은 하지 않는다.

**판정**

- **분리 지지:** G0UV가 BASE 고정 mask × UV와 동등하다(쌍대 차이 중앙값 \|Δ\| ≤ 5%, 10 seed). 이 경우 "gate 척도와 갱신 할인의 분리"가 고정 mask 의존성을 대체한다고 기록한다.
- **분리 미지지:** G0UV도 악화하면, prior 오염에 따른 정상 packet 거절을 1단계 결과로 확인한다.

## E7. 일반화 평가 정정

**P0 감사 (실행 전 필수)**

μ_B·μ_M·R을 생성한 전 단계를 outer fold 안에서 재학습할 수 있는지 확인한다.
- 대상: PJ_SEPARATE_RS arm 선택과 Δs 평균 보정 파이프라인
- 확인 항목: 코드, 입력(full RF H), 결정론적 재현

**재현 가능할 때: nested LORO**

- outer = 평가 route(R2, R4, R5). μ, R, σ_b(또는 대체 할인 규칙), 임계값을 모두 inner route에서만 학습한다.
- inner의 모델 선택은 inner cross-fit으로 한다.
- 06a8a09의 D1은 다음 이름으로 바꾼다: "고정 OOF μ,R 위에서의 2단계 분산표 경로 제외 재적합"

**재현 불가할 때**

- D1의 범위를 위 이름으로 한정한다.
- 일반화는 **hand table과 모든 설정을 동결한 채 새 환경에서** 평가한다.
- 후보 환경은 저장소의 office corridor 마운트 0 RF 브랜치(`research/office-mount0-rf-20261026` 계열)이다. 사용 가능성은 P0에서 함께 확인한다.

**할인량 학습 절차의 일반화**

- E1/E4 결과로 절차를 정의한 뒤 별도 계약으로 평가한다.

## 실행 순서와 규모

| 단계 | 내용 | 대략적 run 수 (1 run ≈ 1.5–3 s) |
|---|---|---|
| A | C0 logging 확장 + ID parity, E5 진단 | 6 case × 3 arm × 10 seed = 180 |
| B | E1 (전 위상, RAND 20, THIN, RSC) — seed 0 전체, 이후 seed 반복은 m = 4, 8만 | ≈ 6 × 2 × 4 × 40 ≈ 1.9k + 반복 |
| C | E4 (ID/PERM/BLOCK×4/SIGNFLIP) | seed 0: 6 × 2 × 6 × 20 ≈ 1.4k, seed 반복 ≈ 3.6k |
| D | E2, E3 | ≈ 1k |
| E | E6 1단계(폐루프 없음) → 2단계 | ≈ 0.5k |
| F | E7 P0 감사 → nested LORO 또는 새 환경 평가 | 감사 결과에 따름 |

- **우선순위:** A → C → B → D → E → F
  - E4를 B보다 앞에 둔 이유: E4가 가장 직접적인 인과 대조이다. B는 E4 결과의 해석(빈도·채널 귀속)에 필요하다.
- **예상 시간:** GitHub Actions에서 case×seed shard로 나누면 단계별 수십 분 수준이다.
