## 2. S0: exact mathematical mechanism

### Scalar analytic reference

Let Σ = σ²[[1,ρ],[ρ,1]], `H_same=[1,1]^T`, `H_opp=[1,-1]^T`. For |ρ|<1:

`I_corr_same = 2/(σ²(1+ρ))`, `I_corr_opp = 2/(σ²(1−ρ))`, `I_iid = 2/σ²`.

At ρ=0.9: `I_corr/I_iid_same = 0.5263157894736842`, `I_corr/I_iid_opp = 10`. Independent evaluator must reproduce both within absolute 1e−10. This is a fixed small-case analytical test, not a claim that current FFD has opposite-sign H at chosen poses.

### 4-state fixed design

- Keep one 4-state linearized transition/measurement design `(F_k,H_k,Q_k,P0)` fixed while replacing Σ with controlled covariance. Then keep Σ and replace `(H_k)` with preselected designs while **holding F,Q,P0, time grid fixed in S0**.
- Comparators use identical marginal per-packet `R_k` and `N` across arms. Correlated case uses full Σ, iid case uses `blockdiag(Σ_kk)`; avoid treating `diag(Σ)` as block diagonal when r/s cross covariance nonzero.
- Condition state information on prior. For initial-state deterministic model `J_k=H_k Φ_{k,0}`, `I_data=J^T Σ^{-1}J`; `I_post=P0^{-1}+I_data`. Report prior, data and posterior separately.
- With process noise, use stacked states and process residuals `(x_k−F_kx_{k-1})` plus covariance Q, and measurements with full Σ. Marginalize nuisance states or solve block Gaussian posterior; **do not use only J^TΣ^{-1}J as complete dynamic information**.
- If nuisance parameter a in full precision I, `I_eff(a)=I_aa−I_au I_uu^{-1} I_ua` (or `(I^{-1})_aa^{-1}`). Include prior and check invertibility, units and conditioning.
- Set state scale matrix `D=diag(0.1 m,0.1 m,5° in rad,0.2°/s in rad/s)` before FFD geometry selection; transform `I_nondim = D^T I D`, **never** `D^{-1} I D^{-1}`. For radial/tangential, rotate 2D position block into anchor-defined frame first.
- Information *overcount* `OC_a = I_iid,eff(a)/I_corr,eff(a)`; also report `(P_corr)aa/(P_iid)aa` for posterior and data information ratios separately. They are not algebraically equal under arbitrary prior/marginalization.
- Log sign of expected H orientation and eigenvectors, and covariance condition numbers; per-state OC need not monotonic in all designs.

## 3. S1: field covariance with explicit dimensional units

Let `q_i=(p_i,ψ_i)`, pose in world coordinates, `t_i` seconds; noise vector `(epsilon_r[m],epsilon_s[1])`.

`epsilon_i = D_i [sqrt(alpha_p) u_pose(q_i) + sqrt(alpha_t) u_time(t_i) + sqrt(alpha_w) u_iid(i)]`.

Three zero-mean unit marginal vector fields are independent, each with 2×2 channel covariance `C=[[1,c],[c,1]]`.
`alpha_p+alpha_t+alpha_w=1`, nonnegative; `|c|<1`; `D_i=diag(sigma_r(rho_i)[m], sigma_s(rho_i)[dimensionless])`.

`k_pose(i,j)=exp(-||p_i−p_j||²/(2 ell_p²))*exp(-2 sin²((ψ_i−ψ_j)/2)/ell_psi²)`.
`k_time(i,j)=exp(-|t_i−t_j|/tau)`; `k_iid(i,j)=1[i=j]` **for observation identifiers**. In joint covariance, `Σ_ij=D_i C D_j [alpha_p k_pose+alpha_t k_time+alpha_w δij]`.

- For two observations at the same pose but different time: spatial component is the same draw; temporal OU and independent white parts generally are not. `pose_id` identity must be exactly canonical including x,y,z,yaw, not merely same x,y with different yaw.
- For `alpha_p=0,alpha_t=0`, this is an iid-channel case (with r/s same-time correlation via C). It is the true *white* control; `ell_p→0` alone is not identical at revisited poses.
- Frozen baseline proposal: `sigma_r=0.05 m`, `sigma_s=0.02`, `c=0`, `alpha_t=0`; high spatial correlation `alpha_p=0.7,ell_p=0.5m,ell_psi=20°`, `alpha_w=0.3`; low `alpha_p=0,alpha_w=1`. Other levels only as explicitly marked sensitivity. These are **design parameters**, not estimates of current physical RF.
- To keep covariance changes causal: in primary S0/S1 comparisons the marginal diagonal variance at every observation must match within tolerance 1e-12 (constructed exactly). Compare identical H and time list when varying correlation; when H changes, report that Σpose changes too (S1 is not fixed-Σ intervention).
- Exact Σ is known in Track S by construction; in Track R it is **unknown** and cannot be called oracle. No empirical full covariance inverse when scenes fewer than dimensions.
- Random key hierarchy: `(contract_sha256, cell_id, field_realization_id, noise_stream)` → independent RNG; paired estimators consume identical observations. Field realization is reused for all anchor/path probes **only when the same generated world noise field is explicitly shared**; otherwise label anchors conditional replicas, not independent scenes.
- Never clip normalized signed s; before accepting S1 pose candidates enforce |h_s|≤0.7 and observe out-of-bounds rate. If any unphysical result occurs, preserve raw output and `STOP_UNPHYSICAL_OBSERVATION`; any change of noise amplitude after seeing outcome is amendment/exploratory.
