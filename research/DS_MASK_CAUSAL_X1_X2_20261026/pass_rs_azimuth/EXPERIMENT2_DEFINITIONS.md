# 실험 2a 사전 계산 정의

- 입력은 E1 원래 A0/A1 trace만. RS 결과를 장부 입력으로 사용하지 않는다.
- GT 기준 첫 통과 및 확장 창은 P2_PASSES_GT.csv에서 가져온다.
- 확장 창 첫 packet을 k0라 하고 초기 오차차이는 k0-1 posterior에서 가져온다. k0=0이면 초기 prior 오차차이를 사용한다. 이 선택으로 첫 갱신을 중복 계산하지 않는다.
- 전파 증분은 prior_k-posterior_(k-1)-(GT_k-GT_(k-1)); k=0 전파는 0. range/pol은 joint K의 각 열×nu×acc.
- range 반경/접선 분해축은 각 arm의 갱신 prior 추정 위치. 서로 다른 축을 각 arm에 적용한 후 세계 벡터의 MB-BB를 계산한다.
- 초기 차이와 채널 증분을 세계 좌표로 누적한 뒤, 각 평가 packet의 GT 접선축으로 투영한다. 통과 후 30초 평균은 P3의 유효 post 창과 같다.
- 전체 합은 통과 이후의 갱신도 포함한다. 원인 형성 위치를 혼동하지 않도록 확장 창 이내 증분과 이후 증분의 기여도 따로 저장한다.
- 기여 비율은 signed contribution / signed observed post gap. 분모 절댓값<=1e-10cm이면 NA. 음수는 상쇄 기여이며 임계값 판정에 절댓값을 사용하지 않는다. 비율은 인과 효과가 아니다.
- 통과 후 평균 및 매 packet 재구성 허용차 1e-10cm.
- 주 분석6조건 중 어느 조건에서든 rng,tan 비율>=0.3이면 CUT_RT 대상 선정 근거로 기록한다. rng,rad>=0.5이면 H1 기술적 귀속을 보고한다. prop/pol>=0.5이면 기존 결과와 재검토하고 자동 인과 확정하지 않는다.
- 2c는 설계만이며 구현/실행하지 않는다.
