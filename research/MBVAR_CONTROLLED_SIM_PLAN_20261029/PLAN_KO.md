## 1. 설계 전에 확인한 사실 (설계를 바꾸는 전제)

### 1.1 현재 RF 관측에는 잡음 실현이 없다 — "시간상관"은 전부 pose 상관이다

- **검증 결과:** R4_aB의 742개 packet에서, 필터가 실제로 사용한 z_s와 같은 pose의 H에서 다시 계산한 잡음 없는 s의 차이가 최대 2.2e-16이다(`PREMISE_CHECK_NOISE.json`).
- **잡음 기능은 꺼져 있었다:** `observation.py`에는 H에 복소 Gaussian 잡음을 넣는 기능이 있지만, 이 데이터에서는 비활성이었다.
- **결과 1 — 관측된 상관의 정체:** ε은 pose(위치·자세)의 결정론적 함수이다. 관측된 자기상관(lag-1 0.73–0.95)은 **공간·자세 상관을 궤적을 따라 표본화한 것**이다.
- **결과 2 — 첨부 4절 실험의 의미:** 첨부의 Δt/Δd 분리 실험은 현 시뮬레이터에서 **구성상 결과가 정해져 있다.**
  - Δt만 바꾸면 같은 pose에서 ε이 동일하다.
  - 상관은 Δd(와 Δψ)에만 의존한다.
  - 따라서 이 실험은 "발견"이 아니라 **설계 검증(identity check)** 으로 쓴다.
  - 진짜 시간 성분은 **합성 주입(Track S)** 으로만 만든다.
- **결과 3 — E4 해석 정정:** E4의 순열은 "시간상관 제거"가 아니라 **pose–잔차 정합 파괴**였다. 결과는 이 정의로 다시 읽는다.
- **결과 4 — 상관 모델의 축:** 상관 모델은 시간(FOGM in t)이 아니라 **이동거리·yaw 축**(GM in distance/yaw)이 자연스럽다. 이를 **속도 변화 실험으로 판별**한다(§6).

### 1.2 독립 RF 실현의 단위

- 독립 표본은 **장면 변형(반사체 배치·재질) × 앵커 × 궤적**이다.
- 같은 RF를 공유하는 gyro/odometry seed는 독립 RF가 아니다. 신뢰구간은 RF 실현 단위로 계산한다.
- **보호 조건 R5-B의 seed 민감성:** 10 seed 중 3개가 모든 arm(BB_ORIG 포함)에서 약 5°로 발산했다. 이는 RF가 아닌 **센서 실현의 영향**이다. 따라서 seed는 RF 실현과 교차하는 별도 요인으로 유지한다.

### 1.3 생성 능력과 비용

| 항목 | 확인 내용 |
|---|---|
| RT 엔진 | Sionna RT 2.0.1 PathSolver. depth 3, 반사·굴절 on, 회절·diffuse off. 257 주파수, 2×2 포트, FULL + DIRECT_LoS 쌍 |
| 장면 정의 | `src/qclean_uwb/scenarios/{corridor,office,ply}.py` (claude/office-e-layout). 판재(slab) PLY 조합 → **새 통제 장면을 같은 방식으로 정의할 수 있다** |
| 처리량 | Snowball 8병렬: 811 pose를 3.4 h에 처리(Office M0, 2026-10-27). **≈ 240 RF pose/h** |
| 이미 있는 전이 데이터 | Office O01/O02/O03 M0 FULL/LoS (811 pose, Release `office-m0-rf-20261026-complete`), Corridor R2/R4/R5 |
| 필터·분석 | `mbvar_control_correction_20261029/ctl_core.py` (exp_pb 산술 동일, 처치 hook·로깅 완비) → Actions에서 실행 |

**비용 절감 원칙: RF는 pose 격자에서 한 번만 계산한다.**
- 경로를 촘촘한 pose 격자(위치 0.05 m, 정지 회전 시 yaw 2°)로 미리 계산해 둔다.
- 속도·RF 간격·궤적 순서가 다른 조건은 모두 그 격자의 **부분표본·재배열**로 만든다.
- 이렇게 하면 Δd·속도 요인에 추가 RT 비용이 들지 않는다.
- 단, 격자에 없는 pose는 보간하지 않는다(새 pose는 새 계산).

### 3.2 앵커

- 높이는 2.65 m(기존과 동일), 앵커는 한 번에 하나씩 사용한다.
- 장면 좌표(원점 = 바닥 모서리)는 다음과 같다.
  - **A (2, 2):** 경로 시작부 근거리
  - **B (10, 2):** 같은 쪽 원거리, 방위 변화 작음
  - **C (6, 10):** 경로 반대편, 방위 변화 큼
- 같은 궤적을 A/B/C로 각각 평가해 **기하만 다른 대조**를 만든다.
- 다중 앵커 융합은 이번 범위에서 제외한다(후속 계약).

### 3.3 사전 기하 점검 (RT 전에 필수)

- 각 (장면, 앵커, 궤적) 조합의 FFD LoS 모델 Jacobian으로 창별 정보를 계산한다. 창별 정보는 30 s 창, prior 표준편차로 정규화, 반경·접선·ψ 좌표에서 구한다.
- 이 값으로 다음 3개 지표를 계산한다.
  - 접선 정보 λ_t
  - ψ 정보 λ_ψ
  - **민감도 다양성 지수** D = 창 안 ∂h_s/∂ψ와 ∂h_s/∂p_t의 부호 변화 비율 × 방향 분산
- **기하 등급 판정:** 지수가 사전 고정 분위(아래 1/3, 위 1/3)에 들면 각각 LOW/HIGH 기하로 판정한다. 중간 1/3은 2×2에서 제외한다.
- **기존 사례 대응(type matching)도 함께 확인한다.** 같은 지수로 다음 구간이 실제로 생기는지 본다.
  - **R5-A형:** ρ ≥ 9 m, λ_t가 경로 중앙값의 1/10 이하
  - **R4-B형:** ρ 3–10 m, 접선–ψ 정보 상관 \|corr\| ≥ 0.5
  - **R5-B형:** λ_ψ 상위, s 의존
- 생기지 않으면 궤적을 수정한다. 기준을 바꾸지 않는다.

**속도·간격 요인 (격자 부분표본으로 구성)**

## 5. Track S — 합성 잔차 생성 모델

**구성**

z = h_FFD(x_true) + μ + ε_syn이다. ε_syn은 다음 성분의 합이다.

| 성분 | 정의 | 조절 인자 |
|---|---|---|
| 공간 성분 | 이동거리 축 Gauss–Markov(길이 ℓ_d) × yaw 축(길이 ℓ_ψ). pose의 함수이므로 재방문 시 동일 | ℓ_d ∈ {0 (white), 0.1, 0.3, 1.0} m, ℓ_ψ ∈ {∞, 20°, 5°} |
| 시간 성분 | 시간 OU(τ). pose와 무관 | τ ∈ {0, 1, 5} s. 진폭 비율 κ_t ∈ {0, 0.5} |
| 백색 성분 | iid | 전체 분산의 고정 비율 |
| r–s 동시 상관 | 성분별 공통 2×2 상관 | ρ_rs ∈ {0, 0.3} |
| 진폭 | 거리 의존 σ(ρ). 기존 corridor MB 잔차의 bin별 RMS를 그대로 쓴다 | 고정 (분산은 처치하지 않는다) |
| 평균 | 조건부 평균 m(ρ, 방위) | {0, corridor 추정값}. Q4용 |

**성질**
- **분산 정합:** 모든 처치에서 성분 분산의 합을 같게 맞춘다. 따라서 상관 처치는 분산을 바꾸지 않는다.
- **Σ를 정확히 안다:** pose 격자에서 공분산을 바로 계산할 수 있으므로, oracle 정보행렬과 oracle GLS를 만들 수 있다.

**2×2 핵심 셀 (Q1–Q3)**

| | LOW 기하 | HIGH 기하 |
|---|---|---|
| **low 상관** (ℓ_d = 0) | A: 기준 | C: 기하 효과 |
| **high 상관** (ℓ_d = 1.0 m) | B: 중복정보 가설 | D: 상호작용 |

- 기하 등급은 §3.3의 사전 점검으로 정한다.
- 나머지 ℓ 수준은 용량–반응 곡선용이다.

**반복 수**
- 셀당 독립 ε 실현을 pilot 10회, 본 실행 30회 돌린다.
- 각 실현에 센서 seed 3개를 교차한다(seed는 RF 실현과 별도로 집계한다).

## 6. 분석 지표와 추정기

### 6.1 상태별 정보량 (필터와 독립)

**정보행렬**
- J_k = H_k Φ_{k,0}를 쌓고, Σ는 Track S의 참값 또는 Track R의 추정값을 쓴다.
- 두 정보행렬을 계산한다.
  - I_corr = Jᵀ Σ⁻¹ J
  - I_iid = Jᵀ Σ_blockdiag⁻¹ J
- **과정잡음 포함판:** Q를 포함한 batch smoother 정보(상태 궤적을 쌓고 동역학 제약 + Q)도 계산한다. 위의 결정론 근사와 함께 보고한다.

**상태별 효과정보**
- 좌표 [p_r, p_t, ψ, b_g]에서 Schur 보수 I_{a\|rest} = I_aa − I_au I_uu⁻¹ I_ua를 구한다.
- 특이할 때는 prior로 정칙화한다.

**과대계상비**
- 상태별로 **OC_a = I_iid,a\|rest / I_corr,a\|rest**를 정의한다.
- OC > 1이면 독립 가정이 정보를 과대평가하고, OC < 1이면 과소평가한다(반대 부호 민감도에서 상쇄되는 경우).

### 6.2 필터·추정기 (같은 관측에 추정기만 교체)

| 추정기 | 오차 모델 | 역할 |
|---|---|---|
| MB_VAR (현행) | R_ss + σ_b² | 기준선 |
| IID-EKF | 상관 0, 분산 정합 R | 과대계상 기준 |
| **oracle GLS / RTS smoother** | 참 Σ (Track S) | 달성 가능 상한. 운영 방법 아님 |
| GM-dist | 거리·yaw 축 Gauss–Markov 상태 증강 (pol_bias_model GM1Y20 계열) | pose 상관에 맞는 재귀 모델 |
| GM-time | 시간 FOGM 상태 증강 | 시간 상관 가정 모델 (오지정 대조) |
| 상태별 할인 | I_corr 기반으로 방향별로 정보 할인 (정의는 S 결과로 확정) | 균일 N_eff 할인의 대안 |
| 균일 할인 | 스칼라 N/N_eff | Q5 대조 |

**속도 판별 실험:** 같은 pose 경로를 v ∈ {0.1, 0.2, 0.4} m/s로 주행한다(격자 부분표본). pose 상관이 맞다면 두 모델의 거동이 갈라진다.
- GM-dist의 z_ψ는 속도에 무관해야 한다.
- GM-time은 속도에 따라 일관성이 깨져야 한다.

### 6.3 공통 결과 지표

다음은 `ctl_core.summarize`·`scores`를 그대로 재사용한다.
- Heading·XY·접선·반경 RMSE
- z_ψ, coverage 68/95/99, NEES(3·4상태) 분포
- 교차항 몫 2E[εδh]/E[ν²], 선형화 나머지 비중 ℓ 몫
- 보고 P와 I_corr⁻¹(또는 smoother 공분산)의 비

## 7. 사전등록 판정 기준

| ID | 가설 | 판정 (모두 독립 RF 실현 단위, 30 실현) |
|---|---|---|
| H1 순수 상관 효과 (S) | 같은 기하·분산에서 ℓ_d가 커지면, 같은 민감도 방향(LOW)의 ψ·p_t에서 OC가 단조 증가한다 | ℓ 수준과 OC 중앙값의 Spearman ≥ 0.8. LOW 셀에서 OC(B)/OC(A) ≥ 1.5 |
| H2 기하 효과 (S) | 같은 상관에서 OC가 기하 등급에 따라 다르다. HIGH 기하에서 OC가 작거나 1 미만이다 | high 상관에서 OC_LOW / OC_HIGH ≥ 1.5. 부호 예측 일치 |
| H3 필터 일관성 예측 (S) | IID-EKF의 z_ψ²가 OC_ψ를 따라간다 | 셀 중앙값 기준 \|log(z_ψ² / OC_ψ)\| ≤ log 1.5 인 셀이 ≥ 75% |
| H4 상한·모델 판별 (S) | oracle smoother는 z 0.8–1.25, IID-EKF보다 RMSE가 낮다. GM-dist의 z_ψ는 속도 간 ±20% 이내, GM-time은 아니다 | 셀별 쌍대 비교에서 ≥ 80% 실현이 같은 방향 |
| H5 보호 (S, T) | R5-B형 구간에서 균일 할인은 Heading RMSE를 ≥ 10% 악화시키고, 상태별 할인은 악화가 ≤ 5%이다 | 두 조건 모두 충족 |
| H6 r/s 가중 (S, R) | 평균 보정 후 R_rr을 재추정하지 않으면 R4-B형 구간에서 s 상대 과중으로 Heading이 악화한다. R_rr 재추정 시 회복한다 | 회복 ≥ 50%, 다른 형에서 악화 ≤ 10% |
| H7 물리 RF 재현 (R) | H1·H2의 효과 부호가 Track R에서 재현된다 | 장면 계열 C1–C4 중 ≥ 3에서 같은 부호. C3(재질)에서는 OC가 진폭과 무관 |
| H8 일반화 (T) | Track S·R에서 고정한 결론과 설정을 동결 적용했을 때, Office O01–O03·Corridor에서 같은 부호를 유지한다 | 동결 후 사전 지정 지표의 부호 유지 ≥ 2/3 경로 |

- **판정 불가 표시:** 기준 미달, NA, 실행 실패를 구분해 기록한다.
- **정의 고정:** H5의 "상태별 할인" 정의는 Track S 결과로 확정한다. 확정 시점에 이 문서에 실행 전 수정으로 고정하고, 이후 R·T 단계에서는 바꾸지 않는다.

## 9. 산출물·위치

**폴더 구성** — `research/MBVAR_CONTROLLED_SIM_<날짜>/`
- `scenes/`: 장면 정의, 변형 seed, 장면 해시
- `poses/`: 격자·궤적·부분표본 정의
- `track_s/`: 생성기, Σ, 실현 해시
- `rf/`: Snowball receipt만 둔다. 대용량 채널은 Release에 둔다.
- `results/run_<id>/`: 판정표, 정보량, 필터 점수

**규칙**
- 기존 결과는 수정하지 않는다.
- 모든 실행은 manifest(config hash, 입력, 출력 SHA, 명령, 시각)를 남긴다.
- 대용량 RF 채널은 기존 관례대로 Release에 두고 SHA를 기록한다.

## 10. 주장 경계

- Track S는 **기전 검정**이다. 실제 RF 오차 모델에 대한 주장을 하지 않는다.
- Track R은 **Sionna RT의 결정론 채널**이다. 시간적 RF 변동(인체·문 개폐·수신기 잡음)은 없다. 시간 성분 결론은 Track S의 합성 주입에 한정된다.
- 단일 앵커 결과를 다중 앵커 시스템으로 일반화하지 않는다.
- 실측(TB3 + 실제 UWB)으로의 이전은 별도 계획이다. 이 계획의 판정은 시뮬레이션 내부에 한정된다.
