## 4. 요약

1. integrity 미달은 두 기전이 겹친 결과다.
   - **(M-a) case 간 스케일 불일치:** 전역 c_L 하나로는 R4_aB(절대 기준 station 단위 약 1.8배, sweep 단위 약 2.6배 과소. 약 4.6배는 다른 case 대비 상대값)와 나머지 case(대체로 과대)를 동시에 맞추지 못한다.
   - **(M-b) station 고정 오차와 재방문:** 오차가 site에 고정돼 있는데 경로가 소수 station을 반복 방문한다. 같은 오차를 독립 관측으로 계산하므로 과신한다. R4의 station 수(10)와 Markov 순차 방문 규칙이 이를 키운다.
2. E1 자체는 정보가 있다. 버릴 대상이 아니라 스케일과 site 상관 구조를 보완할 대상이다.
3. 2 m 간격에서 station 간 상관은 거의 0이다. 0.45 m 간격의 상관은 새 RT(G1-RT-TB3-001)에서 직접 측정해야 한다.
4. 실제 TEACH/REPEAT 운용은 같은 물리 station을 다시 방문한다. 따라서 (M-b)는 시뮬레이션 인공물인 동시에 실제 운용에서도 일어나는 구조다. 재방문을 아는 site-bias 상태가 필요하다.
