## 검증과 한계

- 입력 74개 Git blob, 14개 H SHA-256, 주파수/LUT/소스 6개 해시를 대조했다. 축약 해시는 사양에 인쇄된 접두·접미사를 대조했고, 전체 SHA-256은 입력 검증 기록에 보존했다.
- 원형 창 최솟값을 15,000개 합성 예에서 완전탐색과 대조했다. White Gaussian 기준 posterior 분산 0.6246520789 deg²와 필터 값이 10⁻¹⁰ deg² 이내로 일치했다. Monte Carlo MSE는 0.625963 deg²였다.
- 모든 bootstrap 배열은 1000×50이다. 원본 배열과 CSV에서 누적 비율, CI, NEES, 포함률을 다시 계산했다. 독립 코드 검토는 5개 case의 계산 및 판정 로직을 수용했다. 독립 실험 반복과 과학적 채택은 수행하지 않았다.
- 95% CI는 측정 스케일·ρ 추정치와 200개 공통 DR 경로를 고정한 조건에서 평가 J station 표본 변동을 반영한다. Markov와 셀 모형은 유한 lane 끝에서 순환하며, 세 모형의 수치가 물리적 상·하한으로 보장되지는 않는다. RT 0.45 m의 실제 sweep은 없고, 90°는 TB3 120° sweep의 근사다. 전체 결과는 동일 복도 형상에 대한 `GENERALIZATION_NOT_PROVEN` 상태다.
- 초기 집계는 곡선 저장 후 느린 bootstrap 집계를 중단했다. 합과 개수를 station 단위로 먼저 계산해 재집계했다. 최초 공간 코드가 R4 대각 진행 구간을 제외한 문제는 같은 lag와 통계식으로 수정했다. 원래 상관 파일과 첫 S2 실패 로그는 별도 보존했다. 판정 임계값은 변경하지 않았다.
