### 2.2 M1-R 거리 입력 (1차)

- **range를 쓰지 않는다.** 같은 tap에서 range와 s가 나오므로 range를 거리 입력으로 쓰면 두 오차가 결정론적으로 묶인다.
- d_geo = ‖anchor − (x̂, ŷ, z_rx)‖. (x̂, ŷ)는 해당 RF station의 명목 좌표에 §4.3에서 정한 평가 위치 prior 오차를 더한 좌표다. anchor 좌표와 z_rx는 CASES.json 값이다.
- σ_d² = u^T Σ_xy u, u는 anchor 쪽 수평 단위벡터에 수평거리/거리 비를 곱한 투영 벡터, Σ_xy는 가정한 위치 prior 공분산이다. 1차에서는 Σ_xy = (0.13 m)² I이고 σ_d = 0.13 m · ρ_h/d다(ρ_h는 수평거리, d는 경사거리). 투영 벡터와 d_geo는 동일한 평가 XY에서 계산한다. XY-P 민감도는 축별 0.10 m를 쓴다.
- **σ_d에는 하한을 두지 않는다.** anchor 가까이에서는 ρ_h/d가 작아져 σ_d가 축별 0.13 m보다 작아질 수 있다(예: R2_aA_m0 첫 RT 명목 위치에서 약 0.108 m).
- d 적분: 5점 Gauss–Hermite로 s̄_i(ψ) = E_d[s_i(d, ψ)], V_d,i(ψ) = Var_d[s_i(d, ψ)].
- σ_d가 tap 반주기(약 0.075 m)보다 크면 sub-tap 효과는 사실상 평균되고, 작으면 sub-tap 위치에 따른 s 변화가 그대로 남는다. 두 영역 모두 같은 적분식으로 다루며, 작은 σ_d 영역이 M1이 M0와 달라지는 핵심 구간이므로 하한으로 덮지 않는다.
- **한 sweep의 모든 pose는 같은 base 위치에서 측정되므로 거리 오차를 공유한다.** 1차는 공동 거리 변수로 적분한다(§2.4). σ_d는 case·RF station·평가 XY의 기하로 정해진다. §5.2의 각 격자점에서 계산한다.

### 2.3 M1-RI (보조)

- 같은 sweep pose의 관측 index k_i를 쓴다. noise-free LoS 모델에서 index가 k_i가 되는 거리 구간 C(k_i, ψ)를 구하고, d를 그 구간 안에서 d_geo prior로 가중해 적분한다.
- 실측 index와 LoS 모델 index가 맞지 않으면(구간이 비면) 그 pose는 M1-R 값을 쓰고 비율을 보고한다.
- μ_r, σ_r,dir는 index→거리 변환에만 쓴다.
- **index는 조건화에만 쓰고, 같은 station에서 range를 독립 측정으로 다시 쓰지 않는다.** Step 2 필터는 heading만 갱신하므로 이중 계수는 없다.

### 2.4 비용 함수: sweep 공동 거리 적분

- **1차(J_joint):** sweep 하나의 거리 d를 공동 변수로 두고 적분한다. d_g = d_geo + √2·σ_d·x_g, w_g는 5점 Gauss–Hermite 노드·가중치다.
  - L(ψ) = Σ_g (w_g/√π) · Π_i N(s_obs,i ; s_i(d_g, ψ), σ_s0²)
  - J(ψ) = −2 ln L(ψ) − Σ_i ln(2πσ_s0²) (상수항을 빼서 무차원 χ² 척도로 맞춘다)
  - 수치 안정을 위해 log-sum-exp로 계산한다.
- **민감도(J_diag):** pose 간 거리 공분산을 생략하는 대각 근사. J_diag(ψ) = Σ_i (s_obs,i − s̄_i(ψ))² / (σ_s0² + V_d,i(ψ)), s̄_i = E_d[s_i], V_d,i = Var_d[s_i]. v2의 J_w와 같다.
- σ_s0²: case별 열잡음 분산. LoS H에 N30 잡음 seed 0–19를 넣고 pose별 s 분산을 구한 뒤 pose 중앙값을 쓴다(multipath를 쓰지 않는다). N10, N0도 같은 방법이다(N0는 σ_s0² = 1e-8 하한).
- M0에서는 거리 의존이 없으므로 J_joint = J_diag = Σ_i (s_obs,i − s_LUT,i)²/σ_s0²이다. 기존 J(비가중)는 R0 회귀(§6)에서만 쓴다.
- 아래에서 J는 1차 J_joint를 뜻한다.

## 3. M-ERR: 정직한 측정 오차 모델

모든 파라미터는 **route 단위 홀드아웃(LORO: R2/R4/R5)**으로 정한다. 평가 route의 오차를 쓰지 않는다. 학습에 쓰는 정렬 오차는 PREREG와 같이 참값 중심 ±10° 창의 J 최소에서 얻는다(학습 route에서만, 오프라인).

### 3.1 Arm

| Arm | 측정 분산·우도 | LORO 파라미터 |
|---|---|---|
| E0 | 고정 σ²: 학습 route 정렬 오차의 2차 모멘트(G1-FLOOR-001 방식) | σ² |
| **E1** (1차) | **Laplace 국소 분산**(§3.2) | c_L |
| E2 | 2성분 혼합: (1−π)·N(0, R_E1) + π·N(μ_o, σ_o²) | π, μ_o, σ_o (μ_o = 0 고정 민감도 포함) |
| E3 | Student-t(ν), scale R_E1 | ν |
| E4 | R_E1 × g(margin), g는 margin 3분위 계단의 단조 증가 계수 | g |

- E1은 편파 관측 자체의 정보량(J 곡선의 날카로움)으로 station마다 불확도를 정한다. 라벨 없이 관측과 모델만으로 계산된다.
- E4는 관측 품질을 **분산으로만** 반영한다. 기각은 하지 않는다. Goal 1/Goal 2 경계 사례로 표기한다.
- **case별 평균 편향을 학습해 빼는 방법은 Goal 2(보정)로 분류해 제외한다.**

### 3.2 E1 정의와 보정 순서

후보 하나(국소 최소 ψ̂_i)에 대해:

1. 곡률: ψ̂_i ± 2°(0.25° 격자 17점)에서 J(ψ) ≈ a(ψ − ψ̂_i)² + bψ + c를 최소제곱으로 맞추고 J''(ψ̂_i) = 2a [deg⁻²]로 둔다. 중앙차분은 쓰지 않는다.
2. 잔차 보정: χ²_red = min_g Σ_j (s_obs,j − s_j(d_g, ψ̂_i))² / σ_s0² / (n_valid − 1). n_valid는 유효 s 관측 수다.
3. 보정 전 분산: R_raw = max(1, χ²_red) · 2 / J''(ψ̂_i) [deg²].
4. **유효성 판정:** a > 0, 이차 fit R² ≥ 0.5, ψ̂_i가 창 경계에서 0.5° 밖이면 "유효 곡률", 아니면 "평탄·경계".

LORO 학습(평가 route 제외)은 다음 순서로 한 번만 수행한다. 1차 위치 모형에서는 학습용 case·90° 물리 station·RF seed마다 독립인 잠재 위치 오차 N(0, 0.13² I)를 하나씩 뽑고 §5.2의 snap 및 격자 밖 직접 계산 규칙을 적용한다. 정렬된 단일 sweep을 학습하므로 정상 주변분포를 사용한다. 학습 전용 PCG64 seed는 `2026111336`이고 case ID, 물리 station ID, RF seed를 오름차순으로 정렬해 XY를 배정한다. 같은 위치 모형을 비교하는 arm끼리는 이 오차 표본을 공유한다. XY-P 민감도는 §4.3의 XY-P를 적용해 별도 보정한다. c_L은 마지막에 정한다.

| 단계 | 내용 |
|---|---|
| L1 | 학습 route의 정렬 조건(참값 중심 ±10° 창)에서 창 안의 **모든 국소 최소**(§4.4의 원형 격자·후보 자격 규칙, 서로 2° 이상, **개수 제한 없음**)의 R_raw를 계산한다. C1의 3개 제한은 갱신 단계에만 적용한다 |
| L2 | **표본 A = 유효 곡률인 모든 후보**의 R_raw 99 백분위를 R_cap,raw로 정한다 |
| L3 | 평탄·경계 후보는 R_raw := R_cap,raw로 바꾼다(학습·평가 모두 같은 규칙, 평가에는 학습 R_cap,raw를 쓴다) |
| L4 | **표본 B = sweep당 J 최저 후보 하나**(정렬 오차 e가 정의되는 후보). 이 후보가 평탄·경계이면 L3 값을 쓴다. 표본 B의 \|e\|/√R_raw 95 백분위 q95로 c_L = (q95/1.96)²를 정한다 |
| L5 | R_E1 = c_L · R_raw. **R̄_train = 표본 B의 R_E1 평균** |

- 표본 A는 cap의 분포 꼬리를 정하는 데만 쓴다. c_L과 R̄_train은 오차 e와 같은 후보(표본 B)에서만 구해 오차–분산 짝을 맞춘다.
- 평가 시에는 C1–C6의 모든 후보에 같은 c_L을 적용한다.
- 표본 B에서 평탄·경계 후보의 비율을 보고한다(이 비율이 높으면 c_L이 R_cap,raw에 좌우된다).

E2–E4의 파라미터도 L5 이후의 R_E1을 입력으로 같은 학습 집합에서 정한다.

## 4. 추정기와 DR 과정

### 4.1 측정 시점과 DR 정의 (D4)

- z_k는 **station k의 sweep 시작 직전 base 자세의 heading**에 대한 측정이다. sweep 상대각은 base 기준이다.
- DR 증분 E_k − E_{k−1}은 **base(k−1) → base(k)**로 정의한다.
- 이 정의로 TEACH/REPEAT에서 재계산한 **σ_w = 0.486°**(짝 차이 SD 0.687°/√2)를 1차로 쓴다. 0.34°는 민감도다.
- β_DR-uncal은 같은 정의의 평균 2.046°/station(TEACH 2.278, REPEAT 1.813)이다.

### 4.2 σ_β (D5)

- 1차 σ_β = 0.45°/station(run 1회 보정). 민감도 {0, 0.32, 0.93}. 0.93은 TB3 3개 run(TEACH 2.28, REPEAT 10/04 1.82, REPEAT 11/13 0.48°/station)의 run 평균 표준편차다(§4.5).
- **σ_β\***(G1/DR-cal 비율 = 0.8이 되는 σ_β)를 각 J 모델 × E arm마다 보고한다.
- run 안 β 변화 민감도: β를 run 내 random walk(σ_βw = 0.037°/station, 짝 차이 추세에서)로 둔다.

### 4.3 위치 prior 오차 XY-AR(1)

- 경로별 잠재 위치 오차는 δp₀ ~ N(0, σ_xy² I), δp_k = ρ_xy·δp_{k−1} + η_k, η_k ~ N(0, σ_xy²(1−ρ_xy²) I)다. 1차 값은 축별 σ_xy = 0.13 m, station 간 ρ_xy = 0.90, 혁신 표준편차 0.05667 m다. x·y 혁신은 서로 독립이며 RF 및 DR 난수와 독립이다. 첫 sweep은 k = 1이다.
- AR 재귀는 연속 δp_k로 진행한다. 위치 prior 좌표를 평가할 때만 §5.2의 snap을 적용한다. 반올림값을 다음 AR 상태로 되먹이지 않는다. 필터에 주는 Σ_xy = σ_xy² I는 경로와 k에 무관하다.
- 동일 경로의 위치 난수는 비교 arm과 RF 상관 모델 간에 공유한다. ρ_xy는 위치 prior 오차 상관이고 §4.4의 ρ_case는 RF 관측 잔차 상관이다.
- 정상 오차는 이 시뮬레이션에서 가정한 위치 prior다. 현재 heading 필터는 range 갱신을 실행하지 않는다. XY-P 민감도는 station마다 독립 N(0, 0.10² I)이고 직접 계산한다. R0는 §6의 기존 설정을 적용한다.

### 4.4 상태, 측정 오차 구조, 다중 후보, gate

**상태:** x = [E, β, a]ᵀ. E는 DR heading 오차, β는 run bias, a는 측정 AR 성분이다.
- 예측: E⁻ = E + β + w(σ_w), β⁻ = β (+ σ_βw 민감도), a⁻ = ρ_case·a + u, Var(u) = (1 − ρ_case²)·σ_a².
- σ_a² = ρ_case · R̄_train. ρ_case는 S1-4의 0.45 m δs 상관을 [0, 1]로 제한한 값이다. ρ_case = 0이면 a ≡ 0이고 기존 white 필터와 같다.

**후보 i의 측정식:** y_i = wrap₁₈₀(z_i − ψ_DR) = −E + a + ε_i, H = [−1, 0, 1]. wrap₁₈₀(·)은 (−180°, 180°]로의 사상이다.
- Var(ε_i) = max(R_i − σ_a², 0.25·R_i), R_i는 그 후보의 E-arm 분산(E1이면 R_E1).
- **혁신 분산:** S_i = H P⁻ Hᵀ + Var(ε_i). heading–AR 교차공분산은 H P⁻ Hᵀ에 포함된다.
- **gate와 갱신은 같은 S_i를 쓴다.** 혁신 ν_i = wrap₁₈₀(y_i − H x̂⁻), NIS_i = ν_i² / S_i, 이득 K_i = P⁻ Hᵀ / S_i.

**다중 후보 절차 (station마다, 이 순서로):**

| 단계 | 내용 |
|---|---|
| C1 | 창 안 J의 국소 최소를 J 값이 작은 순으로 최대 3개 뽑는다(서로 2° 이상, 후보 자격은 아래 격자 규칙) |
| C2 | **측정 가중치(갱신 전, 측정만으로):** w_i^J ∝ exp(−(J_i − J_min)/2). 정규화 후 w_i^J < 0.05인 후보를 버리고 다시 정규화한다 |
| C3 | 남은 후보마다 NIS_i ≤ χ²₁(0.99) = 6.635를 검사한다 |
| C4 | **사후 가중치:** 통과한 후보끼리 π_i ∝ w_i^J · N(y_i ; H x̂⁻, S_i)로 정규화한다 |
| C5 | 후보별 KF 갱신(x_i, P_i, Joseph form) 후 합친다: x̄ = Σ π_i x_i, P̄ = Σ π_i [P_i + (x_i − x̄)(x_i − x̄)ᵀ] |
| C6 | 통과 후보가 없으면 **gate 기각**, 갱신하지 않는다 |

**원형 격자와 후보 자격:**
- J 격자는 [−180°, 180°)의 1,440점이며 **원형**이다. 인덱스 0과 1,439는 이웃이다. 국소 최소 판정, ±2° 이차 fit, 2° 분리 판정은 모두 원형 인덱스로 계산한다.
- 탐색창 [c − h, c + h]는 원형 구간이다. 반폭 h = 180°이면 전체 원이며 끝점이 없다.
- 국소 최소: 창 안의 격자점 j가 창 안 양쪽 이웃 이하이고 한쪽보다는 작으면 국소 최소다(평탄 구간은 가운데 점 하나를 대표로 쓴다).
- **창 끝점:** 끝점은 창 안 이웃이 한쪽뿐이다. 끝점이 그 이웃보다 작으면(창 밖으로 계속 내려가는 경우) **경계 후보**로 둔다. 경계 후보는 버리지 않고 §3.2의 평탄·경계 규칙(R_raw := R_cap,raw)을 적용한다.
- 모든 각도 차(후보 간 분리, 창 포함 여부, 혁신, 평가 오차)는 wrap₁₈₀으로 계산한다.

- **기각률 분모:** 유효 J(n_valid ≥ 3)가 있고 C2 이후 후보가 1개 이상인 station 수. window miss(참값이 창 밖)와 무효 station은 따로 집계한다.
- **탐색창:** PREREG를 유지한다(중심 ψ_DR − Ê⁻, 반폭 min(180°, max(3√P⁻_EE, 10°))). window miss 최장 연속 길이를 지표로 추가한다.
- 단일 최소(G1-FLOOR-001 방식, C1에서 1개만)는 민감도다.

## 5. J 곡선 저장과 검증

### 5.1 RF 실현과 위치 prior의 분리

- RF 실현은 (case, 물리 station, 잡음 seed)에서 얻은 고정 관측 s, 관측 index 및 sweep 상대각이다. 셀과 Markov 재사용은 이 RF 실현을 재사용한다. 위치 prior는 경로와 k에서 따로 정하고 관측 H와 s에는 교란을 추가하지 않는다.

### 5.2 위치 격자 조회와 직접 계산

- 1차 XY 격자는 축별 −0.30 m부터 +0.30 m까지 0.05 m 간격으로 13×13이다. 두 축 모두 `|δ| ≤ 0.30 m`이면 가장 가까운 격자점으로 snap한다. 정확한 중간점은 작은 격자 인덱스를 선택한다. 범위 판정은 반올림 전 연속값에서 한다. 한 축이라도 범위를 넘으면 두 축의 원래 연속값에서 직접 계산한다.
- 각 RF station과 XY 노드에서 d_geo와 σ_d를 §2.2에 따라 계산한다. 동일 노드의 값은 k와 무관하다. J와 E1에 필요한 최소 GH 노드의 χ² 잔차 곡선을 해당 XY에서 계산해 저장한다. J 및 잔차에는 위치·거리 불확도 보간을 적용하지 않는다.
- 노드 계산은 float64, 저장은 float32로 한다. 1차의 격자 밖 직접 계산과 G-E2E′ 연속 arm에도 같은 float32 변환을 한 번 적용한다. §3.2와 §4.4 연산은 읽은 값을 float64로 변환해 수행한다.
- yaw 격자와 C1–C6은 §4.4를 적용한다. 각도 차이를 추가 진단할 때는 양쪽 모두 유효한 양의 곡률을 가진 ±2° 이차 fit의 꼭짓점을 쓴다. 꼭짓점이 중심 격자점에서 ±0.25° 안에 있고 탐색창 안에 있을 때만 사용한다. 원형 차이를 계산하고 0.50° 초과 비율과 제외율을 보고한다. 이 진단은 갱신과 G-E2E′ 판정에 쓰지 않는다.

### 5.3 G-SNAP

- G-E2E′의 모든 경로와 S2′ 명목 경로에서 잠재 위치 오차와 평가 좌표의 차이를 축별 평균, RMS, 절댓값 p95로 집계한다. 격자 안 station의 양자화 분포, 전체 station 중 직접 계산 비율, 경로당 직접 계산 횟수와 한 번 이상 직접 계산한 경로 비율을 보고한다. 직접 계산 station의 좌표 차이는 0이다.
- 0.05 m 간격의 축별 균일 양자화 RMS 근사는 0.0144 m다. 정상 Gaussian AR(1)의 격자 밖 비율은 station당 약 4.16%다. 17 station 경로의 한 번 이상 이탈률은 약 25%로 추정된다. 이 수치는 보고용 기준값이다.
- 범위·반올림·경로 재귀와 동일 노드 저장을 검사한다. 두 RF 모델의 처음 50쌍에서 접근한 내부 노드의 합집합 중 RF station ID, RF seed, x·y 인덱스를 사전순으로 정렬한 앞 16개 고유 노드(16개 미만이면 전부)를 직접 재평가한다. 유효 yaw 마스크와 float32의 J·최소 잔차가 저장값과 일치해야 한다. 비교 계산은 저장과 같은 관측 입력과 배치 연산을 사용한다. float64 직접값과 float32 저장값의 수치 차이도 별도 기록한다. 노드 불일치나 잘못된 범위 처리는 §5.4의 수치 무효 조건이다.

### 5.4 G-E2E′ (S2′ 진입 검사)

**case 및 구성.** `R5_aA_m0`의 90° station 30개, RF seed 0–19를 쓴다. 이 case는 RUN2에서 G-OBS-1/2를 통과한 mount-0 6개 중 0.45 m 주행 pose의 δs 상관이 가장 높다(ρ_case = 0.5187741068843829). §8의 N30·M1-R(J_joint)·E1 조건을 station 1–17에 적용한다. 초기 오차는 E₀ = 0이고 gate를 사용한다. **짝 구성과 기준 구현.** 경로별 RF station·seed, Markov 전이, 잠재 위치 경로와 DR-cal 과정을 두 arm에 공유한다. snap arm은 §5.2의 좌표에서 평가하고, 연속 arm은 같은 잠재 위치에서 직접 계산한다. 각 arm은 자신의 posterior로 다음 station의 prior, 탐색창, gate와 갱신을 계산한다. 두 arm 모두 RUN3의 R5 평가용 E1 보정값(R_cap,raw, c_L, R̄_train)을 쓴다. 보정값은 R2/R4 M1-R 적격 case로만 계산했다. [RUN3 매니페스트](RUN3_20261113T085001Z/outputs/MANIFEST.json)

**경로 수와 난수.** RF 모델당 **새 경로 1,000쌍**을 고정한다. 두 RF 모델은 같은 외생 난수 원표본을 각 모델의 선택 규칙으로 매핑한다. 한 모델 안에서 경로별 원표본은 독립적으로 생성하고 각 경로의 두 arm에 공유한다. RUN3 경로와 경로별 결과는 이 표본에 포함하지 않는다. PCG64 seed는 위치 `2026111351`, DR `2026111352`, RF `2026111353`이다. 각 난수 흐름에서 경로 ID 0–999 순서로 생성한다. 경로 안에서 위치는 초기 표본, station 1–17의 혁신 순으로 x·y를 뽑고, DR은 잔여 β와 station 1–17의 w 순서로 뽑는다. RF는 station 1–17마다 station 선택, seed 선택, 재사용 판정용 균등 난수 순서로 미리 생성한다.

처음 50쌍(ID 0–49)은 §5.3의 노드 검사와 수치 점검에 쓴다. 점검 통과 후 미리 정한 **950쌍(ID 50–999)**을 계산한다. 처음 50쌍도 최종 1,000쌍에 포함한다. 중간 지표에 따른 중단이나 표본 수 조정 없이 완료 후 한 번만 판정한다.

| 지표 | 1–17 집계 방식 | 동등성 허용폭 |
|---|---|---:|
| 누적 95% 포함률 | 각 경로에서 17개 posterior의 포함 여부를 평균한 뒤 경로 평균 | ±2.0%p |
| station 17의 95% 포함률 | 끝점 포함 여부의 경로 평균 | ±4.0%p |
| G1/DR-cal RMSE 비율 | 각 arm의 G1 누적 RMSE를 동일 DR-cal 누적 RMSE로 나눈 값 | ±0.05 |
| 평균 NEES | posterior heading의 1자유도 NEES를 17개 station과 경로에 걸쳐 평균 | ±0.25 |
| G1 절대 누적 RMSE | 17개 station과 경로의 MSE 평균의 제곱근 | ±0.15° |
| gate 기각률 | 각 arm에서 기각 수의 합을 §4.4의 gate 대상 수의 합으로 나눈 값 | ±3.0%p |

허용폭은 이 한 case의 계산 근사를 판정하기 위해 사전 지정한 절대 차이다. §8의 판정 수치와 RF 표본 불확도는 §8의 본 계산에서 적용한다.

**차이의 95% 구간.** 차이의 부호는 snap − 연속이다. 아래 예외를 제외한 지표는 10,000회 짝지은 경로 bootstrap의 2.5/97.5 백분위를 쓴다. PCG64 seed는 `2026111354`이며 모델 (b), (c) 순으로 각 모델의 10,000회 표본을 생성한다. 각 반복에서 1,000개 경로 ID를 복원 추출한다. 각 경로의 두 arm과 17개 station을 함께 가져오고, 매 반복에서 RMSE, 비율, 기각률 분자·분모를 다시 집계한다.

- **누적 포함률.** 경로 i의 포함 횟수를 각 arm에서 Cᵢˢ, Cᵢᶜ로 두고, 경로 차이 Dᵢ = (Cᵢˢ − Cᵢᶜ)/17의 평균을 점추정으로 보고한다. n = 1,000이고 k는 두 포함 횟수가 다른 경로 수다. 모든 k에서 p = Pr(Dᵢ ≠ 0)의 단측 95% CP 상한 U를 구한다. k < n이면 U는 Beta(k+1, n−k)의 0.95 분위수이며, k = n이면 U = 1이다. |E[Dᵢ]| ≤ E[|Dᵢ|] ≤ p이므로 평균 차이의 보수적 구간 [−U, U]를 판정에 쓴다. 이 판정은 경로별 차이의 부호 상쇄에 기대지 않는다. U ≤ 0.02(k ≤ 12)이면 해당 지표는 `PASS`이고, 그 밖에는 `INCONCLUSIVE`다. k, U와 경로 차이의 부호별 건수 및 포함 횟수 차이를 함께 보고한다. 이 구간은 고정 RF bank를 조건으로 하는 경로 분포에 적용한다.
- 끝점 포함률은 snap만 포함한 수와 연속만 포함한 수에 각각 97.5% 양측 Clopper–Pearson 구간 [L₊, U₊], [L₋, U₋]을 계산해 [L₊−U₋, U₊−L₋]을 쓴다. 이 차이 구간의 포함 확률은 최소 95%다.
- gate 기각·대상 개수 쌍이 두 arm에서 다른 경로가 5개 미만이면, 그 비율에 대한 단측 97.5% Clopper–Pearson 상한 U를 쓴다. snap arm의 경로별 gate 대상 개수를 17로 나눈 평균을 q̂라 할 때, q_L = q̂ − √(ln(40)/(2·n)) (n = 1,000)으로 그 기댓값의 단측 97.5% Hoeffding 하한을 둔다. q_L > 0이면 [−U/q_L, U/q_L]을 [−1, 1]로 제한해 쓴다. 정규화한 기각·대상 개수를 각각 a, b, 연속 arm의 모집단 기각률을 r이라고 두면 각 arm의 a − r·b는 [−r, 1−r] 안에 있다. 두 arm의 차이는 불일치 경로에서만 생기며 절댓값이 최대 1이다. q_L ≤ 0이면 해당 지표는 판단 유보다.
- 유효한 분모가 없는 원표본이나 bootstrap 표본이 하나라도 있거나, 위 예외 밖에서 bootstrap 구간이 폭 0으로 퇴화하면 해당 지표는 판단 유보다. 누락 경로는 `INVALID`다.

**구현 확인.** 본 경로를 생성하기 전에 n = 1,000에서 k = 0, 12, 13, 1,000의 경계 사례와 k에 따른 상한의 단조성을 검사한다. 최종 판정은 저장한 경로별 집계에서 재계산해 대조한다.

**판정과 중단.**

| 상태 | 조건 | 조치 |
|---|---|---|
| `INVALID` | 필수 입력 또는 노드 조회 검증 실패, 짝의 외생 입력 불일치, 누락 경로, 비유한 필터 상태·공분산, P_EE ≤ 0 | 발견 즉시 중단하고 기록한다. 원인 수정 후 같은 seed로 50쌍부터 재실행한다. 정상적인 관측 결측·window miss·gate 기각은 §4.4에 따라 기록한다 |
| `PASS` | 모델당 1,000쌍 완료 후 두 모델 각각의 6개 구간이 모두 각자의 닫힌 허용구간 안에 포함 | S2′ 1차 계산 진입 가능 |

| `INCONCLUSIVE` | 그 외에 구간이 허용구간 경계를 걸치거나 지표가 판단 유보 | 진입 검사에서 중단 |

`FAIL` 또는 `INCONCLUSIVE`면 진입 검사에서 종료한다. 경로 추가, seed 교체, 허용폭 변경을 통한 재시도나 snap 모델 정의 변경을 통한 진입은 이 사양의 범위 밖이다. 이 검사의 허용 주장은 한 case의 고정 RF bank와 공통 보정값에서의 두 계산 방식 비교에 한정한다. §8의 과학 판정과 6개 case의 일반화는 별도 본 계산 범위다.

## 9. 계산 절차

## 11. 한계와 다음 단계

- RT station 간격 2 m, sweep 90°, 복도 형상 1개, R4의 90° station 10개라는 한계가 남는다. **최종 판정은 G1-RT-TB3-001 데이터에서 같은 규칙으로 반복한다.** 이 사양의 결과는 모델 선택용이다.
- E1의 곡률은 잘못된 최소에서 날카로울 수 있다. c_L LORO 보정과 E2/E3 비교로 검사한다.
- M1-R은 가정한 위치 prior에 의존한다. G-E2E′는 고정 RF bank의 R5_aA_m0에서 양자화 효과를 검사한다. 실제 위치 오차의 정상성·상관·분산과 A3 폐루프는 별도 검증 대상이다.
- Step 3는 보류다. 향후 PROCEED_A2 또는 INTEGRITY_ONLY이면 선택된 조합의 G1-RT-TB3-001 재판정과 passive 경로를 검토한다. STOP이면 E2/E3 후보와 실패 case를 기록한다.
