## 1. 연구 질문

실제로 획득 가능한 5점 편파 sweep과 인과적 위치·heading prior를 사용해 단일 anchor에서 재방문 간 multipath 오차를 올바르게 전파하면 heading 불확도와 DR-cal 대비 정확도를 함께 확보할 수 있는가?

1. **재방문·스케일.** 비슷한 장소에서 반복되는 편파 오차와 첫 방문부터 잘못 좁아지는 분산을 각각 계량한다. 둘을 함께 모델링했을 때 R4_aB에서 보인 두 실패 양상이 줄어드는지 시험한다.
2. **잔여 오차.** R2_aA처럼 재방문이 없어도 남는 하향 꼬리를 분리한다. 대칭 두꺼운 꼬리, 방향성 잔차, 후보 선택·피드백을 구분하고, 남은 failure가 전체 평균에 가려지는지 확인한다.
3. **지속 정확도.** 초기 heading 오차 $E_0=0$에서 같은 DR 과정을 공유하는 짝지은 비교로, 관측 방문 범위 안에서 G1이 DR-cal보다 앞서기 시작하는 구간과 그 이후 지속 여부를 판정한다.

## 4. R4_aB에서 드러난 오차를 다룰 모델

### 4.1 반복되는 site 오차

후보 $j$가 같은 물리 heading을 나타내는 국소 가지의 관측식은 $\operatorname{wrap}_{180}(z_{t,j}-\psi_t)=\operatorname{wrap}_{180}(b_t+\epsilon_{t,j})$다. $b_t$는 공통 평균이 0인 site 효과이고 $\epsilon_{t,j}$는 방문 내 오차다. 조건부 분산 $r_{t,j}^{\rm within}$은 geometry와 후보 곡률의 정보를 쓰되, G-T1의 같은 위치·조건 안 seed 변동에서 보정한다. site 분산은 seed를 평균한 station 간 성분에서 추정하며, 유한 seed 평균 오차를 분리한다. 후보들은 한 sweep의 대안 가설로 갱신한다.

- S-A는 기존의 일반 RF 상관 상태를 site 상태로 대체한다. site 효과는 같은 anchor에서 인과적으로 연계된 방문 사이에 잠재 상태와 heading과의 교차 공분산으로 유지한다. 같은 곳을 두 번 측정하면 공통 site 오차를 한 번만 모델링한다. DR bias 상태는 별도로 전파한다.
- 재방문 공유·독립·부분 상관의 선택과 station 간 상관의 채택은 G1-RT-TB3-002 §6의 C1–C3 조건을 적용한다. 부분 상관 가지는 C1–C3을 근거로 물리 위치에 대한 양의 준정부호 공분산 $K$를 특성화에서 적합한다. 정확한 동일 위치에서 공유하는 극한과 멀리 떨어진 위치에서 독립인 극한을 검증한다. K 진단의 Markov 계수와 곡선 재사용은 동결 회귀에 쓴다.
- 연계는 주행 계획의 정거장 ID 및 시점까지의 odom·range 위치분포로 한다. 초안은 연계를 확정할 수 없는 스케줄 방문에서 갱신을 보류하고 DR 예측을 보고하는 방식을 제안한다. 연계 가능 여부는 운용 입력만으로 정하고, 보류까지 포함한 적용 가능 범위를 기록한다.
- 조건부 분산과 site 분산을 따로 다룬다. 같은 site 성분을 E1의 전체 잔차 분산, 일반 AR 상태와 site prior에 반복 계상하지 않도록 선형 한계 시험에서 예측 공분산을 대조한다.

### 4.2 초기 분산 스케일과 꼬리

- 여기서 $K_{ts}$는 대각 성분이 1인 site 상관행렬이다. G-T1에서 각 조건의 기준 site 분산 $\bar r_t$를 정의하고, 스케일 arm의 예측은 예를 들어 $\operatorname{Cov}(b_t,b_s\mid\kappa)=\kappa\sqrt{\bar r_t\bar r_s}\,K_{ts}$로 둔다. $\bar r_t$의 기준은 특성화 C4의 E1 정규화와 정합되게 고정한다. $\kappa$는 site 분산 비율이다. 후보의 $r^{\rm within}$은 스케일 대조에서 고정해 site 분산 변화만 비교한다.
- S-C는 C4–C5 구조를 따른다. 첫 갱신부터 $\kappa$ 분포와 적합 불확도를 예측에 적분한다. 적분할 때 같은 조합의 반복 관측은 같은 잠재 스케일과 연계 site 효과를 공유하고 sweep별 우도를 한 번씩 반영한다. 새 조합의 prior는 특성화에서 동결한다. 기본 대조는 특성화에서 동결한 전역 단일 스케일이다. 혁신으로 추정한 단일 스케일을 run 중 대입하는 방식은 사전 지정 민감도로 둔다.
- **상위 사양 개정 의존성.** 현 G1-RT-TB3-002 §5 C5는 BLOCK_C로부터 가져온 log-scale 표준편차 하한 **0.81**을 사용한다. 이 값은 이번 모델의 모수·prior에 사용할 수 없다. 특성화 전에 출처 충돌을 해소하는 개정이 필요하다. 초안은 G-T1 세 조합의 station-cluster 적합과 조합 분산 추정의 불확도를 함께 전파하는 방식을 제안한다. 조합 수가 적어 예측 분포를 고정할 근거가 부족하면 S-C의 확인 진입을 보류한다.
- S-D는 C6 조건에 따라 도입하는 **site 효과의 두꺼운 꼬리**다. 제안 구현은 자유도 $\nu>2$인 분산 정규화 Student-t site 효과다. 상관된 site 묶음 안에서는 같은 공분산을 유지하고, 독립으로 지정한 묶음 사이에서는 별도의 t 혼합 변수를 사용한다. $\kappa$와 $\nu$가 각각 조합 간 스케일과 조합 내 꼬리를 설명하는지 특성화에서 확인한다. 첫 방문부터 heading 점추정치를 기준으로 각도를 펼쳐 주변 heading 사후분포의 2.5%·97.5% 분위수를 구하고 원형으로 되돌린 95% 구간을 모든 확인 arm에서 평가한다. 다중 가지가 만드는 넓은 구간도 폭과 함께 기록한다. $\pm1.96\sqrt P$ 포함률과 NEES는 동결 S2′와의 비교용으로 병기한다.

## 5. R2_aA 잔여 실패와 대조 설계

R2_aA의 비복원 무작위 방문(K3) 포함률은 87.35%로 기준 88%에 미달했다. K4 oracle 스케일 적용 시 Markov는 75.88%, K5 고정 oracle 편향 제거 시 73.82%였다. K6의 R2_aA SKIP arm에는 실제 생략이 0건이었다. Q1의 truth-aligned 창에서는 $e<-5^\circ$가 30.95%, $e>+5^\circ$가 4.76%였다. 이 비대칭은 해당 창에서 얻은 진단이며 운용 창에서 별도로 검증한다. [K0–K8](https://github.com/myoungsunk/sionna-resimulation/blob/b070c8685e03133cfe4b846b530181acf66260b8/research/G1_SWEEP_HEADING_FLOOR_20261113/DIAG_K_20261114/REPORT_KO.md) · [Q1 station 요약](https://github.com/myoungsunk/sionna-resimulation/blob/d9701160ffc498af7c73a3d02c2600613d82629b/research/G1_SWEEP_HEADING_FLOOR_20261113/DIAG_Q1_20261114/q1_case_table.csv)

확인 데이터 해제 전, G-T1의 동일 경로·복소 잡음에서 다음 순서로 잔여 실패를 분리한다.

1. **RF와 후보 선택.** LoS/full 및 정렬 창/인과적 창을 개발 진단으로 짝지어 비교한다. 모든 후보의 signed residual, 선택 후보, 경계·평탄 여부, 혁신·gain, 갱신 전후 heading과 양쪽 미포함을 남긴다. 창 밖, 다른 최소점 선택, gate 기각과 작은 $P$를 따로 센다. 초기 관측에서 발생한 오차와 다음 prior의 이탈을 시간순으로 추적한다.
2. **꼬리와 방향성.** 공통 zero-mean 가우시안 → 대칭 두꺼운 꼬리 → 같은 꼬리 구조에서 방향성 추가의 순서로 비교한다. 방향성 arm은 range·고각·sweep 곡률/후보 간격처럼 그 시점에 관측 가능한 변수로 조건부 위치 효과 $m(w_t)$와 양·음 꼬리를 분리한다. 위치 효과를 쓸 때 혁신은 $\operatorname{wrap}_{180}(z_{t,j}-\hat\psi_{t\mid t-1}-m(w_t))$이고, $m$의 추정 불확도도 전파한다. 절편이나 별도 꼬리 폭은 물리 station 그룹을 제외한 특성화 검증에서 방향·재현성이 확보될 때만 동결 후보로 채택한다. RT case 이름, 실제 heading과 LoS/full 차분은 운용 입력에 포함하지 않는다.
3. **독립 평가층.** BLOCK_C R2_aA는 기전·회귀를 위한 별도 행으로 둔다. 새 G-T2/G-V에서는 후보 모호성이 높은 **첫 방문** 및 조건부 상·하 꼬리를 각 형상×anchor에서 필수로 보고한다. 모호성 층과 최소 물리 station 지지도 G-T1만으로 동결한다. 확인에서 해당 층이 비거나 지원이 부족하면 잔여 모드는 미확인으로 기록한다. 원래 R2_aA 환경에 대한 재현·해소 주장은 그 환경을 독립적으로 확인할 수 있을 때에 한한다.

## 6. 특성화에서 동결할 항목

- `CHARACTERIZATION_PLAN.json`에는 C1–C10의 계산법과 §4–5의 추가 추정량, 그룹 분리, 초기화와 데이터 부족 기준을 기록한다. R2_aA K3–K6에서 드러난 잔여 기전도 §5의 진단으로 먼저 분리한다. 기전 분리의 범위와 남은 불확실성을 기록해 확인 진입 여부를 정한다. 상위 C8에서 LoS 모델 오차 우세 조건이 나오면, G-T1에서 관측 체인 수정을 먼저 검증하고 특성화를 다시 동결한다.

## 7. 확인 지표와 판정 초안

### 7.1 Integrity 우선

- 제안 기준은 S2′의 수치 문턱을 P-A의 5점 프로토콜에 적용한다. $E_0=0$, 1–17 방문의 명목 95% 구간 포함률 ≥88%, 17번째 방문 포함률 ≥80%, 평균 NEES ∈[0.5, 2.0]이다. 전체와 6개 형상×anchor 조합을 표로 낸다. **전체와 각각의 확인 조합, 사전 고정한 첫 방문·재방문 평가층의 누적 포함률·NEES가 기준을 충족해야 전체 적용을 검토한다.** 끝점 기준은 17번째 방문이 있는 경로에 적용한다. 새 데이터의 모호성 높은 첫 방문층에도 누적 기준을 적용한다. 부족한 층과 각 표의 실제 분모를 명시한다.
- 기각·생략·무효·창 이탈 방문에는 해당 시점의 필터 출력과 구간을 사용해 평가한다. 출력 자체가 없으면 포함률 실패에 넣고 NEES 누락을 별도 보고하며, 그 층의 종합 integrity는 미확인으로 둔다. 후보가 왼쪽/오른쪽으로 틀린 경우와 truth가 구간 하단/상단 밖에 놓인 경우를 구분한다. 종점·초기 1–5 방문·후반, 연속 miss와 연속 DR-only 길이, 구간 폭도 보고한다. `accepted-only` 수치는 개발 진단으로 둔다.
- 95% CI는 형상×anchor를 고정 층으로 두고 독립 물리 경로 또는 물리 station 묶음을 공유하는 경로 그룹을 짝지어 재표집한다. 한 그룹의 순서와 재방문 기록을 통째로 유지한다. 같은 RF 은행에서의 DR Monte Carlo 변동은 별도 CI로 보고한다. 독립 물리 그룹이 사전 최소 수보다 적으면 RF 표본 CI와 그 CI를 요구하는 정확도는 미확인으로 남긴다.

### 7.2 정확도와 교차점

- Integrity 통과 후에만 정확도를 판정한다. 초안은 S2′의 RMSE 기준인 누적 G1/DR-cal ≤0.8, 짝지은 cluster 95% CI 상한 <1, G1 누적 RMSE ≤3°, 사전에 정한 경로·조합별 비율 <1, 후보 게이트 기각률 ≤20%를 유지하는 것을 제안한다. 재방문 생략·연계 불확실·관측 무효는 gate 기각과 구분해 별도 분모와 비율을 보고한다. 경로 집합과 분모는 확인 해제 전에 고정한다. [S2′ §8](https://github.com/myoungsunk/sionna-resimulation/blob/d9701160ffc498af7c73a3d02c2600613d82629b/research/G1_SWEEP_HEADING_FLOOR_20261113/SPEC2_KO.md#8-사전등록-판정-규칙)
- 방문별 $Q(n)=\mathrm{RMSE}_{G1}(n)/\mathrm{RMSE}_{DR-cal}(n)$를 관측한다. $N^*$는 $Q(n)<1$이 처음 관측된 방문이다. 끝까지 유지된 최초 방문 수, 전체 방문 중 이긴 비율, 짝지은 CI, $Q(n)=1$ 경계를 함께 낸다. $\mathrm{RMSE}_{DR-cal}=0$인 방문은 양쪽 절대 RMSE를 기록하고 비율과 교차의 분모에서 분리한다. 끝까지 교차가 관측되지 않으면 $N^*>N_{\rm obs}$로 표시한다. 거리·시간은 실제 경로 좌표와 timestamp가 연결된 방문에만 부여한다. 외삽은 별도 항목으로 표기하고 판정은 관측 범위에 한정한다.
- 필요한 층이 미확인 또는 미통과면 전 범위 우위 판정을 유보한다. 제한 범위 평가는 확인 전에 고정된 적용 범위와 별도 기준을 갖춘 경우에만 검토한다. 풀링된 성능만으로 R2_aA형 잔여 모드의 해소를 선언하지 않는다.
