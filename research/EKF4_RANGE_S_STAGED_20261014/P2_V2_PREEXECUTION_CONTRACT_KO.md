1. **사전감사 필수**: workflow checkout 뒤, 모델 import/pytest/진단/입력생성 이전에 audit-only Python이 계약·소스 AST·필요한 파일·진단 테스트의 optional metadata 접근·실행 명령 및 결정을 점검하고 `PRE_RUN_AUDIT.json`을 보존. 코드가 동일한 Git SHA인지 확인. 감사는 해당 구체 실행을 **허용/보류**하는 결정만 내리고 과학 결과를 PASS로 판정하지 않는다.
2. **검사 의미 분리**: R1/R2의 `curvature_ratio`, `step_acceptance` 등 경로 의존 메타데이터를 보편적인 solver acceptance condition으로 사용하지 않는다. 해당 branch를 강제·모킹한 instrumented unit test에서만 관찰하고, 전체 수렴 판정은 원 `status`, 원래 기울기 허용치, 독립 residual/gradient/국소 P로 한다.
3. **수치 단위 문제**: fixed failure 4.5s·6.0s의 재생/수학 결과는 P2 프리플라이트에 포함하되, 진단 로그 형식 오류가 본 결과를 무효로 하지 않도록 독립 결과로 보고. 실제 `solver nonconvergence`는 **해당 estimator/조건 무효**, `NUMERICAL_FAILURE`로 남기며 성공인 양 대체하지 않는다.

5. **대표→범위**: P2 프리플라이트는 3경로×2bias×1 trial, 4개 모델 전 시점, 두 기존 실패의 고정 출력 검증. 각 모델 결과/부분 trace를 구분 보존. 프리플라이트 수치 FAIL이면 전수 실행은 보류하고 실패 증거·원인·결정 경계를 보고. 성공 후 동일 P2 본 실행(모든 100 trials/조건)을 별도 승인된 커밋에서 시행.

## 사전감사 검증 질문 (각각 다음 결정을 바꾸는 것만)
