# R3 솔버 수정 사전 감사 결정 (2026-10-14)

**목적:** D3의 4개 동결 P2 실패에서 증명된 `GN full step 실제 비용 감소, float64 비용차 양수, step 후 gradient<1e-8` 문제만 수정한다.

변경 경로: `core.py`의 `map_update` 스텝 수용부. P2 원 `P2_SPEC.json`, `synthetic.py`, RF model, prior 및 Q/R, 80반복/gradient 1e-8은 변경하지 않는다. 처음 시도는 비용 계산 반올림 한계 근처에서 **충분히 작은 GN 종결 스텝**, 새 gradient가 정확히 기존 기준 이하, gradient 개선 및 3점 방향미분 적분에서 실제 감소와 방향 일치 확인 시 수용한다. 단순 cost 여유만으로 승인하지 않고, 일반 Armijo는 비교 가능한 진짜 감소가 있을 때만 수용한다.

**중요 한계:** 3점 방향미분은 구간 전체 적분에 대한 엄밀 오차 증명이 아니다. 이 변경은 P2 synthetic R3 수치 후보로만 취급하고, 동결 4개 실패와 음성 대조·새 대표 조건을 통과해야 채택한다. 원 가설 결과를 유리하게 바꾸거나, 독립 RF 성능을 주장하지 않는다. 실패 시 해당 수치 사례를 저장하고 원인 재진단하되 다른 모델 결과와 과학적 신뢰도를 섞지 않는다. 모든 실행 전에 해당 source SHA·스크립트/진단 AST·source/원본 입력 hash 감사 필수.

**단계:** source audit→ P0/P1→R1/R2→ 네 archived failure 수치 확인(이전 D3 독립 고정밀 결과와 일치)→P2 6셀 대표→전체 P2. **P3–P6는 실제 frozen RF asset 및 LUT/좌표/관측 모델의 독립 code 감사 후 구현/실행.** 아직 없는 코드를 실행한 것으로 보고하지 않는다.
