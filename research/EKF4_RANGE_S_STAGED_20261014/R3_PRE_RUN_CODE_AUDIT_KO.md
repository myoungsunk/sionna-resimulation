## 해결 방향·반증
R3는 `J(y+d)-J(y)=∫g(y+t d)ᵀd dt`로 별도 평가한다. 일반적인 비용 감소가 충분히 크게 구분되면 직접 Armijo, 그렇지 않으면 5점 적분과 3점 적분의 수렴, 기울기 감소, Armijo의 실제 감소를 확인한다. 성공 가능성을 위해 허용치나 RF 우선 가중치를 변경하지 않음. 후보가 유효한 감소를 보이지 않으면 기존처럼 미수렴으로 기록.

R3 회귀는 직전 R1/R2 고정 실패 입력, 네 D3 실패 입력, 비수렴·비매끄러움 음성 대조를 먼저 검증하고, 대표 6조건, 이후 동결 P2 전체 실행한다. **P2에서 scientific claim이 미지지라도 P3 자료 적격성 검사는 별개**이며, 국소 P4/P5/P6에는 실제 필요한 의존성만 부여한다. 원본이나 입력 위변조는 강한 차단.
