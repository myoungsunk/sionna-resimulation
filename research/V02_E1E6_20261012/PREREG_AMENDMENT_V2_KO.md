# V02 E1–E6 사전등록 개정 v2 (확증 실행 전)

날짜 2026-10-12. `PREREG_KO.md`는 수정하지 않고 보존한다. 이 개정은 **개발 seed 2900–2931에서만** 얻은 정보에 근거하며 확증 seed 3000–3511은 아직 열지 않았다. 개정 내용은 PF 구현 세부와 arm 목록(M=1 추가)뿐이다. 해석 규칙 R1–R4, 평가 지표, 구간, V1–V3 유효성 기준은 변경하지 않는다.

## 개정 사유 (개발 결과, 숨기지 않음)
PREREG §3.1 그대로의 PF(부트스트랩, 정적 보정 상태에만 Liu–West a=0.98, N=20k)를 개발 seed 32개에서 점검했다.
| 설정 | CONS_LARGE 48 s 위치 RMSE: 20k vs 80k 상대차 | V3(≤3 %) |
|---|---|---|
| 원안 (정적 3상태 지터, 부트스트랩) | 7.7 % (NEES 4.6 vs 4.1; N=5k는 NEES 26) | **불합격** |
| + 국소 최적 제안분포 (오도메트리 노이즈 주변화) | 17.3 % | 불합격 |
| 지터 대상을 전 상태 6개로 (a=0.995) | 10.7 % | 불합격 |
| 지터 대상을 yaw+정적 3개 (a=0.98) | 5.6 % | 불합격 |
| **전 상태 6개 지터, a=0.98 + 국소 최적 제안** | **0.4 %** (SMALL 1.3 %, HIGH 2.5 %) | **합격** |
V3를 만족하는 구성은 마지막 하나뿐이었으므로 이를 PF 명세 v2로 고정한다. 이 선택은 개발 seed에서 이루어졌고, 선택지 5개 중 하나를 고른 것이라 **선택 편향이 있을 수 있다**(확증 seed가 이를 독립적으로 점검한다).

## PF 명세 v2
- 입자 N=20,000, 입자 prior = 필터 prior (HIGH는 8성분 부호 혼합 prior, 성분 표준편차 = 수준값의 5 %).
- 국소 최적 제안: 입자 상태가 주어지면 오도메트리 모델은 공유 입력 노이즈 (nd,ng)에 선형 가우시안이다. 주변 우도 N(y; 0, S), S = (ε/b)²Q_d + (L/D)²Q_g + Q_o 로 가중하고 (nd,ng)는 조건부 분포에서 추출(Matheron 규칙). range 우도는 갱신 후 상태로 가중.
- ESS<N/2에서 systematic resampling, 직후 **전 상태 6개**(yaw는 기준 입자 상대 wrap)에 Liu–West 축소 지터(a=0.98; 평균·공분산 보존). 이는 커널 평활이라 posterior의 근사이며 PF를 “정확한 참값”이 아니라 “수렴 점검을 통과한 기준 근사”로 취급한다.
- 평균·공분산은 가중 모멘트(yaw 원형 평균).

## 그 밖의 변경
- arm 목록에 `GSFXY1`(GSF, M=1) 추가. 개발 seed 8개×세계 3개(24회)에서 EKF와 GSF(M=1)의 상태·공분산 최대 차이 0 확인(§3.2 요구).
- 개발 seed 전체 arm 점검은 확증이 아니며 결과를 판정에 쓰지 않는다. 다만 사전에 알린다: 개발 단계에서 EKF는 CONS-LARGE에서 실패(NEES≈9), PF는 구간 안(3.5), GSF M=4–16은 4.6–4.8로 EKF보다 낫지만 여전히 구간 밖이었다. 이 사전 지식이 해석 규칙을 바꾸지는 않는다.
