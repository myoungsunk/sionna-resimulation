# PALO — DR/IMU 주도 편파 선택적 갱신의 오라클 대조 및 실패 메커니즘

**참조:** `myoungsunk/sionna-resimulation`, commit `4c43020f04fbbf7d0510f792c4ab99a1d9f5ddb5`, `research/POL_HEADING_RESEARCH_20261107`.

**판정:** `ONE_STEP_COUNTERFACTUAL_VERIFIED / ORIGINAL_S4_AFFINE_REPLAY_PARITY_PASS / EXACT_NONLINEAR_ORACLE_CLOSED_LOOP_NOT_RUN`.

> 본 파일은 기존 NPZ에 대해 독립적으로 계산한 **동일 사전상태의 단일 갱신 반사실**과 추정기의 기하·오차 패턴 분석을 기록한다. 미래 관측을 사용하지 않는 실제 비선형 LUT 재귀 오라클 결과는 아니다. 원본 데이터를 수정하거나 Sionna RT를 재실행하지 않았다.

## 1. 한 시점 오라클 (동일 S4 prior)

`k`의 원본 S4 갱신 직전 `x^-_k,P^-_k`와 실제 S4 갱신 후 `x^+_k,P^+_k`에서, 참값으로 판정하는 완벽한 선택기를 적용하였다. 선택이 이뤄진 결과는 다음 시점으로 전달하지 않는다.

- Heading Oracle: `|wrap(psi^+ - psi_GT)| < |wrap(psi^- - psi_GT)|`인 경우에만 업데이트.
- XY Oracle: `||p^+ - p_GT|| < ||p^- - p_GT||`인 경우에만 업데이트.
- Joint Oracle: 두 오차를 모두 감소시킨 경우에만 업데이트.
- 기존 S4 게이트가 거절한 관측은 새로운 후보를 생성하지 않았다.
- 40초 이후 779개 시점, LoS/Full, B0/L0/L1/L2.

| 환경 | 자이로 수준 | S4 Heading RMSE ° | Heading Oracle ° | S4 XY RMSE m | XY Oracle m |
|---|---|---:|---:|---:|---:|
| LoS | B0 | 0.8976 | 0.8965 | 0.0981 | 0.0980 |
| LoS | L0 | 0.8927 | 0.8915 | 0.0981 | 0.0981 |
| LoS | L1 | 0.8766 | 0.8754 | 0.0983 | 0.0982 |
| LoS | L2 | 0.9314 | 0.9304 | 0.1014 | 0.1013 |
| Full | B0 | 1.5400 | 1.5284 | 0.3075 | 0.3063 |
| Full | L0 | 1.5288 | 1.5171 | 0.3042 | 0.3030 |
| Full | L1 | 1.4062 | 1.3944 | 0.3008 | 0.2996 |
| Full | L2 | 1.2919 | 1.2799 | 0.3081 | 0.3070 |

동일 prior에서 즉시 이득은 작다. 원래 S4 궤적에 누적된 과거 잘못된 갱신의 효과는 제거되지 않는다.

## 2. Full B0 손익 분해

40초 이후 원래 S4의 751개 수용 관측 중:

| 헤딩 | XY | 수 |
|---|---|---:|
| 개선 | 개선 | 317 |
| 개선 | 악화 | 133 |
| 악화 | 개선 | 136 |
| 악화 | 악화 | 165 |

헤딩 악화 301건 중 297건은 **실제 헤딩 오차를 줄여야 하는 방향과 반대로 보정**, 4건은 **방향은 맞았으나 지나치게 보정**한 경우다. 단순 gain 축소만으로 보정 방향 오류를 제거할 수 없다는 것이 핵심 관찰이다.

Full−LoS 편파비 차이의 절댓값을 단순 품질 지표로 사용해 수용 관측을 구분했다. 이 지표는 실제 온라인 관측이 아니라 **같은 시간/기하에서 대응되는 두 RF 채널을 사용한 오프라인 기준**이며, 아래의 값은 새로운 게이트 임계값으로 채택할 수 없다.

| |Full−LoS 절대차| 수용수 | 헤딩 악화 비율 | 갱신의 헤딩 제곱오차 총 순이득 deg² | XY 제곱오차 총 순이득 m² |
|---|---|---:|---:|---:|---:|
| Q1 | 0–.02 | 348 | 35.1% | +4.455 | +0.0877 |
| Q2 | .02–.05 | 179 | 41.3% | +8.409 | +0.0750 |
| Q3 | .05–.10 | 110 | 55.5% | +3.399 | −0.0254 |
| Q4 | .10–.20 | 94 | 38.3% | +8.748 | −0.0580 |
| Q5 | >.20 | 20 | 40.0% | **−8.810** | **−0.2026** |

오염이 큰 관측이 항상 해롭지 않다. 예를 들어 .10–.20에서는 순헤딩 이득이 양수였다. 단순히 신호 오차 임계값으로 전부 버리는 정책은 유익한 RF 보정도 소실한다.

**NIS가 작아도 해로울 수 있다.** NIS 0–1 구간에서 265개의 헤딩 악화 갱신이 있었으며, NIS 3.841–6.635 구간에서는 32개 중 5개만 헤딩을 악화시켰다. NIS는 혁신 크기를 정규화하는 지표이지 보정 방향이 참상태에 가까워지는지 예측하는 충분통계량이 아니다.

큰 손실 사례: Full B0 96.8/97.0/97.2초에서 헤딩 절대오차가 각각 0.826→1.788°, 1.796→2.513°, 2.512→2.936°로 증가했다. 같은 구간의 Full−LoS 편파비 차이는 −0.224/−0.241/−0.217이고 NIS는 4.559/3.457/1.799로 모두 기존 S4 게이트를 통과했다. 이 사례가 특정 반사경로 때문이라는 인과 판정은 별도 RF 구조 조사 없이 확정하지 않는다.

## 3. 과신 원인과 연구가설

1. **오염 지표와 추정 이득의 불일치.** FP/CIR/전력 기반의 물리적 품질, 정규화 혁신 NIS, 실제 헤딩/XY 보정 이득은 서로 다른 목표 변수다.
2. **수용 시 공분산 자동 축소.** S4 스칼라 Gaussian 관측은 오류 방향의 참값과 무관하게 업데이트 시점의 공분산을 감소시킨다.
3. **공간·방향에 따른 편파 모델 불일치.** 동일 R2의 Full−LoS 차이는 위치에 따라 다르고, 100–120초 부근에 크게 집중된다. 근접/원거리의 차이를 거리만의 인과효과로 해석해서는 안 된다.
4. **지속 오염과 재귀 자기확증.** Full−LoS lag-1 상관 약 0.880, Full B0에서 116.2–122.4초 32개 연속 큰 불일치 관측을 수용했다. 반복 갱신이 실제 독립 정보보다 과도한 정밀도를 축적할 수 있다는 가설은 타당하지만, 개별 인과 기여율은 통제 개입으로 검증해야 한다.
5. **Heading/XY 간 손익 충돌.** 같은 편파 갱신이 헤딩은 개선하고 XY는 악화시키거나 반대로 작동하는 비율이 높다. 헤딩 손익만 예측하는 분류기를 전체 상태 품질 분류기로 간주해서는 안 된다.
6. **이미 오염된 prior의 문제.** 원본 S4의 각 시점 prior를 쓰는 단일 갱신 오라클은 과거 오염과 공분산 과신을 되돌리지 못한다. 폐루프 리플레이가 반드시 필요하다.

## 4. 재귀 민감도 시험 — 과학적 채택 금지

기존 S4 공분산 갱신에서 Jacobian과 innovation을 수학적으로 복원해 원본 S4 prior 근처에 **고정 1차 근사**를 적용하는 실험도 수행했다. 전체 수용을 사용하면 원본 S4와 상태 최대 오차 3×10⁻¹³, 공분산 최대 약 3×10⁻¹⁶ 이하로 재생됐다. 반면 오라클 선택기를 바꾸면 S4 기준상태와 위치 최대 약 0.5 m, 헤딩 최대 3–6° 차이가 발생했다. 이 차이는 2° LUT 셀보다 크므로, 근사 모델의 오차 상한이 검증되지 않았다.

따라서 위 민감도 실험에서 나타난 매우 낮은 재귀 RMSE를 **성능 검증값이나 달성 가능 상한**으로 사용하면 안 된다. 또한 정답 기반 선택기 자체가 숨겨진 참상태 정보를 의사결정 비트로 인코딩하므로, 그 성능을 실현 가능한 신뢰도 판정기의 성능으로 해석할 수도 없다.

## 5. 정확한 비선형 폐루프 오라클 리플레이

동봉한 `palo_oracle_closedloop.py`는 원본 frozen `core.predict`, `gaussian_update`, `FrozenLut`를 직접 import한다. Sionna RT 없이 기존 NPZ/IMU·odometry 입력으로 8조건을 다시 실행한다. 첫 번째 실행은 **S4 원본 X/P/NIS/mask가 원본과 일치**해야만 결과를 통과시킨다.

- DR-only (4상태)와 기존 S4 replay
- 완벽한 **헤딩 갱신 손익 오라클** / **XY 손익 오라클** / **둘 다 개선 오라클**, 각 시점의 참값 기반 선택
- 원래 NIS 게이트를 함께 유지한 오라클 대조
- `|s_full-s_los| ≤ {0.02,0.05,0.10,0.20}`을 100% 알고 있다고 가정한 **RF 품질 오라클** (Full에서만 적용). 이는 추정 손익을 직접 아는 오라클과 다르다.

### 실행

```bash
python -m pip install numpy==1.26.4
python palo_oracle_closedloop.py \
  --root /path/to/sionna-resimulation/research/POL_HEADING_RESEARCH_20261107 \
  --output /path/to/PALO_ORACLE_CLOSEDLOOP_RESULT
```

출력: `SUMMARY.json`과 각 조건의 수용 결정·오차·공분산·NIS·참값 평가를 포함한 CSV.

**중요:** 이 대화 환경에서는 frozen LUT의 11,923,328바이트짜리 `.npy`를 GitHub 연결로 파일 전체 다운로드하지 못했으므로, 위 **정확 비선형 폐루프** 코드는 작성·문법 검사만 했고 실제 8조건 재귀 실행과 parity는 아직 수행하지 못했다. 결과를 계산한 것으로 표시하지 않는다.

### 채택 기준

오라클 대조이 아무리 좋아도 그 자체는 논문의 달성 성능이 아니다. 이후의 신뢰도 검출기에는 참상태·LoS 대응값·미래 관측을 입력할 수 없다. 정상 유익 관측을 거부해 드리프트 보정을 잃는 비용도 측정해야 한다. 최종 평가는 R2에서 판정기를 학습/설계한 뒤 독립 R4/R5 환경·시드에서 시행해야 한다.
