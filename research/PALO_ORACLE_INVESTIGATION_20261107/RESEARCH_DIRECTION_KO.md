# 논문 1 후속 연구 방향 — 사용자 제안 보존

2026-11-07. 이번 변경은 전달 자료와 연구 방향의 GitHub 게시다. 신규 실험·재학습·독립 감사·성능 재검산은 수행하지 않았다.

| 우선순위 | 필요한 검증 | 이유 |
|---|---|---|
| 1 | 완벽한 갱신 손익 오라클의 정확한 폐루프 재생 | 선택적 편파 사용의 개선 가능 범위 확인 |
| 2 | 완벽한 RF 오염 판정 오라클과 비교 | RF 오염 검출과 실제 추정 이득의 차이 분리 |
| 3 | DR/IMU 예측과 편파 보정 방향의 일관성 조사 | 전달 보고서의 해로운 헤딩 갱신301개 중297개가 잘못된 방향이라는 관찰 조사 |
| 4 | 공간적 연속 오염과 공분산 과신의 인과 대조 | 관측 수용과 정보 중복 축적의 영향 분리 |
| 5 | 실제 관측 가능한 지표로 신뢰도 판정기 개발 | 참값 없이 오라클 판단을 얼마나 근사할 수 있는가 |

현재 가설은 유망하지만 성능 입증 단계는 아니다. 상당수 편파 갱신의 손해와 NIS 또는 RF 오염 크기 단독 지표의 한계는 전달 보고서의 조사 결과이며, 이번 게시 작업에서 새로 검증한 수치가 아니다.

운동 예측을 기본으로 유지하면서 편파 갱신의 위험을 인과적으로 판단하는 신뢰도 평가기를 우선 검토한다. 실제 갱신 정확도와 공분산 신뢰도를 함께 검증하며, 헤딩 정확도만 개선하고 posterior를 과신하는 모델은 최종 성공으로 취급하지 않는다.

## 실행·주장 경계

- 정확 비선형 LUT 폐루프 재생과 원본 X/P/NIS/mask parity는 아직 실행하지 않았다.
- 단일 갱신 반사실, 고정 선형근사 재생, 정확 비선형 폐루프는 서로 다른 증거다.
- 참값 기반 즉시 손익 오라클은 전역적으로 최적인 장기 정책 또는 실현 가능한 성능 상한을 보장하지 않는다.
- 참값·대응 LoS·미래 관측을 실제 온라인 판정기의 입력으로 사용하지 않는다.
- 연구 방향 등록은 기존 논문의 채택 판정이나 원본 결과를 변경하지 않는다.
