# 마운트 45° 원본 채널 복원 및 이전 평가 보완

2026-10-28 Snowball의 2026-10-07 원본 실행에서 요청된 다섯 채널을 복원했다. 새 시뮬레이션은 수행하지 않았다.

이전 보고서의 없음 판정은 로컬 동결 입력 묶음에 한정됐다. 원본 실행 폴더에는 R2_aB, R4_aA/B, R5_aA/B의 mount45 Full RF H가 모두 존재한다. 이 폴더의 FULL_RF에 원본 바이트 그대로 추가했다.

12개 원격 RF 파일의 SHA-256이 원본 실행 manifest와 일치했고, 현재 사용하는 7개 RF도 동일 원본과 일치했다. 각 mount0/45 쌍은 같은 포즈 입력과 Jones 전파 경로 기록을 사용한다. 요청된 다섯 복원 파일은 RECOVERY_RECEIPT.json에 크기와 SHA-256을 기록했다.

| 채널 | 포즈 수 |
|---|---:|
| R2_aB_m45 | 1303 |
| R4_aA_m45 / R4_aB_m45 | 각각 922 |
| R5_aA_m45 / R5_aB_m45 | 각각 1883 |

배열 축은 pose × 257 frequency bins × RX(+45,-45) × TX(+45,-45)이다. 기존 R2_aA_m45는 원래 입력에 있으므로 중복 복사하지 않았다.

동일 조건의 Full RF 재시뮬레이션은 불필요하다. 현재 파이프라인에 없는 다섯 조건의 특징·OOF/MR/HG 예측과 현재 센서/필터 조건의 trace 생성은 별도 작업으로 필요하다. 과거 S6 결과는 현재와 센서·필터 조건이 달라 그대로 대체할 수 없다. 기존 학습 집합을 동결한 예측과 새 45° 학습 데이터를 추가하는 실험은 구분한다.

ASSESSMENT.json은 원본 동일성 검증, RECOVERY_RECEIPT.json은 이번 실제 복원 검증이다. 기술적 무결성 확인은 기존 과학적/물리적 검증 한계를 변경하지 않는다.
