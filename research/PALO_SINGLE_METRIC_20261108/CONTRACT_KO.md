# PALO — 지표 하나씩 사용하는 선택적 편파 갱신

## 질문
기능 블록을 누적하지 않는다. 기존 S4 운동모델·관측·공분산·NIS 게이트를 그대로 유지하고, **추가 지표 하나의 임계값**만으로 전량 수용/거부한다. 참값은 정책 입력에 사용하지 않는다. 새 분류기, 바이어스 보정기, alpha 조절기, 윈도우 스무더는 추가하지 않는다.

## 원본과 선행 오류
- 입력은 원래 frozen manifest로 해시 검증한 `4c43020` R2/Anchor B/seed0, LoS/Full × B0/L0/L1/L2. 원래 scalar EKF 재생 X/P/NIS/수용 마스크 16조건 parity를 첫 관문으로 삼는다.
- 이전 `PALO_MOTION_CIR_RISK`의 `run_analysis.py`는 t≥40초로 만든 prior 행의 절대 k에서 200을 빼고, 자르지 않은 979프레임 CIR 배열에 접근했다. 따라서 **현재 상태와 40초 전 RF가 결합된 오류**가 있다. 해당 CIR/Full−LoS 연관성·분류기 결과 및 '큰 헤딩 손실의 RF 차이가 작았다' 주장은 재검증 전 사용하지 않는다. 원래 운동 통계·Hpsi·보정량은 이 오프셋의 대상이 아니다.
- 이번 실행에서는 절대 k, t, pose_id, 복원 s와 원본 s를 대조하고 절대 k로 결합한다. 원본은 보존하고 정정표를 새 폴더에 게시한다.

## 단일 지표 정책
공통 기존 NIS99=6.6348966010212145를 통과한 뒤, 아래 중 **하나만** 추가 적용한다.

1. `h_prior`: 현재 운동 예측 상태의 |∂h/∂ψ|.
2. `h_fd1`: 같은 위치에서 ψ±1°의 중앙 할선 기울기. 국소 구간 경계 민감도를 비교한다.
3. `h_candidate`: 아직 채택하지 않은 일반 S4 갱신 후보의 위치·헤딩에서 |∂h/∂ψ|. 후보 상태는 실제 수용 전까지 전파하지 않는다.
4. `h_sroot`: 현재 예측 위치를 고정하고 수신 s에 대응하는 정확한 piecewise-linear LUT 역해를 찾는다. 여러 역해 중 현재 예측 헤딩에 원형거리상 가장 가까운 해의 기울기를 사용한다. 역해가 없으면 거부한다. 역해 존재만 검사하는 `root_exists`를 별도 대조한다. 역해 헤딩으로 상태를 직접 교체하지 않는다.

위 네 정의 각각에 대해 τ={0.05,0.1,0.2,0.3,0.5,0.75,1,1.5,2,3} s/rad의 **상한(≤τ)**과 **하한(≥τ)**을 모두 시험한다. 큰 기울기가 항상 나쁘다는 전제를 두지 않는다.

기존 지표의 직접 사용 대조: 후보 |δψ|, NIS, |innovation|, FP13 국소폭, FP25 국소폭, FP±2tap Δs, 현재-직전 s 변화량. 각 지표는 독립 정책이며 조합하지 않는다. 구체적인 임계값은 `experiment.py:policies()`에 동결한다.

## 평가
- 130정책 × 8조건 = 1,040개의 자기 상태·공분산 비선형 폐루프, 각각 979시점.
- 모든 정책은 같은 초기 상태에서 시작하며 선택된 X와 P를 모두 다음 시점으로 전파한다. 기존 S4 궤적에서 라벨만 바꾸지 않는다.
- 전체 주 평가 t≥40s; 개발 40≤t<120s; 공백 120≤t<140s; 후반 평가 t≥140s.
- 가족별 공통 τ/방향 하나를 Full 4조건 개발구간의 `max(Heading RMSE/DR, XY RMSE/DR)` 최악비율 최소로 선택한다. 동률에서는 적은 수용수·정책 이름 순서. 조건별 참 바이어스에 따라 온라인 규칙을 교체하지 않는다.
- 선택 규칙은 후반 결과를 보고 바꾸지 않는다. 전체 sweep도 전부 보고하되 '사후 가장 좋은 조건별 값'을 실제 공통 알고리즘 성능으로 주장하지 않는다.
- Heading/XY RMSE, 95% 포함률, NEES, 수용수, 실제 수용 큰 손실 수, 역해 부재율을 보고한다.
- 779개 RF를 여러 정책·바이어스로 재사용한 것이므로 독립 환경 수로 합산하지 않는다. R2는 이미 분석한 경로여서 후반 평가도 개발용 재검증이며 새 환경 일반화가 아니다.

## 실패 및 채택
원본 parity, 입력 SHA, RF pose/s 대응, 양정치 공분산, saved-array 지표 재계산 중 실패하면 결과 채택·게시를 중단한다. 측정 s 역해가 없는 것은 정책의 정상 거부 사유로 수와 시점을 남긴다. DR보다 Heading와 XY가 함께 좋아지는지 조건별로 확인하며, 한 조건의 큰 드리프트 이득으로 B0 악화를 가리지 않는다.
