# LEARN G2 LiDAR 스캔 처리 수정 사양서

문서 ID `LTR-G2-SCAN-001` · 2026-11-15 · 구현 제안 v1

## 1. 원래 목적과 변경 범위

LEARN은 사용자가 선언한 시작 자세 `P_U`와 주행 거리를 받아 복도를 왕복하면서 원본 센서를 기록한다. 출발 시 정지 스캔과 복도 벽으로 주행 방향을 잡고, 복귀 후 시작·종료 스캔을 정합해 왕복 폐합 오차를 구한다. 기록한 bag으로 Cartographer 맵을 만들고, 복도 축·폭·벽 선분·주행선·위치별 관측성과 회전 여유를 담은 공간 모델 `space.json`을 생성한다. TEACH와 REPEAT는 이 모델을 기준으로 측정 지점과 헤딩을 판단한다.

벽 기준은 현재 자동 직진 제어에 필요하다. 시작 헤딩 오차는 거리와 함께 선언 좌표의 횡오차를 키우며, 벽 유도는 직진 방향과 측면 편차를 측정하는 데 쓰인다. 왕복 폐합과 맵 정합은 수집이 끝난 뒤 공간 모델을 등록할지 판단하는 증거다. 폐합 오차는 해당 왕복의 재현성을 나타내며 절대 위치 정확도를 직접 검증하지 않는다.

이번 변경은 **LEARN의 스캔 선별, 안전 판정, 실패 기록**에 적용한다. 기존 사용자 좌표·거리·왕복 계약, 주행 명령 상한, 베이스와 녹화기 연결 검사, OpenCR 300 ms 명령 만료 감시, 폐합·공간 모델 등록 기준은 현행 구현을 기준으로 삼는다. 드라이버 원인 조사와 운용 범위 확장은 이 사양에서 분리한다.

## 2. 기준 코드와 실제 실패

기준은 Pi에서 모듈 해시와 로딩 경로를 확인한 3M G2 그래프 수정판 `LTR_3M_MODE8_G2_GRAPH_FIX_20261115/deploy_stage`다.

| 경로 | 기준 동작 |
|---|---|
| `learn_run.py`의 `LearnIO`, `main` | 거리 1 m에서도 `wall_guided=True`다. `--check-only`와 실제 실행 모두 새 입력으로 `preflight`를 수행한다. 사전점검이 끝난 뒤 결과 디렉터리와 bag을 시작한다. |
| `corridor_map.py`의 `preflight` | 스캔 7 Hz 이상, odom 15 Hz 이상, 35 cm 주변 여유를 점검한다. 최신 스캔을 먼저 확인하고 새 스캔 24장을 최대 5초 동안 모은다. 24장 모두 `checked_points`를 거쳐야 벽 기준을 추정한다. |
| `corridor_map.py`의 `checked_points` | `base_scan`, 유한한 각도·거리 메타데이터, 양수 각도 간격, `range_min ≥ 0`, `range_max ≥ 8 m`를 요구한다. 각도 범위가 미달이면 장애물과 벽 반사점을 검사하기 전에 예외를 낸다. 이어 35 cm 내 반사점, 전방 양쪽 각각 유효 반사점 5개 이상, 폭 48 cm의 전방 경로와 계획된 직선의 장애물을 확인한다. 최초 전방 검사 길이는 요청 거리 + 0.50 m다. |
| `corridor_map.py`의 `ForwardIO.check`, `WallGuidedMotion._cmd`, `drive_wall_segments` | 직진 중 새 스캔을 검사한다. 불완전 스캔을 만나면 정지하고 새 스캔 12장과 정지 자세를 확인한다. 성공한 주행 중 복구와 일부 경유점 재측정은 같은 세션 한도 3회를 공유한다. 복구 창 자체에서 조건을 다시 위반하면 종료될 수 있다. |
| `learn_run.py`의 `turn_clearance`, `back_reference`, `stationary_capture` | 회전은 스캔 신선도와 반사점 여유를 별도로 검사한다. 복귀 전 벽 기준은 다시 24장 전수 검사한다. 기준판의 시작·종료 정지 캡처는 스캔 프레임을 확인하고 모은 스캔을 폐합용으로 융합한다. |

기존 각도 검사는 라디안으로 다음 값을 사용한다.

```text
N = len(ranges)
span = N × angle_increment
완전 판정 범위 = [2π − 0.10, 2π + 0.10] rad
하한 ≈ 354.27°
```

이 값은 **메시지가 표기하는 각도 폭**이다. 유효 거리 반환의 비율, 내부 각도 공백, 누락 구역의 방향, 주행 경로의 관측 여부는 이 숫자 하나로 판정할 수 없다. 하한의 `0.10 rad`는 기존 복도 주행 구현에서 이어진 상수다. 검토한 LEARN 설계와 실행 자료에서는 이 값이 안전 정지거리나 벽 추정 오차를 기준으로 도출됐다는 근거를 확인하지 못했다.

| 현장 증거 | 확인 내용 |
|---|---|
| 21:46 G2 실행 | 베이스 외에 bag 녹화기가 `/cmd_vel`을 구독하면서 구독자 수 검사에서 종료됐다. 발행한 속도 명령은 8건 모두 0이었다. 별도 그래프 수정판을 만든 계기다. |
| 그래프 수정판 사전점검과 22:02·22:04 실행 | 첫 사전점검에서 353.24°가 검출됐다. 새 표본으로 다시 한 사전점검은 통과했다. 실제 실행 두 번은 각각 새 사전점검에서 352.04°를 만나 `PREFLIGHT`, `output=null`로 종료했다. 두 번째는 직전 완전 스캔 60장이 관측된 뒤였다. 두 실행 모두 구동과 bag 녹화를 시작하기 전의 실패다. |

| 단발 미달 간격 | 앞뒤가 완전한 단발 미달 39건에서 두 완전 스캔의 수신 간격은 약 0.1895–0.2002초였다. 0.15초 완전 스캔 나이 기준은 이 표본에서 단발 미달만으로도 정지할 수 있다. |

스캔 폭 미달은 LEARN에서 처리하기 전 `/scan` 메시지에 이미 나타난다. 메시지 조립과 패킷·센서 출력 중 어디에서 폭이 줄었는지는 설치 바이너리 및 원시 패킷 대조가 필요하다. 352.04°를 무조건 허용하면 이번에 비는 정면 부근의 관측 공백까지 지나칠 수 있다.

## 3. 수정 요구사항

### S1. 정지 계측에서는 유효 표본을 다시 모은다

대상은 출발 전 벽 기준, 경유점 벽 보정, 복귀 전 벽 기준, 시작·종료의 폐합용 정지 캡처다.

1. 정지 계측은 새 스캔을 시간순으로 받는다. 고정 개수의 수신 묶음에서 첫 미달 스캔에 전체 실행을 끝내는 동작을, **품질을 만족한 새 스캔을 제한 시간 안에 모으는 동작**으로 바꾼다.
2. 초기 구현은 기존 24장 요구와 각도 하한을 벽 추정·폐합용 선별 기준으로 사용한다. 벽 계측은 단계당 최대 5초, 시작·종료 캡처는 현행 `n/7 + 3초` 한도를 적용한다. 계측마다 단일 단조시계 마감 시각을 두며, 새 메시지가 도착해도 마감 시각을 늘리지 않는다. 채택한 스캔의 유효 수집률과 기존 센서 수신률 검사를 기록한다. 경유점의 기존 7 Hz 유효 수집률 요구를 유지한다.
3. 폭만 작고 메타데이터와 관측점이 정상인 스캔은 벽·폐합에 넣지 않는다. 이 스캔의 실제 관측점은 35 cm 주변 및 계획 경로의 장애물 검사에 계속 쓴다. 각도 미달보다 먼저 또는 독립적으로 관측된 장애물을 처리한다. 잘못된 프레임이나 메타데이터, 신선도 상실, 정지 위치·헤딩 이탈은 별도 실패 사유다.
4. 최소 수량을 채우기 전에는 벽 결과나 폐합용 표본을 합격시키지 않는다. 벽 후보의 품질, 시작 헤딩, 예상 벽 여유, 양측 반사 및 정지 상태 확인을 현행 기준으로 적용한다. 창이 만료되면 스캔 수와 사유를 남기고 해당 단계의 비영점 명령을 금지한다.
5. bag이 시작된 구간은 원본 스캔을 그대로 기록한다. 정지 캡처 원본과 벽·폐합 계산에 실제로 사용한 표본을 스캔 시각 또는 순번으로 대응시킨다.

### S2. 이동 안전을 필요한 방향의 관측으로 판단한다

1. 모든 새 스캔에서 유효 관측점의 장애물 검사는 유지한다. 짧은 스캔에 장애물이 잡히면 즉시 기존 정지 경로를 호출한다. 관측되지 않은 각도와 아직 의미를 검증하지 못한 무반사·무효 범위는 안전 여유 계산에서 미관측으로 취급한다.
2. 직진은 차체 경계와 여유를 포함한 예정 주행 통로와 정지에 필요한 구간을 보호한다. 회전은 부착물을 포함해 회전 중 차체가 지나가는 구역을 보호한다. 관측 방향은 LiDAR 장착 변환을 적용해 로봇 기준으로 판정한다. 장애물 점이 없다는 이유만으로 관측 공백을 확보된 공간으로 집계하지 않는다.
3. 직전 관측을 이어 쓸 수 있는 최대 시간은 구역별로 정한다. 시간 한도를 검토할 때 사용할 속도, 센서·제어 지연, 정지 성능, 위치·각도 불확도를 명시한다. 운용 가능한 관측거리에서 이 동안의 이동과 실제 정지거리를 포함한 차체 여유를 확보해야 한다. 직전 스캔의 관측을 이어 쓸 경우 경과 시간과 자차 이동에 따른 위치·방향 변화를 함께 반영한다.
4. 필요한 구역의 관측이 부족하거나 기한이 지나면 즉시 속도 0을 요청하고 비영점 명령을 보류한다. 독립적인 OpenCR 300 ms 감시는 계속 적용한다. 소프트웨어가 일시 정지한 뒤 재개할 때는 정지 상태, 새 관측의 유효성, 장애물 여유, 같은 주행 구간, 베이스·녹화기 상태를 다시 확인한다. OpenCR이 만료 잠금에 들어간 경우 기존 운영자 재무장 절차를 따른다.
5. 방향별 관측을 보장하는 로직이 마련되기 전에는 보수적으로 정지한 뒤 완전 스캔으로 다시 확인한다. `0.15초`는 완전한 스캔의 나이를 제한하는 비교 시험값이다. 이 값을 운용값으로 채택할지는 실측 구간에서 정지 횟수·정지 시간·최소 실제 여유를 확인한 뒤 결정한다. 구역별 관측 근거 없이 전역 각도 하한만 낮추는 변경은 수용하지 않는다.

### S3. 맵과 공간 모델은 기록 후 품질을 판정한다

1. 완료한 왕복의 원본 bag으로 기존 Cartographer 절차를 실행한다. 폐합 계산은 S1에서 채택한 정지 스캔을 사용한다. 원본과 파생 결과의 경로와 해시를 연결한다.
2. 맵 생성, 시작 자세 정합, 벽 축 일치, 왕복 폐합과 공간 모델 등록의 판정을 기록한다. 주행 중 일시 정지, 계측 표본 부족, 녹화 실패, 맵 실패를 서로 다른 원인으로 남긴다. 수집이 중단됐거나 자료가 부족하면 기존 실패 상태를 기록하고 그 자료로 TEACH용 공간 모델을 등록하지 않는다.
3. 실행 기록에는 단계별 수신·채택·각도 미달 수, 최장 연속 미달, 완전 스캔 공백, 필요한 방향의 관측 공백, 정지·재개 시각과 사유, 적용한 설정과 코드 해시를 남긴다. 모의 실행과 Pi 실기 결과를 각각 기록한다.

## 4. 검증과 수용 기준

질문은 **간헐적 스캔 폭 미달을 처리하면서 동일한 안전 조건 아래 LEARN 데이터를 수집하고, 같은 품질 기준으로 공간 모델을 등록할 수 있는가**다. 동일 입력으로 기준판과 수정판을 비교한다. 진단에 사용한 180초 자료는 현상 재현에 쓰고, 운용값 채택에는 별도의 새 정지·주행 자료를 사용한다.

| 검사 | 입력과 수용 조건 |
|---|---|
| V1 기준판 재현 | 동일한 스캔 창에 352.04° 표본을 한 장 삽입한다. 기준판이 `PREFLIGHT`에서 종료하고 비영점 명령이 0건임을 확인한다. 수정판은 장애물이 없고 마감 안에 충분한 유효 표본이 있으면 정지 계측을 통과한다. |
| V2 수집 부족과 잘못된 입력 | 지속 미달, 오래된 스캔, 잘못된 프레임·각도, 정지 중 자세 이탈을 각각 주입한다. 제한 시간 안에 이유를 남기며 다음 주행 명령이 0건이다. |
| V3 짧은 스캔의 장애물 | 각도 미달 스캔에 35 cm 내 반사점 또는 보호할 전방 경로에 있는 장애물 점을 넣는다. 스캔을 벽 계산에서 제외해도 장애물 정지가 적용된다. |
| V4 누락 방향과 시간 | 동일한 전체 스캔 폭으로 전방·측방·후방에 각각 공백을 만든다. 필요한 직진 구역·회전 구역에 미관측이 남으면 해당 명령을 보류한다. 한도 경계 직전·정확히 경계·직후, 단발 미달과 연속 미달도 시험한다. 구역별 판단에 필요한 근거가 없으면 정지 후 재확인을 검증한다. |
| V5 운영 조건 회귀 | 베이스 구독 소실, 추가 발행자, 녹화기 소실, bag 쓰기 불가, odom·배터리 이상을 기존 기준대로 차단한다. 정상 0 속도 명령, OpenCR 만료와 재무장 흐름도 검증한다. |
| V6 왕복·결과 회귀 | 완전 스캔 기준 시나리오와 실제 진단 자료에서 얻은 간격·미달 분포를 반영한 시나리오로 편도 1 m 모의 왕복을 수행한다. 거리·회전 제한, 사용한 스캔 식별, bag·폐합·공간 모델의 실패 처리까지 확인한다. 매핑을 대역으로 시험한 경우 명시한다. |

오프라인에서 허용할 결론은 알려진 입력에 대한 소프트웨어 동작과 회귀 여부다. Pi에서의 주행 성능과 공간 모델 사용 가능성은 실기 결과 및 기존 등록 기준으로 판정한다. 여러 번 시험한 뒤 통과한 회차만 골라 기준을 정하지 않는다. 운용값을 확정할 때는 사용 자료·시간·판정 근거를 함께 남긴다.
