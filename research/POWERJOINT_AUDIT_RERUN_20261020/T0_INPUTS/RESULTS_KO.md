# T0 입력 보존 결과

TECHNICAL_PASS. 5개 Actions 원본 ZIP을 `audit-inputs-20261020-r01` release에 바이트 그대로 보존했다. 원본 Actions digest, 저장본 SHA256, release 재다운로드 SHA256이 모두 일치했다. 상세 asset URL·크기·해시는 INPUT_RECEIPT.json에 있다.

실행: Actions 39357262848, 실행 소스 b10ecb16534b4981d1f74a8d09963c9cef7de02b. 결과 artifact 12235433909, SHA256 95a3f0e6944201e7729c9eb62dbedb2229feb5897754385411845b212311cb8a.

공통 restore.py는 이 receipt의 release URL만 입력으로 사용하며 각 ZIP 및 FFD bank SHA256을 검사한다. 원본 artifact는 변경하지 않았다.
