## 2. 통제 채널 분석 (CTRL-TRAJ-07)

### 구성

- **경로:** x 4.2–19.8 m, y ∈ {0.0, 0.3, 0.6}.
- **조합:** mount 0/45 × yaw 0/180 → 12 config.
- **시나리오:** LOS, LOS+C(ceiling), LOS+F(floor), LOS+W(wall), ALL.
- **offset 정의:** 같은 참 pose의 LoS 모델 대비 차이다. 즉 LoS h()를 쓰는 EKF가 지속 편향으로 보는 양이다.
- **Stokes 구 위의 분해:**

```
t̂ = ∂S_LoS/∂ψ 방향(heading 방향),  n̂ = S_LoS × t̂ (heading에 직교하는 유일한 접선 방향)
b_par = ΔS·t̂   — heading과 혼동됨 (스칼라 b_s = Δs_fp와 같은 성질)
b_n   = ΔS·n̂   — 1차 heading 불변 (S2/S3 필요)
```

### 2.5 b_par를 heading 불변 지표로 예측할 수 있나 (leave-one-config-out 선형 R², 비중심)

| 대상 | 지표 집합 | ceiling만 (pose / 1 m 창) | ALL (pose / 창) | 반사 종류 혼합 (pose / 창) |
|---|---|---|---|---|
| b_par (FP) | b_n만 | 0.86 / 0.89 | 0.22 / 0.44 | **0.04 / 0.08** |
| b_par (FP) | 상관 지표 전체 (b_n, Δq, tap별 Stokes 모양) | 0.94 / 0.98 | 0.79 / 0.87 | 0.61 / 0.67 |
| b_par (FP) | 전력 지표 전체 (Δs, pulse 모양, log P_fp) | 0.91 / 0.94 | 0.46 / 0.63 | 0.27 / 0.25 |
| b_par (FP) | 전체 | **0.98 / 0.99** | **0.80 / 0.91** | **0.61 / 0.68** |
| b_s | 전체 | 0.88 / 0.97 | 0.75 / 0.82 | 0.67 / 0.79 |

- b_par와 b_n의 관계는 config와 반사 종류마다 다르다.
  - ceiling: corr(b_par, b_n) 중앙값 0.19–0.38이지만 config별로 −0.72 – +0.82로 **부호까지 바뀐다.** 1 m 창 방향의 원형 std는 33–47°다.
  - floor·wall: 원형 std 25–151°다.
  - 따라서 고정된 b_par/b_n 비율로 b_par를 추정할 수 없다. 회귀가 맞는 경우는 같은 반사 종류 안에서 다른 지표를 함께 쓸 때뿐이다.
- 반사 종류를 섞으면 b_n만으로는 b_par를 예측할 수 없다(R² 0.04).
- 잡음이 없는 결정적 R²다. Δs·모양 지표는 ceiling에서 SNR이 2–3이라 잡음이 있으면 기여가 크게 줄 것으로 본다.

## 3. 후보 state 설계 비교

| 설계 | 근거 | 판정 |
|---|---|---|
| A. 스칼라 b_s (GM) | 구현 2회, RMSE 이득 없음. ψ–β 상관 0.85–0.97 | 단독은 기각 |
| B. b_s + Δs 의사관측 | 전력만 사용, corpus R² 0.41, ψ 독립 | floor·wall형(겹침 0–3 tap)에 유효. **ceiling에는 신호가 0.005 수준이라 거의 못 본다** |
| C. Stokes 접선 offset (β_par, β_n) + Stokes 3성분 관측 | b_n 누설 0.05, SNR 11–25. mount 0 heading 감도 3.3배. 관측만 바꿔도 ceiling 편향 5.6 → 3.1° | **주 후보.** 단, β_par는 b_n과의 관계가 config마다 바뀌어(상관 −0.72 – +0.82) prior·회전 외에는 식별되지 않는다 |
| D. C + β_par 의사관측(지표 회귀) | 결정적 R²: ceiling 0.98, 혼합 0.61–0.68 | 회귀는 corpus 학습이 필요하다(계약 amendment 필요). Method A처럼 Δμ/g 정렬 위험을 state 불확실성으로 흡수해야 한다 |

권장 구성(설계 C → D 순서):

```
state  x = [x, y, ψ, b_g, β_par, β_n]
관측   z_S = S_obs (단위 Stokes, 접선 2성분),  z_r = r
모델   h_S(x) = S_LoS(x, y, ψ) ⊕ (β_par t̂ + β_n n̂)
동역학 β ~ GM(거리 L_d ≈ 1.5–2 m, yaw L_ψ ≈ 30–45°), σ_β(ρ) ≈ 0.03 (<3 m) → 0.09–0.10 (>6 m)
       floor/wall형 빠른 성분: R_S inflation (상관 거리 0.25–0.5 m)
선택   β_par 의사관측 = f(b_n, Δs, tap별 Stokes 모양) ± √(1−R²)·σ_β
```

## 4. 남은 확인 사항

1. **관측성 Gramian:** PJ_WINDOW_OBS 방식으로 [x, y, ψ, b_g, β_par, β_n] 창별 σ_ψ와 ψ–β_par 상관을 확인한다. 직진에서는 β_par가 prior로만 정해질 가능성이 높다.
2. **폐루프 검증:** CTRL-TRAJ-06 틀에서 설계 C(Stokes 관측 + β state)와 BASE / s 관측을 비교한다.
3. **corpus 검증:** Stokes 지표–e_s 관계와 β_par 회귀 학습은 POL-XCORR-001 label 격리 대상이다. contract amendment(별도 ID)가 필요하다.
4. **하드웨어:** 패킷 내 두 포트 위상 동기(S2/S3 측정 가능성)를 확인한다.
