# CTRL-TRAJ-05 — EKF P_ψψ 기반 gating, 운용 가능한 판별력 (EXPLORATORY)

- 실행: Actions run [41004445524](https://github.com/myoungsunk/sionna-resimulation/actions/runs/41004445524) → `results_run_41004445524/`
- 입력은 두 가지다.
  - CTRL-TRAJ-04 창 통계(run 41003294951).
  - 같은 EKF trace의 `cov[k−1, arm, ψ, ψ]`: 오차 정의와 같은 시점, 즉 k−1 posterior = k의 prior.
- 창별 σ_w = √(mean_w P_ψψ)이다. trace에 저장된 yaw 단위는 rad이고 deg로 변환했다. 정렬 검사는 구간 rms 차 < 1e-9로 통과했다.
- **gating과 임계값에는 참값을 쓰지 않았다.**
  - 임계값은 trace 2-fold 교차적합으로 정했다. 한 fold의 NULL 창으로 임계값을 정하고 다른 fold에서 평가했다.
  - mount·yaw 조합별로 따로 정했다. 운용 중에는 heading prior가 있으므로 조합을 알 수 있다.
  - 참값 오차는 oracle 비교에만 썼다.
- 실현 FPR은 모든 방식에서 0.049–0.055다. 교차적합 임계값이 다른 trace로 옮겨가도 유지된다.

## 해석

1. **운용 가능한 gating으로도 이득의 대부분이 남는다.**
   - P_ψψ 하위 82% 창: Dperp TPR 0.81 (oracle 0.97).
   - 하위 34% 창: 0.92 (oracle 1.00).
   - 같은 조건의 d0는 0.45 / 0.62다.
2. **oracle과의 차이는 P_ψψ의 과신과 낮은 분해능 때문이다.**
   - 실제/σ ≈ 3, rank 상관 0.23이다.
   - σ가 거르는 것은 큰 오차 꼬리뿐이다.
   - 따라서 gating을 더 좋게 하려면 공분산 consistency(Q 조정, NEES calibration)를 먼저 개선해야 한다.
3. **창을 버리지 않는 방식은 효과가 작다.** S_cov와 Z는 0.58 → 0.64–0.70이다. 운용에서는 "P_ψψ가 큰 구간은 판정 보류"가 맞다.
4. **gating은 d0에도 도움이 된다.** 그래도 같은 coverage에서 Dperp가 0.30–0.45 높다. 신호 상관이 주는 이득은 gating으로 대체되지 않는다.
5. **mount 45° / yaw 0°는 여전히 가장 약하다**(0.64–0.77).

## 한계

- **독립성 가정.** 오차와 σ는 실제 FULL 채널로 돌린 EKF에서 가져왔다. 이를 합성한 ceiling 가설에 입혔으므로, ceiling 오염이 EKF 자체의 오차와 σ를 바꾸는 피드백은 반영하지 않았다.
- **P_ψψ에 Q를 더하지 않았다.** posterior(k−1)를 그대로 썼다. G_cov(순위 기반)에는 영향이 없지만 Z의 스케일에는 영향이 있다.
- **통제 환경이다.** 1회 반사, 직선 1개만 다뤘다. 두 포트 위상은 이상적이라고 가정했다.
