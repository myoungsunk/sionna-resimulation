# CTRL-TRAJ-03 — 실제 heading prior 오차(시간 상관 포함)에서 원거리 ceiling 판별력 (EXPLORATORY)

- 실행: Actions run [41001310799](https://github.com/myoungsunk/sionna-resimulation/actions/runs/41001310799) → `results_run_41001310799/`
- 채널: CTRL-TRAJ-02 구성(실제 FFD bank, slab Fresnel, 직선 y = 0.3, x 4.2–19.8 m). 판별 대상은 원거리 ρ > 6 m.
- heading prior 오차: run 39376076166 EKF trace(FULL 채널, B0/L2, filter arm 9개). prior(k) = posterior(k−1) − truth(k), t ≥ 30 s, 15.6 m 길이(391 sample) 구간을 stride 25로 잘라 **2,556 구간**.
- label(e_s, e_r)은 쓰지 않았다. 오차 시계열만 사용했다.

## 판별 결과 (1 m 창, NULL = LoS만 vs LOS+C)

| 통계 | AUC (mount·yaw 4조합) | TPR @ FPR 5% |
|---|---|---|
| Dvec: 예측 LoS와의 상태 차이를 창에서 벡터 평균 | 0.78–0.91 | 0.03–0.17 |
| **Dperp: heading 오차 방향(∂S/∂ψ) 성분 제거 후 벡터 평균** | **0.90–0.96** | **0.34–0.73** |
| 시간 순서를 섞은 대조(Dperp) | 0.90–0.97 | 0.28–0.76 |

- heading 방향 성분을 빼는 것이 핵심이다. NULL 중앙값이 2–3°에서 0.07–0.25°로 떨어진다. ceiling 편차는 3.0–6.4°로 대부분 남는다.
- **시간 상관의 영향은 작다.** 시간 순서를 섞어도 AUC는 0.01 정도만 바뀐다.
- **제약은 오차 꼬리다.** 오차 rms > 8°인 구간(전체의 8%)에서 NULL 오경보율이 52%다. 1차 선형화(∂S/∂ψ)가 큰 오차에서는 성립하지 않기 때문이다.

- 여기서 gating에 쓴 rms는 **참값 오차**다. 실제 운용에서는 EKF 공분산 P_ψψ로 대체해야 하며, 그 경우의 성능은 아직 확인하지 않았다.

## 해석

1. 실제 EKF 수준의 heading prior(중앙값 1.3°, 꼬리 큼)에서는 단순 편차(Dvec)로 원거리 ceiling을 낮은 오경보율로 잡을 수 없다.
2. heading 오차가 편파 상태를 움직이는 방향을 빼면(Dperp) AUC가 0.90–0.96으로 오른다. 오차 rms ≤ 4° 구간에서는 TPR 0.88(oracle gating)까지 간다.
3. 남는 문제는 큰 heading 오차 구간의 선형화 실패다. 시간 상관은 주원인이 아니다.
4. mount 45°는 일관되게 더 어렵다(TPR 0.34–0.77). ceiling 편차가 heading 방향과 더 많이 겹치기 때문이다(Dperp 중앙값 3.0° vs mount 0°의 5.0–6.4°).

## 다음 단계 후보

- P_ψψ 기반 gating: trace의 `cov`에 있으므로 deployable 판별력을 확인할 수 있다.
- 비선형 판별: Dperp의 1차 투영을 "LoS 상태 곡선 S(ψ + ê)까지의 최소 거리"(ê를 창 안에서 추정)로 바꾸면 큰 오차에서도 동작할 가능성이 있다.
- 장착 오차(roll/pitch/장착각)를 추가해 정적 편차 혼동을 점검한다.
