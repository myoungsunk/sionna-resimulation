# 편파 상관오차 FGO — 기존 S4 비교

질문 ID: POL-FGO-CORR-001. 구현·실행·자기검사 완료. 독립 감사·과학적 채택은 미수행.

## 결과 판정

**현 버전 채택 보류: 목표 미달.** 동일 S4 게이트를 사용한 시간상관 FGO의 Full 헤딩 RMSE는 기존 S4의 2.39–2.94배였고, 헤딩 95% 포함률도 약 75%에서 50–52%로 악화했다. XY는 B0/L0에서 소폭 개선, L1 유사, L2 악화였다. 불확실성이 커졌지만 일관성과 정확도가 함께 개선된 것은 아니다. 기본 FGO의 결과는 S4와 대체로 비슷했다.

공통 게이트 16개 실행 중 시점별 최적화 평가한도 도달 16건(총 15,664 window), 게이트 없는 비교에는 44건이 있다. 결과는 누락 없이 포함한 탐색적 수치이며 엄격한 수렴 검증 완료 또는 최종 과학적 실패 판정으로 확대하지 않는다.

## 비교 조건

- R2 / Anchor B / mount 0 / seed 0, LOS·Full × B0·L0·L1·L2.
- 원본 S4 소스의 센서 입력 생성·운동 모델·frozen LUT 재사용. 거리 관측 없음.
- 979시점 모두 재귀 처리, t>=30초의 829시점 채점. 최신 상태만 비교하며 미래 관측 미사용.
- Fixed lag: 10 intervals (2초). 시간창 선택에 대한 민감도·실시간 장치 검증 없음.
- 첫 30초 Full 관측과 참 상태로 오프라인 잡음 식별, 이후 모든 채널·bias에서 파라미터 고정. 같은 궤적의 시간 분할이며 독립 환경 검증 아님.
- 관측오차 총분산 0.0081 유지, 상관 성분 분산 0.00417836, 독립 성분 분산 0.00392164, 지속시간 1.72164초.
- 원본의 영(0) bias process noise와 rank-deficient 운동잡음을 그대로 유지. 상태·제어잡음 변수로 결정론적 제약을 제거하는 reduced-coordinate nonlinear factor graph를 SciPy로 구현. GTSAM 사용 아님.
- 주변화: 오래된 prior·관측·첫 transition만 제거. 전체 window posterior를 새 prior로 재사용하지 않음. 과거 prior는 1차 근사, 출력 공분산은 국소 Gauss–Newton 주변 공분산.

## 검사와 해석 제한

- 선형 KF 대조, 색잡음 Schur complement, 고정창 주변화/중복 계산 방지, 관측 누락+색잡음 선형 대조, 유한차분 Jacobian 검사 통과(TESTS.json, MATCHED_TESTS.json).
- 8개 S4 조건의 상태·공분산·수용 mask 및 기존 CSV 지표 대조 통과(PARITY.json, VALIDATION.json).
- 56개 결과 행의 RMSE를 저장된 상태로 재계산. 입력·소스 해시 불변 확인.
- 최적화는 국소 LM, 종료는 scipy ftol/xtol/gtol 기준. 양의 종료코드가 엄격한 gradient stationarity나 전역 최적해를 보증하지 않음. 각 시점 status/nfev/optimality를 solver.json에 보존. 평가한도 도달 결과도 누락하지 않고 포함했으며 실패 0으로 처리하지 않음.
- 모델은 zero-mean stationary AR(1) 근사. 식별 구간의 잔차 평균 0.01812는 제거하지 않았고 추가 상태·파라미터를 사후 튜닝하지 않음.
- 헤딩과 c의 식별성, 다중 초기값·창 길이 민감도, 독립 RF 환경 반복 검증은 미완료. 공분산만 커졌다고 해결로 판정하지 않음.
- Full에서 기존 S4 대비 두 RMSE 모두 10% 이내인 탐색적 정확도 조건: False.

실행 증거: CONTRACT.json, MATCHED_CONTRACT.json, INPUT_HASHES.json, RESULT.json, MATCHED_RESULT.json. 원본 입력·기존 S4 결과는 변경하지 않았다.
