# 시간상관 FGO 악화 원인 분석

질문: POL-FGO-CORR-001-CAUSE. 자기검사이며 독립 감사가 아니다. 판정: REDIRECT. 기존 결과와 기준선을 변경하지 않았다. 새로운 성능 캠페인이나 파라미터 튜닝은 하지 않았다.

## 결론

현재 증거는 단순 최적화 계산 부족보다 **관측 오차의 시간 구조를 잘못 단순화한 모델과 헤딩/오차 분리 문제**를 더 강하게 지지한다. 구현의 전체 무결성이나 유일한 원인은 확정하지 않는다. 이번 FGO는 범용 FGO의 실패 증거가 아니다.

## 1. 모델 문제 — 확인된 사실과 인과 해석 구분

- 모델은 영평균 정상 AR(1), 지속시간 1.72164초, 총분산 0.0081이다. Full 첫 30초의 참 상태 잔차에서 식별했다. 평균 0.01812는 추정 과정에서 제거하거나 별도 평균모형으로 반영하지 않았다.
- 원시 평가 잔차의 평균은 0.02327, 분산은 0.012179로 학습 구간 0.005517보다 크다. 그러나 공통 게이트로 실제 사용한 표본의 분산은 0.004559이다. 따라서 **단순한 관측분산 부족만으로 공통 게이트 결과를 설명할 수 없다.** 학습은 게이트 전 전체 잔차, 평가 likelihood는 S4 선택 후 관측이라는 모델링 불일치가 있다.
- 실제 사용한 관측도 구간별 평균이 바뀐다: 30–60초 -0.00167, 60–100초 +0.00704, 100–140초 +0.06075, 140–196초 -0.01600. 동일한 영평균·단일 지속시간 근사로 설명하기 어렵다. 사후 구간 분석이며 독립적인 원인 제거 실험은 아니다.
- B0에서 100–140초 평균 heading 오차 +5.158도, 다음 구간 +3.621도이다. 편파 오차가 바뀐 뒤에도 헤딩 오프셋이 남는 패턴이 확인된다.
- c 추정값의 실제 관측오차 대비 RMSE는 0.0945–0.0958이다. 참 상태 기준 관측오차 RMS 0.1128에 비해 완전히 제거되지 않았다. pose-induced model error와 c의 상관은 약 -0.44이다. 이는 두 변수가 잔차를 나눠 설명하는 현상과 정합하지만, 이것만으로 전역 관측불가능성을 확정하지 않는다.

관측 선형화는 delta_s = H_pose delta_pose + delta_c이다. 한 시점에서 헤딩 변화와 c는 대체 가능하며, 분리는 운동·시간 prior에 의존한다. 시간상관 모델을 추가하는 것 자체가 그 분리 문제를 해결하지 않는다.

AR(1)+white 모델의 무한 정상 시계열 스펙트럼은 zero frequency 0.075939, Nyquist 0.004164이다. 원래 white 모델 0.0081과 비교하면 느린 변화의 관측 정보는 약 1/9.38로 감소하고 빠른 변화는 상대적으로 강하게 가중된다. 이 값은 이론적인 스펙트럼 비교이며, 실제 유한창/누락 관측에서의 정확한 정보비가 아니다. 같은 주변 분산을 유지해도 헤딩·바이어스와 연결된 느린 변화의 영향은 크게 달라진다는 점이 핵심이다.

## 2. 구현 문제 — 근거와 남은 제한

기존 검사: S4 8조건 상태·공분산·게이트 재현, 선형 KF 대조, 색잡음 Schur complement 대조, 고정창 중복 정보 방지 및 누락 관측 검사 통과. 이번 B0 causal replay도 저장 상태와 최대 차이 0이었다. 공통 gate 비교이므로 관측 개수 차이는 basic/corr 차이의 설명이 아니다.

발견한 근사 차이: window의 운동은 최적화된 입력 잡음에서 평가하지만, 오래된 transition 주변화는 입력 잡음 0에서 선형화한다. 엄밀한 동일 선형화점의 Schur marginalization과 다르다. 점검한 9개 window에서 transition intercept 차이 최대 약 9.9e-15, F 차이 최대 3.3e-7이었다. **이 차이의 존재는 확인했지만, 현재 수 도 악화를 설명할 크기의 증거는 없다.** 향후 정식 구현에서는 최적점의 동일 Jacobian으로 주변화하도록 통일해야 한다. 이 검사는 전체 시점의 오차 누적 영향을 배제하지 않는다.

2초 창은 유지 중인 변수의 길이일 뿐이다. 이전 정보는 주변화 prior에 남으므로, '2초보다 오래된 정보가 모두 삭제돼서 실패'라고 설명하면 틀리다. 오래된 비선형 제약을 재선형화할 수 없는 근사 영향은 아직 분리하지 않았다.

## 3. 최적화 문제 — 국소 검사

상관 FGO의 Full B0/L0/L1/L2에서 평가한도 도달은 각각 1/0/0/0회이다. 전체 공통 게이트 비교 16건을 상관 FGO Full 전체의 실패처럼 표현하면 안 된다.

B0의 시작·학습 경계·중간·최대 헤딩 오차·최대 gradient·계산 한도 도달·마지막을 포함한 9개 window에서 같은 prior/목적함수를 다시 점검했다. max_nfev 60→600, 더 엄격한 종료 허용오차를 적용한 국소 대조에서 heading 변화 최대 4.57e-6도, XY 변화 최대 3.80e-7m이다. 계산 한도 도달 시점도 heading 변화 약 1.12e-8도였다. 다른 초기 mean-start 대조에서도 비용은 사실상 같다.

따라서 검사 범위에서는 계산 횟수 부족이 수 도 악화의 주원인이라는 설명이 지지되지 않는다. 일부 window의 gradient 지표는 계속 크며, LUT의 구간별 미분/경계 효과 가능성이 있다. 전역 최적해, 모든 초기값, 모든 bias의 엄격한 수렴은 미확인이다. 대체 국소 해는 다음 시점으로 전파하지 않았다.

## 4. 개선 순서

1. **공통 비교 계약 정리:** S4 관측 선택기를 사용하는 조건부 비교를 유지해 모델 수정 효과를 분리한다. 전체 잔차로 식별한 모형과 선택 후 likelihood의 차이를 명시하고, 별도 자료에서 게이트와 관측모형을 함께 검증한다. 단순히 선택 후 분산으로 재조정하는 것 역시 선택편향을 해결한 것은 아니다.
2. **정상 영평균 AR(1) 수정:** 기하/공간/관측 품질에 의존하는 평균 또는 지속 오차 구조와 짧은 잔여 상관을 구분한다. 장기간 오프셋을 현재 zero-mean c 하나에 맡기지 않는다. 참값 기반 평균표는 오프라인 진단이며 온라인 모델로 주장하지 않는다.
3. **헤딩과 c의 분리 근거 확보:** c를 자유롭게 늘리기보다 추가 RF 특징이나 재방문 위치의 공유 오차 구조 등 독립 제약을 검토한다. 동일 XY라도 헤딩에 따라 RF 오차가 달라질 수 있으므로 공간 위치만으로 동일 오차를 강제하지 않는다. 별도 근거가 없으면 분리 불확실성을 그대로 인정한다.
4. **구현 정리 후 재검증:** transition 주변화를 동일 선형화점으로 통일하고, 원래 모델·파라미터 그대로 작은 회귀 검사로 영향 확인. 그 뒤에만 창 길이/초기값 민감도를 비교한다. 반복 횟수 증가나 창 확대만을 해결책으로 우선하지 않는다.

기존 FGO와 S4 결과는 유지한다. 모델 변경 후 성능 향상은 보장되지 않는다. 현재 원인 판정은 '모델 부적합을 강하게 지지, 주요 계산 부족 설명은 국소 검사에서 약화, 구현 근사 결함은 확인하되 영향 미확정'이다.

- ATTRIBUTION.json: 헤딩·bias·c·관측오차 및 solver 상태
- SOLVER_PROBES.json: 동일 prior 국소 최적화와 주변화 선형화 비교
- PROVENANCE.json: 소스 해시·원본 보존 확인
