# 편파 헤딩 + 가변 불확실성: 기존 데이터 비교

질문 ID POL-HEADING-VAR-001. 구현·실행·자기검사 완료, 독립 감사·과학적 채택 미수행.

## 결과 요약

**현재 버전은 S4 대체 채택 보류.** 공통 gate의 Full 조건에서 가변 불확실성 모델은 S4 대비 XY RMSE를 약 8–10% 줄였지만 heading RMSE는 약 18–25% 증가했다. heading Gaussian 95% 포함률은 약 70–73%, 원형 HPD 포함률은 약 71–74%로 명목 95%에 미달한다. 정확도 유지와 과신 해소를 동시에 달성하지 못했다.

게이트 없는 고정분산 heading 모델 대비 가변 모델은 큰 오차를 줄였다. 이는 가변 가중치가 작동했다는 증거이며, 기존 S4를 넘어섰다는 뜻은 아니다.

## 구현

- 원본 S4의 운동 입력 생성·상태 초기값·공분산·frozen LUT 재사용. 거리 관측 미사용. R2 Anchor B mount0 seed0, 979시점 인과 처리, t>=30의 829시점 평가.
- 추정기는 EKF/FGO가 아닌 **원형 헤딩 격자 + 가우시안 혼합 + 분산모드 IMM**이다. 기존 s의 정보는 frozen forward model을 통해 heading likelihood로 변환한다. 새로운 독립 헤딩 센서를 가정하거나 가까운 역함수 해 하나만 고르지 않는다.
- 360도 0.25도 간격의 헤딩 후보. 각 heading에 조건부인 위치·bias 분포를 사용하고 관측 likelihood에서 위치 불확실성을 선형 근사로 적분. 같은 prior를 두 번 독립 정보로 곱하지 않는다.
- 분산 후보: Rs*[1,2,4,8,16,32]. 후보별 확률을 Gaussian likelihood의 정규화 항까지 포함해 갱신. IMM 지속시간 5초, prior [0.70,0.15,0.075,0.04,0.025,0.01]. 결과 전 고정한 공학적 선택이며 참값 학습/평가 후 튜닝 없음.
- 각도 분포의 복수 봉우리를 유지하고 모드 간·분산 간 평균 차이도 공분산에 반영. 미세 봉우리 상대 prominence 1e-4 이하는 moment merge, IMM에서 45도 이내 basin은 혼합 근사. 확률질량을 특정 참값 가지로 선택하지 않음.
- 모든 조건에서 초기 heading 표준편차 5도를 알고 시작한다. 180도 전역 모호성이 실제 자료에서 해결되었다는 주장이 아니다. 대칭 synthetic case에서 두 후보 50:50 유지 검사로 기능만 확인.
- 이 모델은 가변 관측분산이며 시간상관이나 지속적 평균편향을 직접 보정하는 모델이 아니다.

## 검증

- 200개 입력에서 vector LUT 값은 원본과 정확히 동일, Jacobian 최대 차이 3.56e-15.
- 선형 관측의 Gaussian 평균·공분산 해와 격자 적분 결과 최대 차이 1.67e-16.
- 180도 대칭 모호성의 두 후보 질량 0.5 유지, 모드 간 공분산 확인. 잔차 0에서 log variance 정규화가 작은 분산을 선호하는지 검사.
- 8개 S4 조건의 상태·공분산·수용 mask parity, 저장 상태로 40개 지표 행의 RMSE 재계산, 입력 해시 불변·유한성·공분산 양의 정부호 확인.
- Full B0 matched 가변 모델을 0.125도 격자로 다시 계산한 numerical refinement 통과. 다른 조건의 전수 grid convergence 검증은 아님.
- 원형 HPD 포함률은 전체 다중모드 격자의 95% 질량집합으로 계산(참 헤딩에 가장 가까운 격자점). Gaussian 95% 포함률과 구분.
- 상대 분산 후보, 지속시간, 혼합 근사 및 LUT 물리 정확성에 대한 독립 검증 없음. 한 경로·seed에서 과신 해결/일반화를 주장하지 않는다.
