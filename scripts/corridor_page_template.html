복도 앵커–로봇 설치도

천장 앵커(보어사이트 바닥 방향)와 바닥 로봇(안테나 z 고정, xy 이동, yaw sweep). 두 안테나 모두 LP +45° / −45° 이중 선형 편파 포트 쌍(LP_plus45, LP_minus45, arm LP_DIAG)을 사용합니다.

x축은 화면 표시를 위해 압축했습니다. 실제 비율은 아래 근접 보기에서 확인하세요. 로봇 주변 고리의 눈금은 yaw sweep 값(0°–315°, 45° 간격)입니다.

앵커–로봇 근접 보기 (1 : 1 : 1)

연한 주황 상자는 같은 xy 이동 영역의 다른 예시 위치입니다. 로봇 본체는 시각화용 가정 크기입니다.

예시 위치의 링크 기하

off-boresight는 안테나 +z 축과 상대 단말 방향 사이 각도입니다. φ는 안테나 로컬 프레임 방위각이며 로봇의 φ는 yaw에 따라 변합니다.

확인 필요

  • 복도 치수, 앵커 위치, 로봇 안테나 높이, 로봇 크기는 임시 기본값입니다. 실제 값을 알려주시면 CorridorSetup 한 곳에서 바꿉니다.
  • 벽·바닥·천장 재질은 아직 지정하지 않았습니다. 표시한 면은 형상만 나타냅니다.
  • ±45° 포트의 E장 방향 (x±y)/√2와 보어사이트 = 안테나 로컬 +z는 기존 TX 회전 diag(1,−1,−1) 관례에서 가져온 명목값입니다. FFD 뱅크에서 읽어 확인하지 않았습니다.
  • yaw 부호는 +z 기준 반시계(위에서 볼 때)입니다.
